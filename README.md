## 학습의 구조

모든 PART B는 문제상황, 아직 판단할 수 없는 것, 공사담당자의 사고체계, 공무담당자의 사고체계, 직무 간 연결, 기술원리·공간, 시간축, 현장용어, 조건 변경, 판단 연습의 10개 절로 구성한다. 각 직무의 행동은 이유·미조치 결과·후속 영향까지 설명한다. CASE 17은 추가 정보에 따라 결론을 수정하는 통합 실습, CASE 18은 후배 설명과 새로운 공종으로의 전이 평가다.

## 보조 학습과 기록

기본 82장·도메인 108장·실전 Case 32개는 기존 회상 자료를 선별해 본편에 다시 연결한 보조 자료다. [연결 대장](docs/CARD_LINK_MAP.md)에서 확인한다. 본편 18장과 별개이며 보조 자료의 기존 답변 전체를 전면 재집필한 것은 아니다.

기본·도메인 카드는 질문/답변, 실전은 초안·힌트·대안표·자기평가를 제공한다. 평가는 1분·20분·1일의 고정 복습 간격이며 AI 채점은 없다. Space로 앞뒤 전환, 1/2/3으로 평가한다. 입력 중에는 단축키가 작동하지 않는다.

기록은 같은 브라우저의 localStorage에 저장되고 기기 간 동기화되지 않는다. 기록 탭에서 JSON 백업과 확인 후 초기화가 가능하다. 전면 개편 전 교재 읽음은 새 본문의 읽음으로 간주하지 않으며, 카드 복습·실전 답변은 보존한다. 새 교재는 PART A/B 읽음과 마지막 읽은 영역을 따로 저장한다.

## 저장소 구성과 집필

```text
AUTHORING_GUIDE.md       집필 규칙
README.md               시작·목차·실행
index.html / app.js / style.css
 docs/curriculum.json    성장 순서와 원문 경로
 docs/part_a/01~18.md    현장소설
 docs/part_b/01~18.md    직무별 학습 CASE
 docs/REBUILD_DESIGN.md  원재료 분석·목차·성장·Map
 reference/             용어·약어·도면·기술 검증
 data/book.js           원문에서 생성한 웹 교재
 data/stage*.js          보조 회상 카드
 data/cases.js          보조 실전 문제
 tools/                 빌드·내용·브라우저 검증
```

[집필 가이드](AUTHORING_GUIDE.md)에 따라 원문을 수정하고 다음을 실행한다. 런타임 CDN·API·fetch는 필요 없다. Node는 집필·검증용이다.

```sh
node tools/build-book.js
node tools/validate.js
node --check app.js
```

선택 브라우저 검증은 외부 설치된 Playwright와 Chrome을 사용한다. 저장소에 런타임 의존성을 추가하지 않는다.

```sh
PLAYWRIGHT_PATH=/path/to/playwright node tools/browser-qa.cjs
PLAYWRIGHT_PATH=/path/to/playwright node tools/simulation-qa.cjs
```

Chrome 경로가 기본 macOS 설치 위치와 다르면 CHROME_PATH로 지정한다. [QA 기록](docs/QA.md)은 웹 기능·콘텐츠 구조 검증과 기술 감수의 범위를 구별한다. 원문 변경 후 data/book.js도 함께 생성해야 배포된 화면이 갱신된다.

### 이미지 플래시카드

질문·답변 카드에 선택적으로 PNG 개념도를 연결할 수 있다. [작성·운영 가이드](docs/IMAGE_CARD_GUIDE.md)에 스키마, 이미지 저장 규칙, 샘플 ID와 검증 방법을 정리했다. 여굴·시추공·저면 위치도 이미지 3장과 신규 개념 카드 5개를 포함하며, 기존 공사일보 카드는 ID를 유지해 보완했다.
