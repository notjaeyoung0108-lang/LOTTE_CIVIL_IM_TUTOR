# 공사·공무 기본

> 질문의 출발점은 “누가, 어떤 자료로, 무엇을 결정하는가?”입니다.

## 현장의 두 흐름

공사는 실제 작업을 완성하는 흐름을 관리합니다. 작업면, 공법, 인력·장비, 시공 순서, 검측 준비와 일일 실적이 주요 관심사입니다. 공무는 그 작업을 계약과 비용의 언어로 연결합니다. 물량, 발주, 기성, 실행예산, 변경, 공기 및 준공 정산을 정리합니다. 회사와 현장 규모에 따라 업무 분장은 달라지므로 역할을 절대적인 경계로 외우지 마세요.

굴착 중 예상보다 단단한 지층을 발견했다고 생각해봅시다. 공사 담당은 위치·표고·굴착 방법·장비·작업량을 남깁니다. 공무 담당은 계약의 지반 조건과 비교하고 추가 조사, 변경 통지, 물량·단가·기간 영향을 정리합니다. 실제 작업 기록 없이 추가비만 요구하면 설득력이 떨어집니다.

## 사람과 결정의 관계

- 발주처: 요구 성능과 사업 목적을 제시하고 계약상 권한에 따라 변경·인수 등을 결정합니다.
- 감리: 해당 사업에서 부여된 범위에 따라 적정성을 확인합니다. 감리 확인이 시공사의 시공 책임을 모두 대체하지 않습니다.
- 시공사: 공사 실행과 품질·안전·공정·원가 등을 통합 관리합니다.
- 설계사: 설계 의도와 변경의 구조·기능 영향을 검토합니다.
- 협력업체: 약정된 전문 공종을 수행합니다. 작업 지시뿐 아니라 작업면·자재·검사·대금의 조건도 함께 맞춰야 합니다.

현장소장은 기술·계약·자원을 연결하여 판단하지만, 모든 승인 권한을 혼자 가진 것은 아닙니다. 조직도와 전결기준, 계약상 승인 경로를 확인합니다.

## 작업을 시작하기 전에 읽을 자료

**도면**은 형상·치수·배치를, **시방서**는 재료·시공·시험·인수 조건을, **내역서**는 항목·수량·단가·금액을 보여줍니다. 셋이 불일치하면 계약에서 정한 적용 관계를 확인하고 기술질의로 해소합니다. 현장 편의대로 하나를 골라서는 안 됩니다.

물량산출에는 도면 개정번호, 위치, 산출식, 단위, 공제·할증의 적용 근거를 남깁니다. 토량의 원지반 체적과 운반 체적처럼 상태가 다른 값을 섞지 않습니다. 수량이 바뀌면 발주잔량, 공정, 실행예산까지 연결해 검토합니다.

## 하루의 관리 순서

1. 전일 실적과 오늘 작업면·자재·도면·인력·검측 준비를 확인합니다.
2. 당일 작업 위험과 역할을 공유합니다. 안전활동의 TBM은 Tool Box Meeting입니다.
3. 승인된 순서와 방법으로 시공하고 은폐 전 검측을 받습니다.
4. 실제 물량·투입·대기·중단 사유·사진을 공사일보에 남깁니다.
5. 미해결 사항의 담당자·필요 회신일·후속 영향을 정하고 다음 계획에 반영합니다.

## 현장에서 말해보기

“공사 담당은 실제 지층과 생산량을 기록하고, 공무 담당은 그 사실을 계약 조건·원가·공기에 연결하겠습니다. 도면·시방·현장조건이 다르면 RFI로 판단 근거를 확보하고, 필요한 설계변경과 계약 절차를 별도로 진행하겠습니다.”

## 확인 질문

- 구도면으로 발주한 자재가 있다면 새 도면 배포만으로 조치가 끝날까요?
- 협력업체 지연에서 원청의 작업면 제공 지연은 어떤 자료로 확인할까요?

이 장을 읽은 뒤 기본의 공사·공무 역할 카드, 실전의 협력업체 지연 Case로 이어가세요.

## 실무 보강: 5년차 수준의 학습 목표

이 교재의 목표는 담당 구간의 작업 준비, 검측, 실적, 변경, 인수인계를 하나의 흐름으로 관리하는 것입니다. 학습기간을 실제 경력으로 환산하지 않습니다. 도면을 보고 설명하는 단계에서 출발해, 지도자의 검토 아래 작업계획을 작성하고 이상 상황을 보고하는 단계로 올라갑니다. 구조·지반의 설계 판단과 승인 권한은 해당 책임자에게 연결합니다.

| 역량 | 졸업생에게 요구할 행동 | 숙련 담당자 수준의 결과물 |
|---|---|---|
| 도면 독해 | 평면·종단·횡단·상세의 위치를 맞춘다 | 개정번호와 간섭 위치가 표시된 검토도 |
| 시공 준비 | 작업 순서를 설명한다 | 선행조건·자원·검측·중지 조건이 있는 작업계획 |
| 실적 관리 | 투입과 완료량을 기록한다 | 생산성 차이의 원인과 다음 날 조정안 |
| 문제 대응 | 이상을 발견해 보고한다 | 사실·미확인 사항·통제 범위·결정 요청이 있는 보고 |
| 마감 관리 | 서류를 모은다 | 실물·준공도면·시험·기성의 일치 확인 |

## 첫 현장 배치 때 만드는 다섯 가지 지도

1. **위치 지도:** 공구, 측점, 구조물 번호, 작업면, 차량·보행 동선, 지장물과 대피 경로를 표시합니다.
2. **도면 지도:** 평면에서 해당 측점을 찾고 종단의 높이, 횡단의 폭·경사, 상세의 배근·접합을 대조합니다. 치수 단위와 좌표·표고 기준을 함께 확인합니다.
3. **사람 지도:** 작업 지시자, 검측 요청자, 기술 검토자, 계약 승인자를 조직도에 표시합니다. 역할과 결재권이 같다고 가정하지 않습니다.
4. **문서 지도:** 최신 승인도면, 시방, 작업계획, 검사·시험계획, 위험성평가, 계약 문서의 보관 위치와 개정 이력을 적습니다.
5. **제약 지도:** 미회신 질의, 미승인 자재, 지장물, 장비 진입, 주민 통행 등 착수를 막는 조건에 담당자와 해소일을 붙입니다.

측량에서는 기준점 자체가 움직이거나 훼손될 수 있습니다. 기준점 보호 상태와 기존 검측 결과를 확인하고 독립된 기준으로 교차 확인합니다. 단순 기계 재설치로 기준점 오류가 해소되지는 않습니다.

## 하루를 실제로 운영하는 인수인계 양식

| 항목 | 작성 예시 — 가상 상황 |
|---|---|
| 위치·범위 | BOX-02 벽체, 측점 0+120~0+140 |
| 적용 문서 | 구조도 S-021 Rev.3, 승인 작업계획 번호 기록 |
| 완료·잔여 | 철근 조립 완료, 관통부 상세 회신 대기 |
| 오늘 착수 조건 | 매립물 확인·은폐 전 검측 완료 후 타설 여부 결정 |
| 미해결 사항 | 관통관과 주근 간섭, 임의 절단 금지 및 해당부 작업 보류 |
| 결정 요청 | 공사 담당이 RFI 제출, 설계 검토 및 권한자 확인 필요 |
| 인계 증거 | 위치 표시 사진, 간섭 치수, 검측 기록, 회신 문서 |

“문제없음” 대신 무엇을 확인했고 무엇이 남았는지 적습니다. 사진에는 촬영일·위치·방향·대상·크기를 식별할 정보를 남기고 도면 위치와 연결합니다. 사진만으로 확인하기 어려운 치수와 시험 결과는 별도 기록합니다.

## 훈련 문제와 해설: 구도면으로 철근을 가공했다면

**상황:** 새 도면에서는 개구부가 이동했는데 협력업체가 구도면으로 철근을 가공했습니다. 아직 설치하지 않았고 내일 타설 예정입니다.

**제출물:** 영향 목록, 당일 조치, 회신 요청을 각각 세 줄 이내로 작성하세요.

**해설:** 구도면의 추가 가공·설치를 통제하고 개정 전후 물량과 형상을 대조합니다. 가공품을 식별·분리하고 승인 상세에 따른 사용 가능 여부를 검토받습니다. 임의 절단·이음으로 맞추지 않습니다. 재가공 납기, 검측 예약, 타설·펌프 예약, 발생비용과 원인을 함께 정리합니다. 설계변경 여부와 비용 귀책은 별도 확인하며, 새 도면 전달만으로 완료 처리하지 않습니다.

**통과 기준:** 작업자에게 적용 도면을 설명하고, 영향받는 발주·시공·검측을 찾으며, 자기 권한 밖의 결정을 정확히 요청할 수 있어야 합니다.
