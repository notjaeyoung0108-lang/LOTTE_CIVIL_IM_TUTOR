# CASE 13. Rev.2 작업 중 Rev.3

## PART B. 학습

### 1. 문제상황

S-021 Rev.2로 B벽체 철근을 가공·반입·조립하던 중 최신 적용 승인본 Rev.3를 확인했다. 가공 80%, 반입 50%, B벽체 조립 30%는 각각 보고된 진도이며 동일 분모가 아니다. 검측 전, 타설 D-1이다. 변경 범위는 대조 후 관통부 주변으로 좁혀졌으나 처리 상세·배포 원인·최종 수량은 미확정이다. 비율과 시각은 교육용 상황값이다.

### 2. 아직 판단할 수 없는 것

승인번호가 높다는 사실만으로 모든 철근이 부적합인 것은 아니다. 개정 전후 치수·주근·보강근·정착·이음을 Mark별로 대조해야 사용 가능·재가공·기술검토 대상을 나눌 수 있다. 가공량에 반입량을 더하면 중복 집계된다. 총 대상량을 미가공·가공장 잔량·운송 중·현장 미조립·조립으로 나누어 합계를 맞춘다.

누가 언제 접수·배포·수령·가공 지시했는지, 계약상 변경 권한과 통지절차가 무엇인지 없으면 귀책·추가비를 확정할 수 없다. 작업 가능 시간, 재검측 예약, 펌프 변경 기한도 필요하다.

### 5. 공사 ↔ 공무 연결

공사는 Mark별 변경 전후 수량, 최초 발견 사진, 시각별 통제·전환 인원, 가공·운송 이력, 잔여기간을 넘긴다. 공무는 계약 항목과 대조하고 '대기 여섯 명 중 A로 전환한 인원은 몇 명인가'를 되묻는다. 공사는 실제 전환 시각을 보완한다. 수정 수량·비용·기간·책임을 하나의 추정 숫자로 뭉치지 않는다.

### 6. 기술원리와 공간

```text
가공 지시 → 미가공 → 가공장 잔량 → 운송 중 → 현장 적치 → 조립 → 검측 → 타설
                       Mark + 도면 개정 + 설치 위치를 연결
개정 대조 → 영향 없음 / 승인 상세로 처리 가능 / 별도 기술검토
```

공급망 개념도다. 타설 뒤에는 철근이 은폐되어 조사·처리 방법이 달라진다. 기존 철근을 조금 잘라 맞추는 것은 형상뿐 아니라 정착·이음·구조 힘의 전달을 바꿀 수 있다. 외관상 맞는지를 사용 승인으로 대체하지 않는다.

### 7. 시간축

지금은 오류 확산과 혼입을 막고, 2시간 뒤에는 위치별 수량을 닫는다. 오늘 종료 전에는 처리안·자원·검사 예약을 조정한다. 내일은 타설 착수 조건을 실제로 확인하고, 일주일 뒤에는 수정부와 후속 방수·매립물의 인계를 추적한다. 준공·정산에는 개정·검사·실물·청구 수량이 맞아야 한다.

교육용으로 처리안 승인 후 작업 4시간, 종료 18시라면 역산상 회신 한계는 14시지만 여유가 없다. 공급 변경 기한 13시는 별도 결정시한이다. 회신을 기다리다 이 기한을 넘기지 말고 취소·연기·조건부 유지 비용을 비교해 권한자에게 올린다.

### 8. 현장용어

Rev.는 문서 개정 식별이고 승인 상태가 아니다. 배포대장은 보낸 대상을, 수령·현장 사용 확인은 실제 전달 결과를 뒷받침한다. 귀책은 원인·의무·이행 자료를 검토한 책임 판단이며 구도면 발견만으로 확정되지 않는다.

### 10. 판단 연습과 핵심원칙

13시에 아직 회신이 없다. A도 같은 가공표를 사용한다는 사실이 추가됐다. A 검측을 계속할 수 있는가?

**해설:** 독립성 전제가 깨졌으므로 공통 Mark·상세 적용부터 다시 확인한다. A의 준비 완료를 근거로 적합성을 확정하지 않는다. 검사 준비와 은폐 허용도 구분한다. 공급사에는 권한자가 정한 예약 조정을 통지하고, 기술 회신 후 소요시간을 새로 계산한다. 핵심은 최신본을 찾는 데서 끝내지 않고 실제 물량·작업·계약의 영향 경계를 닫는 것이다.
