# CASE 01. 첫날, 누구의 지시인가

## PART B. 학습

### 1. 문제상황

반입 동선에 기존 자재가 있어 차량 회차가 어렵다. 빈 공간은 오후 장비 배치 예정지다. 자재 이동에는 양중·적치·보행 동선 확인이 필요하다. 즉시 이동 요청이 들어왔지만 이동 위치와 지시·확인 책임이 정해지지 않았다.

### 2. 아직 판단할 수 없는 것

자재 중량·인양 방법·새 적치장의 지지 조건, 동시 반입 계획, 이동 및 통로 재개 권한을 확인해야 한다. 누가 부탁했는지만으로 실행 가능한 지시가 되지는 않는다. 조직도는 이름을, 업무분장·전결·작업계획은 결정 범위를 보여준다.

### 3. 공사담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 충돌하는 차량·보행·양중 동선을 통제 | 사람과 장비가 같은 공간을 사용 | 접촉·협착 위험 | 안전담당·작업 책임자와 경계 확인 |
| 배치도와 실제 자재·장비 조건 대조 | 빈 땅에도 예정 용도가 있음 | 이동한 자재를 다시 이동 | 작업계획 변경 범위·자원 결정 |
| 승인된 이동 후 통로 상태 확인 | 이동 완료와 통로 인수는 다름 | 잔재·장애물 상태로 재개 | 확인된 구간부터 진입 재개 |
| 분리된 자재 검수는 준비조건 확인 후 진행 | 겹치지 않는 작업도 있음 | 불필요한 전체 대기 | 다음 날 반입 준비 유지 |

### 4. 공무담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 대기·이동의 원인과 시작·종료 기록 대조 | 대기 시간만으로 책임을 알 수 없음 | 모든 비용을 한쪽에 귀속 | 계약의 작업면·운반 범위 검토 |
| 원계약 이동인지 추가 이동인지 확인 | 요청이 곧 추가비 승인은 아님 | 정상 작업을 중복 청구 | 필요 통지·수량·단가 협의 |
| 실제 투입과 전환분을 구분해 기성 추적 | 대기했다가 다른 일을 할 수 있음 | 인건비·장비비 이중 집계 | 확인된 비용과 미합의 비용 분리 |

### 5. 공사 ↔ 공무 연결

공사는 배치도에 이동 전후 위치, 대기 차량, 실제 투입·전환 시간을 표시해 일보와 연결한다. 공무는 운반 계약 범위와 전표를 대조하고 누락된 중단 사유를 되묻는다. 현장의 한 줄 지시가 인력·장비·시간을 바꾸므로 사실 생성과 계약 해석이 이어져야 한다.

### 6. 기술원리와 공간

```text
출입구 → 회차 구역 → 작업면
             ↑ 겹침 확인
기존 적치 → 양중 이동 → 새 적치(오후 장비 자리와 대조)
보행 동선은 각 이동의 위험 영향권 밖으로 계획
```

축척 없는 동선 개념도다. 작업면은 면적뿐 아니라 진입·지지·자재·인력·검사 조건을 갖춰야 사용 가능하다. TBM은 작업 전 위험과 역할을 공유하는 회의이며 참석 서명만으로 실제 조건 확인을 대신하지 않는다.

### 7. 시간축

지금 충돌을 통제하고 2시간 뒤 이동·재개 결과를 확인한다. 오늘 종료 때 잔량과 위치를 인계하지 않으면 내일 같은 대기가 반복된다. 일주일 뒤 반복 대기를 운영계획에 반영하고, 정산에서는 일보·전표·지시 기록으로 실제 발생을 설명한다.

### 8. 현장용어

공사는 시공 실행을, 공무는 현장사실의 계약·물량·비용 연결을 주로 맡는다. 회사별 분장은 다르다. 반장은 작업조 운영의 핵심 창구이며 설계변경·금액 승인을 자동으로 가진 사람은 아니다. 작업일보는 계획이 아니라 실제 발생을 남기는 기록이다.

### 9. 조건 변경 시뮬레이션

새 적치장이 확인되지 않으면 자재 이동을 먼저 지시하지 않는다. 진입 예약을 조정하고 검토할 배치안을 올리며 실제 대기를 남긴다. 반대로 이미 승인된 이동계획과 조건이 그대로라면 그 범위에서 실행하고 완료·재개를 확인한다. 다른 작업도 같은 양중 장비를 쓰면 독립 작업이라는 전제가 사라져 공정과 대기비를 다시 계산한다.

### 10. 판단 연습과 핵심원칙

“통로만 비워주세요”를 다음 작업자가 실행할 수 있는 지시로 바꿔보라.

**해설:** 대상·이동 위치·방법·통제 범위·실행 책임·재개 확인·시한을 특정한다. 확인 안 된 지지 조건은 빈칸으로 남겨 결정 요청한다. 현장관리는 지시의 속도가 아니라 실행 조건을 연결하는 일에서 시작한다.
