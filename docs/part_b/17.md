# CASE 17. 한 구간의 아침

## PART B. 학습

### 1. 문제상황

우천 뒤 A 저면이 젖었고 주변 상태 확인이 필요하다. B는 자재가 늦으며 예약 결정시한이 있다. C는 운반로에 버팀이 간섭한다. 세 구간의 동선·자원·지하수 독립성은 아직 확인 중이다. 아래 수량·기간·비용은 통합 연습용 가정이다.

### 2. 아직 판단할 수 없는 것

A의 지반·물·주변 이상과 저면 인수 조건, B 납기 확약·예약 변경 조건, C 승인 단계·우회 동선이 필요하다. 기술적으로 가능한 대안인지 확인되기 전 가격표만으로 선택하지 않는다. 최초 정보는 모순·누락을 포함할 수 있으므로 확인 출처와 시각도 적는다.

### 3. 공사담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |

### 4. 공무담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |

| 사건별 원인·지시·접수·계약 의무 분리 | 우천·납기·간섭은 다른 사건 | 귀책·비용 일괄 처리 | 사건별 통지·변경 경로 |
| 통제·전환·취소·추가 물량을 공통 시간축에 연결 | 같은 장비 시간이 겹칠 수 있음 | 대기비 중복 | 실제 증빙과 임시 추정 구분 |

### 5. 공사 ↔ 공무 연결

공사는 위치도·미확인 사항·물량·실행 소요일·자원 전환안을 보낸다. 공무는 계약 수신자·통지 시한·취소비·지급 조건을 되돌려 준다. 두 직무는 기술 승인, 예약 결정, 비용 합의를 서로 다른 상태로 관리하며 현장 책임자가 필요한 결정을 언제 해야 하는지 보이게 한다.

### 6. 기술원리와 공간

**추가 정보 봉투 1:** 기술검토 결과 A 처리 두 안은 모두 적합하다고 가정한다. 현재 시점부터 A 잔여기간은 느린 안 4일, 빠른 안 3일이다. 비용은 각각 300만원·500만원이다. B 자재와 작업은 합쳐 5일, A·B가 모두 끝나야 D를 2일 수행한다. C의 검증된 우회 작업은 2일이며 D 착수 전 완료 조건이다. 자원 충돌·휴일·기타 제약은 없다고 단순화한다.

```text
현재 ─ A(4일 또는 3일) ─┐
     ├ B(5일) ─────────┼ D(2일) → 완료
     └ C(2일) ─────────┘
```

느린 안도 빠른 안도 max(A,B,C)+2=7일이다. 준공이 실제 단축될 때만 회피 가능한 현장비가 하루 100만원이라면 빠른 A안의 200만원 추가비는 이 조건에서 기간 절감으로 회수되지 않는다. 안전·품질상 우열은 없다고 가정한 경제성 비교이며 실제 공법 추천이 아니다.

### 7. 시간축

지금 위험권 통제와 시한 분리, 2시간 뒤 추가 정보와 대안 재평가를 한다. 오늘 종료에는 기술 회신·예약·실제 전환·계측 결과를 인계한다. 내일 시공·검사 조건을 확인하고 일주일 뒤 잔여 경로와 예상원가를 갱신한다. 준공·분쟁에는 결정 당시 정보와 이후 변경을 구분한다.

**추가 정보 봉투 2:** 교육용 B 예약 변경 기한은 오늘 10시, 기술 회신 예정은 11시다. 11시까지 기다리는 것은 별도 예약 결정을 놓칠 수 있다. 10시 전에 취소·연기·유지 조건과 비용을 확인해 권한자가 결정하고 회신 결과에 따라 공정표를 갱신한다.

### 8. 현장용어

결정시한은 해당 선택을 유효하게 실행할 마지막 시점이다. 회신 예정일과 다를 수 있다. 조건부 대안은 어떤 사실·승인·자원이 충족될 때 실행하고 불충족 시 무엇으로 바꿀지 명시한 안이다.

### 9. 조건 변경 시뮬레이션

| 새 조건 | 달라지는 판단 |
|---|---|
| B가 2일로 회복 | 느린 A는 총 6일, 빠른 A는 5일. 하루 회피비 100만원이면 빠른 안 순추가비 100만원. 기한 가치·다른 비용을 별도 확인 |
| A 주변 균열·탁수 동반 | 비용 비교보다 위험 영향권·전문 검토 확대. 최초 적합 가정 재검토 |
| C 우회로가 A 위험권 통과 | C 진행 안 철회, 새 동선·일정·비용 검토. 이름만 독립 구간이 아님 |
| A 빠른 안 장비가 B와 공유 | 단순 병렬망 무효. 자원 배치와 실제 소요일 재계산 |
| B 지연과 A 통제가 같은 인원에 영향 | 대기 인원×시간을 사건별로 중복 산정하지 않고 실제 전환 대조 |

### 10. 판단 연습과 핵심원칙

해설을 가리고 07:10 최초 정보만으로 한 페이지 보고를 작성한다. 문제·사실·미확인·통제/계속·자료·결정권자·시한·대안·재개/재중지·기록·내일 영향을 포함한다. 그 뒤 봉투 1·2와 조건 하나씩을 받아 결론을 수정한다.

**해설:** 최초에는 안정과 독립성을 모르는 부분을 단정하지 않는다. 보호 조치와 병행 사실 확인, 예약시한 관리를 먼저 제시한다. 봉투 1에서는 두 A안의 총 완료일이 같음을 계산한다. 봉투 2에서는 예약 결정과 기술 승인을 분리한다. 정답 문장보다 새 정보로 기존 결론을 철회·수정하는 능력을 평가한다.

평가는 사실·추정 구별, 통제 범위, 기술·권한 연결, 독립 작업 검증, 시간·비용 계산, 기록·추적의 여섯 항목을 각각 0(누락)·1(언급)·2(근거·조건까지 설명)로 한다. 임의 구조변경이나 위험권 투입이 있으면 총점과 무관하게 해당 판단을 재작성한다. 점수는 교육 피드백이며 현장 자격 판정이 아니다.
