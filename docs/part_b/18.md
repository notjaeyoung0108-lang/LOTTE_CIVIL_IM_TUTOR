# CASE 18. 왜 전부 멈춰야 한다고 생각해

## PART B. 학습

### 1. 문제상황

포장 전 배수 연결부에서 물고임이 관찰됐다. 덮개 높이는 측정했지만 관저고·연결 기능·준공도면이 일치하는지 미확인이다. 오후 포장 장비가 예정돼 있다. 사건을 다른 사람에게 설명하고 인수 자료로 남기는 최종 연습이다.

### 2. 아직 판단할 수 없는 것

상하류 관저고·구배·연결부·막힘·토사 유입·하류 수위, 설계 유량·시험 절차, 실측과 도면의 기준·개정이 필요하다. 물고임만으로 높이 오류를 단정하지 않는다. 독립 포장 구역도 같은 배수·통행 기능을 공유하는지 확인한다.

### 3. 공사담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 기능 미확인 연결부 은폐 통제 | 포장 뒤 접근·수정이 어려움 | 재굴착·민원 확대 | 안전한 조사와 인수 경계 설정 |
| 평면·종단·실측·기능시험 대조 | 덮개 높이는 관로 흐름을 증명 못 함 | 문서만 맞춘 채 성능 누락 | 원인·처리 상세 검토 |
| 처리·재검사 후 준공도면 반영 | 실제값 기록과 설계 적합성은 다름 | 부적합을 도면 수정으로 숨김 | 운영자 인수·유지관리 자료 |
| 후속 담당자에게 근거·미결·시한 인계 | 담당자가 없어도 판단을 이어야 함 | 같은 조사 반복 | 잔여 보완과 기능 확인 종결 |

### 4. 공무담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 인수·기성·준공 조건과 시험 범위 대조 | 본체 시공 완료가 계약 완료 아닐 수 있음 | 인수 지연 누락 | 잔여 의무·통지 관리 |
| 포장 예약·수정·재시험 비용 원인 분리 | 설계·시공·유지 상태 원인이 다름 | 귀책·비용 오판 | 지시·실측·일보 근거 협의 |
| 보완 목록·준공도면·최종 물량 대조 | 서류와 실물이 다르면 정산도 불안정 | 미결 항목 소실 | 합의·지급·하자 자료 인계 |

### 5. 공사 ↔ 공무 연결

공사는 관로 위치·실측·시험·처리·미완료 목록을 제공한다. 공무는 계약 인수 조건과 수량·금액 상태를 연결한다. '끝남' 대신 시공·검사·기능·문서·합의 상태를 각각 적고 무엇이 아직 완료를 막는지 되묻는다.

### 6. 기술원리와 공간

```text
노면 → 집수구 → 상류 관저고 → 관로 → 하류 접속 → 배수계통
                            ↓
             펌프·수위 감지·전원·경보 등 설계 기능시험
```

교육용 직선 관로 40m에 계획 구배 0.5%라면 높이차는 40×0.005=0.20m다. 상류 EL.10.20m라면 하류 EL.10.00m다. 이 값은 권장 구배가 아니며 유량·관경·하류 수위·접속·시방 확인이 별도다. 실제 침수나 정전을 임의로 일으키지 않고 승인 시험 절차로 연동 기능을 확인한다.

### 7. 시간축

지금 은폐 경계와 조사 담당을 정하고 2시간 뒤 기능·높이 자료를 맞춘다. 오늘 종료 전 포장 예약·대안을 판단한다. 내일 처리·검사, 일주일 뒤 운영 인수 및 보완 종결을 확인한다. 준공·정산에는 실물·As-built·시험·기성의 동일 위치가 이어져야 한다.

### 8. 현장용어

관저고는 관 안쪽 바닥의 표고다. Punch List는 잔여 보완 항목 목록, As-built는 실제 시공 상태를 반영한 준공도면 등 기록이다. 실제값을 옮겼다는 사실이 미승인 변경을 정당화하지 않는다.

### 9. 조건 변경 시뮬레이션

**도로 전이:** 관로는 적합하지만 포장 하부층이 강우 뒤 연약해졌다. 배수 합격으로 포장을 승인하지 않고 하부층 재확인·처리·시험을 연결한다. 장비 전환·예약과 기성 인수 조건도 바뀐다.

**교량 전이:** 거더가 받침에 닿았으니 인양구를 해제하자는 요청이다. 임시 고정·횡방향 안정·받침·연결 순서·승인 가설계획 확인 전 해제를 진행하지 않는다. 전문 검토와 작업 책임자의 확인을 연결하고 장비 대기·실제 거치 기록을 남긴다. 명목 크레인 톤수만으로 인양 가능을 정하지 않는다.

**터널 전이:** 막장 용수가 늘고 지보가 늦지만 굴진량을 맞추려 한다. 안전한 위치의 막장·천단·변위·용수 기록으로 설계 지보 패턴과 굴진 조건을 검토받는다. 미지보 구간에 기록자를 투입하지 않는다. 굴진·지보·환기·대피 조건과 장비·인력 영향을 연결한다. 이 문제들은 판단 전이 연습이며 교량·터널 시공법 전체 교육을 대신하지 않는다.

### 10. 판단 연습과 핵심원칙

최종 미지 Case: 포장 3시간 전, 관저고 기록 두 장이 서로 다르다. 시험 담당은 오후에만 온다. 협력업체는 독립 구간이라며 부분 포장을 요청하지만 두 구간의 배수계통도는 아직 없다. 장비 취소 기한은 1시간 뒤다. 모든 시각은 연습 조건이다.

먼저 90초 보고를 하고 이어서 후배에게 던질 질문 다섯 개를 적는다. 상대가 제공하지 않은 사실을 만들어 답하지 않는다. CASE 17의 평가표로 검토한다.

**해설:** 불일치 원자료·기준·위치와 배수 연결을 확보하고 미확인 은폐를 통제한다. 독립성을 모르는 구간은 진행 가능으로 확정하지 않는다. 시험 시각과 예약 결정시한을 분리해 권한자에게 대안을 올린다. 처리·검사·재개·준공 반영 조건과 인계 기록을 남긴다. 좋은 질문은 '어느 기준인가, 어디까지 영향인가, 무엇이 아직 미확정인가, 누가 언제 결정하는가, 무엇으로 확인할 것인가'처럼 다음 판단에 필요한 사실을 끌어낸다.

문제 정의 → 사실 확인 → 통제 → 영향범위 → 기술 검토 → 대안 → 승인 → 실행 → 기록 → 공정·원가 추적을 스스로 전개하되, 긴급 위험에서는 조사보다 보호가 먼저다. 설명할 수 있다는 것은 모르는 부분까지 분명히 말할 수 있다는 뜻이다.
