# CASE 02. 먹과 레벨 사이

## PART B. 학습

### 1. 문제상황

굴착 예정선과 현장 표시가 일치하지 않는다. 사용 도면의 적용 상태, 표시 종류, 기준점 보호 상태가 모두 확인 대상이다. 기계 재설치만으로 해소됐다고 볼 수 없다.

### 2. 아직 판단할 수 없는 것

평면 위치 오류인지 표고 오류인지, 구조물 중심선·외곽선·작업 여유선 중 무엇을 비교했는지부터 구별한다. 승인 도면·측점·좌표계·수직 기준·단위와 원 측량 기록이 필요하다. 도면 Rev. 번호가 가장 크다는 이유만으로 시공본이라 하지 않는다.

### 3. 공사담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 불일치 선을 따르는 굴착 착수 보류 | 잘못 파면 형상·인접 지반까지 영향 | 수정 범위 확대 | 측량 확인 전 인원·장비 배치 조정 |
| 승인본·기준점·실측을 독립 기준으로 교차 확인 | 같은 오류 기준으로 재측정하면 오류 반복 | 정밀하게 잘못 시공 | 측량 책임자가 확인 결과·원인 기록 |
| 평면·종단·횡단·상세를 같은 위치로 묶기 | 한 도면만으로 위치와 높이를 다 알 수 없음 | 매립·접속 단계 간섭 | 수정 표시·재검측 후 착수 확인 |
| 구 표시 제거와 작업자 전달 확인 | 새 도면 배포만으로 옛 선이 사라지지 않음 | 작업조 교대 후 재발 | 후속 먹매김의 기준 이력 보존 |

### 4. 공무담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 도면 접수·측량·작업지시 시각 확보 | 설계 변경과 표시 오류의 원인이 다름 | 재측량 원인 단정 | 계약 의무·귀책 검토 |
| 재측량·대기·재작업 수량 분리 | 미착수면 철거비는 발생하지 않음 | 가정 비용이 실제 비용에 섞임 | 통지 필요 여부와 비용 근거 정리 |
| 착수 지연을 후속 일정에 연결 | 몇 시간 대기가 준공 지연과 같지 않음 | 기간 주장 과장 | 갱신 공정·기성 수량과 추적 |

### 5. 공사 ↔ 공무 연결

공사는 수정 전후 좌표·표고·적용 도면·확인자·작업 보류 시각을 제공한다. 공무는 요청 주체·계약 범위와 대조한다. 사진의 선 색만으로 원인을 설명할 수 없으므로 측량 원자료와 표시 목적을 보완한다.

### 6. 기술원리와 공간

```text
평면: 측점과 좌우 위치 → 횡단: 그 위치의 폭·경사
          ↓
종단: 같은 측점의 높이 → 상세: 접속·치수·배근
          ↑
보호된 기준점 + 좌표·표고 기준 + 현장 측량 기록
```

EL은 정한 기준면에 대한 표고이고 GL은 지표면의 높이를 나타내는 표현이다. 도면별 표기 정의를 확인한다. BM은 높이를 옮기는 기준점이다. 레벨이라는 말이 표고인지 측량기인지 대화에서 구별해야 한다.

### 7. 시간축

지금 잘못된 착수를 막고 2시간 뒤 독립 측량 결과를 대조한다. 오늘 종료 전에 표시 교체와 배포를 확인한다. 내일 굴착·버림·먹매김으로 오류가 넘어가지 않게 인계하고, 일주일 뒤 매립 위치 및 준공 측량에도 동일 기준을 사용했는지 추적한다. 정산 때 수정 범위는 기록으로 설명한다.

### 8. 현장용어

먹은 위치 표시, 측점은 노선상의 위치 식별이다. IFC는 Issued for Construction의 발행 상태 표현이지만 승인·사용 권한은 현장 문서 절차로 확인한다. 승인도면과 시방서가 충돌하면 임의로 우선순위를 정하지 않는다.

### 9. 조건 변경 시뮬레이션

이미 굴착했다면 실측과 지반 영향, 처리 상세 검토가 추가된다. 검측됐어도 기준점 오류 가능성이 확인되면 같은 기준을 쓴 다른 위치까지 영향 조사한다. 단순 오래된 선이었고 승인본·독립 측량이 일치하면 오표시 제거와 작업자 재전달 후 정해진 절차로 재개한다. 각 경우 재작업량·승인·공정·기록 범위가 다르다.

### 10. 판단 연습과 핵심원칙

두 측량값이 같으면 착수해도 되는가?

**해설:** 두 값이 같은 훼손 기준점에 의존하면 독립 검증이 아니다. 기준·적용 도면·실측 방법을 확인해야 한다. 수치의 일치보다 무엇을 기준으로 얻은 수치인지가 먼저다.
