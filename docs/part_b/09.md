# CASE 09. 피복과 관통관 사이

## PART B. 학습

### 1. 문제상황

벽체 일부에서 피복 부족과 관통관·철근 간섭이 발견됐다. 거푸집 폐합과 다음 날 타설이 예정돼 있다. 간격재 누락, 배근·거푸집·관통관 위치 오류 또는 설계 간섭 중 원인은 미확정이다.

### 2. 아직 판단할 수 없는 것

피복을 잰 면과 바깥 철근 위치, 거푸집의 먹 대비 위치, 관통관 중심·치수, 배근 상세·개정, 이웃 구간 영향이 필요하다. 수정 후 조립·재검측 시간과 공급 예약 변경 기한도 확인해야 한다.

### 3. 공사담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 해당 면 폐합·은폐 보류 | 닫으면 치수와 처리 확인이 어려움 | 타설 뒤 조사·철거 확대 | 영향 위치 표시·검측 경계 설정 |
| 먹·거푸집·철근·관통관을 따로 실측 | 같은 부족 치수도 원인이 다름 | 한 부재 이동이 다른 조건 파괴 | 원인별 처리 상세 검토 |
| 설계 변경은 기술질의·승인 경로로 연결 | 주근 절단·관 이동은 기능·구조 변경 | 임의 보수로 새 결함 | 승인 처리 후 재검사 |
| 다른 면 작업은 지지·동선 독립 확인 | 거푸집은 연결된 임시 구조 | 보류 면이 인접 안정에 영향 | 작업 책임자 확인 후 구획 진행 |

### 4. 공무담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 도면·질의·지시 이력과 계약범위 대조 | 설계 충돌과 설치 오류 구분 필요 | 모든 수정이 추가공사로 처리 | 원인·통지 검토 |
| 수정 인원·재료·거푸집 재개방·대기 분리 | 작업 조정으로 피한 비용이 있음 | 비용 누락·중복 | 승인 상세별 실적 증빙 |
| 회신·검측·예약 시한 별도 추적 | 기술 회신일이 타설 가능일 아님 | 취소비·공기 영향 뒤늦게 발생 | 변경·기성·정산 자료 연결 |

### 5. 공사 ↔ 공무 연결

공사는 위치 표시 사진, 치수, 기존·제안 상세, 처리 소요시간을 제공한다. 공무는 계약상 지시와 통지 경로를 확인하고 실제 재작업 일보를 연결한다. 기술 회신 문서만으로 비용 승인까지 끝났다고 표시하지 않는다.

### 6. 기술원리와 공간

```text
거푸집 안쪽 면 |← 피복 → ○ 가장 바깥 철근 | 주근·보강근
                                [관통관]과 간섭 위치 확인
생콘크리트 측압 → 거푸집 면판 → 지지·연결 부재 → 지지체계
```

피복은 철근 보호·내구성과 구조 상세에 관계한다. 철근 중심까지의 거리와 혼동하지 않는다. 동바리는 슬래브 등의 시공 중 하중을 지지하며 바닥 지지·가새·접합·배치가 연결된다. 거푸집·동바리의 국부 변경도 타설 속도·순서·하중 조건과 함께 검토한다.

### 7. 시간축

지금 은폐를 막고 2시간 뒤 원인과 영향부를 특정한다. 오늘 종료 전 회신·재조립·검측·공급 계획을 조정한다. 내일 착수 조건을 확인하고 일주일 뒤 방수·설비 연결을 인계한다. 준공에는 최종 관통부 위치와 검사 이력이 남아야 한다.

### 8. 현장용어

Sleeve는 관통부를 형성·보호하는 관 등의 매립물이다. Spacer는 간격재다. 검측은 시공 상태를 요구사항과 대조하는 검사이며 요청 접수와 진행 승인은 같지 않다.

### 9. 조건 변경 시뮬레이션

간격재 누락만 원인이고 나머지 위치가 적합하면 승인된 상세로 복구·재검사한다. 주근·관통관 상세가 서로 충돌하면 기술검토가 필요하다. 타설 뒤 발견되면 추가 하중·후속 영향 통제, 조사·성능 평가·처리 승인으로 바뀌고 비용과 기간도 확대될 수 있다.

### 10. 판단 연습과 핵심원칙

“10mm만 옮기자”는 말에 어떻게 답할 것인가? 10mm는 이 질문의 가상 치수이며 허용 오차가 아니다.

**해설:** 어떤 부재가 왜 어긋났고 이동으로 정착·피복·기능·임시 안정이 어떻게 바뀌는지 묻는다. 작은 수치가 작은 영향을 보장하지 않는다.
