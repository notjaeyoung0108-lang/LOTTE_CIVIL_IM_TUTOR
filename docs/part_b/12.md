# CASE 12. 덮기 전에 남겨야 할 것

## PART B. 학습

### 1. 문제상황

방수 완료 사진과 검사 요청은 있으나 진행 확인 기록이 없다. 이 현장의 ITP에서는 해당 지점을 Hold Point로 정했다. 일부는 이미 은폐됐고 되메우기 재료의 함수 상태도 달라졌다.

### 2. 아직 판단할 수 없는 것

검사 요청·입회·결과·미결 항목, 실제 은폐 범위, 방수 처리와 보호재 상태, 토사 재료·층두께·함수비·시험 조건을 확인해야 한다. 사진의 범위와 치수·성능 시험을 구별한다.

### 3. 공사담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 미확인 면의 추가 은폐 보류 | 확인 기회를 잃기 전 경계 고정 | 재굴착·재시공 확대 | 품질담당과 검사·처리 범위 결정 |
| 이미 은폐된 부분은 부적합 절차로 조사안 요청 | 사진만으로 충족 여부를 못 정함 | 미검사 상태가 완료로 처리 | 승인 확인·처리·재검사 |
| 되메우기 층별 재료·작업·시험 기록 연결 | 다음 층이 아래층을 가림 | 취약층 위치 추적 불가 | 합격·인수 후 다음 층 진행 |
| 검증된 다른 구간의 작업으로 전환 | 검사 누락은 해당 영향부 문제 | 불필요한 전체 대기 | 동선·재료·장비 독립 확인 |

### 4. 공무담당자의 사고체계

| 행동 | 왜 | 하지 않으면 | 후속 영향 |
|---|---|---|---|
| 검사 통지 의무·수신·처리 이력 확인 | 미입회와 미통지는 다름 | 책임 원인 혼합 | 계약별 통지·협의 |
| 재굴착·복구·재시험·대기 수량 분리 | 정상 되메우기와 재작업 중복 가능 | 기성·청구 오류 | 위치·층별 일보로 실비 연결 |
| NCR 종결과 기성 인정 조건 대조 | 보고서 발행은 적합 확인이 아님 | 미결 품질이 정산에 묻힘 | 보류·확정 금액과 인수 추적 |

### 5. 공사 ↔ 공무 연결

공사는 위치·층번호·시험번호·실제 완료량·미확인량을 넘긴다. 공무는 계약 인정 조건과 비교해 증빙 부족분을 되묻는다. '오늘 100m³'처럼 위치와 상태 없는 양만으로 검사·기성 범위를 같게 보지 않는다.

### 6. 기술원리와 공간

ITP는 Inspection and Test Plan, 검사·시험계획이다. Hold Point는 지정 확인 없이 다음 단계로 넘어갈 수 없는 지점이다. Witness Point는 입회 기회와 통지·불참 처리를 정한 지점으로 현장 절차를 읽어야 한다. IR/WIR은 검사 요청 명칭으로 쓰이지만 서식·권한은 사업별로 다르다.

```text
외벽 → 방수 검사 → 보호층 확인 → 되메우기 1층 → 시험·인수 → 2층
         미확인/부적합 → 조사·처리 승인 → 실행 → 재검사 → 종결
```

함수비는 건조토 질량 대비 물 질량 비다. 다짐은 재료·함수비·층두께·장비·방법이 함께 결정한다. 교육용 습윤밀도 2.00t/m³, 함수비 12%, 최대건조밀도 1.90t/m³이면 건조밀도=2/1.12≈1.786, 다짐도≈94.0%다. 합격 여부는 대상 재료·층·시험법·적용 기준 없이는 정할 수 없다. 젖은 흙에 통과 횟수만 더하는 것은 검증이 아니다.

### 7. 시간축

지금 은폐를 막고 2시간 뒤 검사 이력을 확인한다. 오늘 종료 전 인수·미결 구간을 나눈다. 내일 층별 시험을 이어가고 일주일 뒤 강우·후속 하중으로 상태가 바뀌었는지 본다. 준공에는 검사·부적합 종결·기성이 실물과 맞아야 한다.

### 8. 현장용어

NCR은 부적합의 식별·처리·확인을 추적하는 문서다. 재검사와 종결 권한은 현장 품질 절차에 따른다. 요청서를 보낸 것, 검사한 것, 적합 판정, 다음 공정 진행 확인은 구별한다.

### 9. 조건 변경 시뮬레이션

Witness Point에 적법하게 통지했고 불참한 경우에도 정한 진행 조건·자체 검사·기록을 확인한다. 이미 덮었다면 노출 또는 대체 확인 방법의 적정성을 권한자가 검토한다. 강우 뒤에는 이전 합격층도 유실·연약화를 재확인한다. 조사·재작업·대기와 승인 경로가 각기 달라진다.

### 10. 판단 연습과 핵심원칙

NCR을 닫으려면 무엇이 필요한가?

**해설:** 원인·범위, 승인된 처리, 실행 증거, 재검사 결과, 권한자의 종결과 후속 인계가 필요하다. 서류 생성이 아니라 요구사항 충족을 확인하는 것이 품질관리다.
