# B01. 실행예산 관리 / 원가관리

Layer 1 수행업무 실무지식 → Layer 2 단위 판단 → Layer 3 통합 CASE

※ 아래 수치 및 생산성은 교육용 가정이다. 실제 현장 기준·계약·승인 절차는 해당 프로젝트 자료로 확인한다.

## 1. 이 업무는 무엇인가

Level 1 — 실행예산은 동일 시공 범위에 대해 내부적으로 정한 원가 기준이다. 계약금액은 발주처와의 대가이고 발주금액은 구매·외주 약정액이다. 원가관리는 완료량·발생원가·남은 의무를 맞춰 최종예상원가(EAC)와 손익전망을 갱신하는 일이다.

## 2. 왜 하는가

지급을 늦추면 현금은 남지만 공사비가 줄어든 것은 아니다. 설치량이 계획보다 적어서 돈을 덜 쓴 것도 절감이 아니다. 손실을 늦게 발견하면 필요한 자금·파트너사·회복계획이 동시에 흔들린다.

## 3. 업무의 Input

원가코드별 실행예산·산출 근거, 계약금액과 확정 변경, 발주/외주 Commitment 대장, 완료량·검측, 발생전표·미청구 추정, 지급대장, 발주잔량, 잔여 자원·기간 Forecast를 같은 기준일에 받는다. 세금·간접비 포함 범위를 맞춘다.

## 4. 업무의 Output

완료량 대응 예산과 발생원가 비교표, 수량/단가/생산성 차이 분석, 중복 없는 ETC(잔여예상원가), EAC·Variance·손익전망, 미합의 변경의 별도 시나리오, 회복안 추가비와 회피가능원가 표가 남아야 한다.

## 5. 실제 업무순서

Level 2 — 실행 범위와 기준일을 고정한다. 완료량에 해당하는 예산을 산출하고 발생했지만 청구되지 않은 비용을 더한다. Commitment 전체에서 이미 발생한 부분을 빼 잔여 약정을 분리한다. 미발주 잔여·위험·기간비를 더해 ETC를 만든다. EAC와 계약대가를 비교하되 미확정 회수액은 확정 매출로 넣지 않는다. 월말마다 전월 Forecast와 실제 차이를 원인별로 설명한다.

## 6. 담당자가 보는 핵심 숫자

발생원가+잔여예상원가=EAC다. 실행예산-EAC를 예산여유로 정의하면 음수는 초과다. 계약금액-EAC는 여기서 정한 동일 범위의 예상 손익이며 실제 회계이익과 구분한다. 완료량×해당 예산단가와 발생원가를 비교한다. Commitment를 발생원가에 통째로 더하면 이미 설치된 부분이 중복된다.

## 7. 현장 관계자

공사팀은 완료/잔여량과 생산성을, 파트너사는 실적·미청구 내역을, 구매 담당은 발주 잔액을 제출한다. 공무는 원가코드·미청구·변경 회수 가능성을 맞춘다. 재무 담당은 지급 일정과 현금을 따로 본다. 소장은 비용 승인과 손익 전망의 가정을 확인한다.

## 8. 정상상태

발생·지급·기성·발주잔액이 각각 설명되고 미청구가 다음 달에 갑자기 나타나지 않는다. 잔여 생산성 악화와 공기 변화가 ETC에 반영된다. 확정 변경과 미합의 청구가 나뉘며 가속비 승인 전에 준공 효과를 계산한다.

## 9. 이상징후

완료량은 줄었는데 절감 보고가 나오거나, 지급액을 발생원가로 쓰거나, 전체 발주액과 기발생분을 중복 합산한다. 잔여 구간 운반거리가 늘었는데 기존 평균단가를 그대로 쓰면 EAC가 작아 보인다.

## 10. 이상 발생 시 확인순서

먼저 수량·기간·세금·간접비 범위를 맞춘다. 누락 전표와 미청구를 확인한다. 발주 잔액이 ETC에 이미 들어갔는지 대조한다. 생산성·단가·수량·대기 중 어느 요인이 차이를 만들었는지 분해한다. 대안을 CP와 연결하고 다음 원가 마감 때 실제 절감 여부를 검증한다.

## 11. 다른 업무와의 연결

공정 단축은 실제 종료가 바뀔 때만 기간비 회피를 만든다. 품질 재작업은 물량·자원·파트너사 추가비로 번지고 대외 변경 승인은 비용 발생과 별개다. 싼 자재·작업조로 바꾸는 안은 규격·검사·생산성 적합성을 먼저 확인한다. 비용 지출이 필요한 품질·안전 조치를 손익만으로 배제하지 않는다.

## 12. 현장 언어

“지급 500만원과 발생 700만원은 다릅니다. 남은 공사 Forecast 500만원이면 EAC는 1,200만원입니다. 기성 미승인은 회수 문제로 따로 보고하겠습니다.”

## 13. 미니 문제

### Level 3 — 미니 문제

모든 금액은 부가세·본사비 제외, 동일 범위의 만원이다. 실행 1,000, 계약 1,300, 지급 500, 미지급 포함 발생 700이다. 총 Commitment 800 중 기발생 500, 남은 약정 300이다. 별도 미발주 잔여 150, 잔여 현장비 50이며 서로 겹치지 않는다. EAC·예산차·손익과 “지급이 적으니 절감”의 오류를 설명하라. 추가 60으로 실제 준공 2일 단축, 일 회피비 20이면 경제성은?

#### 해설

ETC=300+150+50=500, EAC=700+500=1,200이다. 예산여유=1,000-1,200=-200, 예상 손익=1,300-1,200=100이다. 700+800+150+50은 기발생 약정 500을 이중 계산한다. 가속의 순추가비=60-2×20=20으로 EAC는 1,220이 된다. 회피비 40은 ETC의 현장비 50 안에 포함되어 있다는 가정이다. 다른 경로 때문에 준공이 그대로면 회피비는 0이고 EAC 1,260이다. 공무가 중복·회피 가능 계약을 확인하고 소장이 기한 가치와 함께 결정한다. 다음 실적 마감에서 실제 발생과 줄어든 잔여비를 재확인한다.
