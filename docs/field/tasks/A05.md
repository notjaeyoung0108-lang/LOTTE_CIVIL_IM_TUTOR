# A05. 공정관리

Layer 1 수행업무 실무지식 → Layer 2 단위 판단 → Layer 3 통합 CASE

※ 아래 수치 및 생산성은 교육용 가정이다. 실제 현장 기준·계약·승인 절차는 해당 프로젝트 자료로 확인한다.

## 1. 이 업무는 무엇인가

Level 1 — Baseline은 승인된 비교 기준이고 Data Date는 실적을 어디까지 반영했는지 정한 기준시점이다. 공정관리는 같은 시점의 계획과 실제를 비교하고 잔여작업·제약을 갱신해 후속과 준공 영향을 판단하는 일이다. 계획표의 막대를 옮기는 것으로 끝나지 않는다.

## 2. 왜 하는가

진도율이 낮다는 말만으로 야근하면 비주공정만 빨라질 수 있다. 반대로 작은 지연도 Near-Critical 경로의 Float를 소진하면 준공을 지배한다. 현재의 Critical Path를 알아야 한정된 비용과 자원을 어디에 쓸지 결정할 수 있다.

## 3. 업무의 Input

Baseline과 지난 Schedule Update, Data Date까지의 작업일보·검측 인수량, Actual Start/Finish 증빙, 잔량·생산성, 승인·반입·검측 확약, 자원 달력과 후속 인수 조건을 받는다. 착수 보고가 있어도 승인 조건이 미충족이면 그 사실을 함께 남긴다.

## 4. 업무의 Output

Actual Start/Finish와 Remaining Duration을 반영한 갱신 공정표, 계획/실적 차이의 원인표, CP·Total Float 변화, Look Ahead 제약대장, Recovery 대안별 Milestone/비용표, 결정과 다음 점검시각을 만든다. Baseline을 덮어써 지연을 숨기지 않는다.

## 5. 실제 업무순서

Level 2 — 기준시점을 고정하고 실제 착수·완료를 검증한다. 물량 기준 진도율과 잔량을 계산한다. 최근 실적이 잔여 작업조건에도 적용되는지 확인한다. 잔여기간과 선후관계를 갱신하고 자원 충돌·승인 달력을 반영한다. CP와 Near-Critical을 함께 보고 회복안 적용 전후를 비교한다. 책임자의 실행 지시 후 다음 실적을 반영한다.

## 6. 담당자가 보는 핵심 숫자

총 20t 중 계획 16t, 실제 12t이면 Data Date 진도는 계획 80%, 실제 60%, 차이는 -20%p다. 잔여 8t÷2t/day=4일이며 남은 계획 3일보다 1일 길다. 순작업 지연 1일이 준공 지연인지 알려면 후속 Float·합류점·자원을 봐야 한다. Total Float는 전체 망과 제약의 결과이며 임의로 모든 작업에 1일씩 배정하지 않는다.

## 7. 현장 관계자

공사담당자는 반장과 검측자료로 실제 완료량을 맞춘다. 공정담당자는 경로·달력을 계산하고 자재/장비 담당자는 향후 확약을 준다. 품질팀은 검사 대기와 재검사를 알려준다. 공무는 추가비·지연 통지 근거를 확인하며 소장은 Recovery와 Acceleration의 목적·비용을 결정한다.

## 8. 정상상태

실적시점과 물량 기준이 같고 미완료 작업에 실제 종료일을 넣지 않는다. 승인·자원 제약을 포함한 잔여망이 실행 계획과 맞으며 CP 옆의 짧은 Float도 감시한다. 회복목표와 실행 담당자가 명확하다.

## 9. 이상징후

진도율은 증가하는데 검사 미완료가 쌓인다. 지난주 CP만 보거나 Actual Finish가 미래 날짜다. 야근해도 후속 검사일이 같고, 비주공정의 여유가 줄어도 보고에서 빠진다.

## 10. 이상 발생 시 확인순서

실적 오류인지 실제 생산성 저하인지 먼저 분리한다. 잔량과 작업면·자재·장비·검측 병목을 확인한다. 현재 CP/합류점을 다시 계산한다. 대안이 원인 제약을 풀 수 있는지 확인하고 타 구간 인원 전환 효과까지 반영한다. 첫 점검에서 회복 목표가 미달하면 추가 지연 원인과 대안을 다시 제출한다.

## 11. 다른 업무와의 연결

공정 지연은 원가의 대기·연장·간접비, 품질의 검사 시간, 자원의 공유 슬롯으로 이어진다. 파트너사에 단순 만회 독촉 대신 잔량·제약·확약을 요청한다. 공무와 발주처/감리에는 원인별 시간축을 제출하고 계약상 인정 여부와 물리적 지연을 구별한다.

## 12. 현장 언어

“Data Date는 화요일 17시입니다. Actual Finish가 아니라 잔량 8t입니다. 이 속도면 4일이니 Recovery로 하루 줄여도 검측 슬롯이 움직이는지 먼저 보겠습니다.”

## 13. 미니 문제

### Level 3 — 미니 문제

Data Date t=0에서 A 계획 잔여 3일, 실제 잔여 8t, 생산성 2t/day다. B는 계획/실제 잔여 5일, 검사 C는 둘이 끝난 뒤 1일이다. A를 3t/day로 높이는 데 90만원이 든다. 모든 작업은 동일 달력, 독립 자원이며 소수 작업일을 허용한다. A 가속이 완료를 당기는가? B가 2일로 회복됐다는 새 정보가 오면?

#### 해설

현재 A=4일, B=5일이므로 전체 6일이다. A 가속 후 2.67일이어도 전체는 6일로 동일하다. 이 단순 망에서 A Total Float는 1일이다. B가 2일이면 원안 5일, 가속안 약 3.67일로 1.33일 단축되지만 실제 검측 예약이 고정이면 그 효과는 줄어든다. 공무에 90만원과 실제 회피비를 비교 요청한다. 당일 종료 시 잔량·B 회복 확약·검사 달력을 갱신해 선택을 재검토한다.
