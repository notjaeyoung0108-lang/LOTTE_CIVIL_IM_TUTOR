## 핵심 문제와 보존한 장점

기존 자료는 공사·공무 역할, 생산성 병목, 공정 여유, 완료량 원가, 저면·가시설·콘크리트, 변경·기록, 7단계 문제해결과 계산 가정을 잘 구분했다. 이를 새 이야기로 대체하지 않았다.

부족했던 것은 절차 사이의 사고과정이었다. 1장의 ‘추가 가공·설치를 통제’는 왜 폐기·해체부터 하지 않는지 설명이 짧았다. 2장 증차 계산에는 출입구·사토장 대기 장면이 없었다. 5장 버팀 제거는 하중 경로를 공간적으로 읽기 어려웠고, 8장 방수 검사 누락은 은폐 후 손실과 재발 방지의 연결이 짧았다. 9장 기술 회신과 계약 결정의 차이는 정확하지만 실제 회의에서 구분하는 대화가 없었다. 공통 인물·성장·시간축·조건별 판단을 추가했다.

초반 재영은 새 도면 배포나 증차 같은 눈앞의 해법을 떠올린다. 중반에는 하중·지반·은폐의 이유를 설명하고, 후반에는 담당자·기한·대체 작업·승인·비용·증거를 직접 연결한다. 현장 5년차가 모두 같은 판단을 한다는 단정 대신 고려해야 하는 변수와 전제를 보여준다.

## 공식 자료 확인과 기술 검증 범위

2026-09-24 열람. 사례의 인물·시간·대화·계산은 자체 구성한 교육용 가정이다.

- [FHWA 시공 관리·검사 안내 Appendix D](https://www.fhwa.dot.gov/construction/cpmi04d2.cfm): 위치·시험·재료·시공 기록의 연결과 공종별 검사 항목을 확인하는 참고자료로 사용했다. 해외 판정 수치·권한을 국내 조건으로 채택하지 않았다.
- [FHWA 공정 추정 안내](https://www.fhwa.dot.gov/majorprojects/schedule_estimating/): 공정 추정 자료의 공식 출처를 확인했다. 교재의 단순 일정 계산은 자체 가정이며 개별 계약 판단이 아니다.
- [국가건설기준센터 영문 기준 안내](https://kcsc.re.kr/standardCode/eng): 영문판이 최신 국문 개정을 반영하지 못할 수 있다는 안내를 확인했다. 용어 번역만으로 적용 기준·판본을 확정하지 않는다.

국내 기준 본문 전체 조항 대조나 구조·지반 전문가 감수를 완료한 것은 아니다. 현장별 피복·정착·지보·굴착·양생·인양·배수·검사·계약 통지 조건은 적용 문서와 책임자 검토가 추가로 필요하다. 범용 수치를 새로 만들지 않았다.

## 다음 개선의 우선순위

먼저 실제 적용 도면·시방·검사계획을 익명화해 1·4·5·6장의 검토 근거 자료 묶음을 만들고 기술 감수를 받는다. 다음으로 여러 대안의 비용·예약 조건을 실제 자료로 바꾸어 조건 변경의 현실성을 높인다. 기존 카드와 32개 Case는 독립 복습 자산으로 보존했으므로, 후속 개선에서는 이야기의 각 사건과 더 세밀하게 연결할 수 있다. 자동 검증은 내용의 기술적 적합성을 인증하지 않는다.

## 장별 순차 업로드

사용자의 ‘하나 하고 올리고, 하나 하고 올리기’ 요청에 따라 1~10장을 각각 별도 커밋·푸시하는 방식으로 반영한다. 각 커밋의 data/book.js에는 그 시점까지 올라간 장만 반영하여 미업로드 장의 원문과 앱 데이터가 어긋나지 않게 했다. 매번 스테이징된 전체 스냅샷의 콘텐츠 검증과 JavaScript 문법 검사를 실행하고, 푸시 후 원격 main의 커밋 일치를 확인한다.

1장에는 도식 조판과 공통 집필 규칙을 함께 올리고, 10장에는 전체 교육 안내·README·결과 보고·추가 QA를 함께 올린다. GitHub Pages의 공개 설정은 main 브랜치 루트이며, 각 푸시가 배포 대상으로 반영된다. 배포 실행의 성공 여부와 원격 커밋 반영은 별도 확인 대상이다.
