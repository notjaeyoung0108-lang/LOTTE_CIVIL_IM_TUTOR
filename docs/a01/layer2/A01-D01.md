# A01-D01. Shop DWG 제출은 도면 Constraint 해소인가

## 문제상황

※ 아래 물량, 생산성, 인원, 비용 및 일정은 교육용 가정이다.

상태시점은 **2028년 3월 14일 화요일 10:00**이다. 현장 달력은 **월요일~토요일 작업, 일요일 휴무, 해당 기간 별도 휴일 없음**이며 작업시간은 **07:00~17:00**, 휴게시간은 **12:00~13:00**이다. 야간작업은 하지 않는다.

B2 교육구간 β의 **벽체 개구부 매립 프레임 설치 및 자체점검** Activity를 3월 17일 금요일 07:00에 시작할 계획이다. 현장에는 Shop DWG Rev.1이 배포되어 있고, 개구부 위치 조정을 반영한 Rev.2가 3월 13일 월요일 16:00에 제출되었다.

**Shop DWG**는 시공을 위해 작성·검토하는 상세도를 뜻한다. 다만 실제 문서 명칭, 검토 결과의 종류와 사용 가능 상태는 프로젝트 문서에 따른다. 선행 장에서 배운 것처럼 **Activity**는 상태 변화를 판정하는 작업이고, **Constraint**는 그 작업의 착수·진행에 필요하지만 아직 충족되지 않은 조건이다.

작업조 책임자는 “Rev.2 제출이 끝났으니 도면 Constraint를 종결(Close)하고 3월 17일 07:00 착수를 확정해 달라”고 요청했다. 그러나 도면대장에는 Rev.2의 제출·접수만 표시되어 있다. B2 교육구간 β에 적용할 수 있는지, Rev.1을 계속 사용할 수 있는지, 누가 어떤 근거로 판단하는지는 표시되어 있지 않다.

이 문제의 판단 초점은 두 가지다.

1. **제출·접수와 실제 Constraint 해소를 구분한다.**
2. **날짜번호 차이·경과시간·작업일·작업시간·시계시각을 구분한다.**

## 제공 자료와 수치

| 항목 | 최초 제공 내용 |
|---|---|
| Activity 범위 | B2 교육구간 β 벽체 개구부 매립 프레임 18개소 설치 및 자체점검 |
| 현재 실적 | 설치 0개소, 잔량 18개소 |
| 포함 | 적용 도면에 따른 설치, 위치·누락 자체점검, 작업기록 정리 |
| 제외 | Shop DWG 작성·제출·검토, 프로젝트 절차상 공식 검사·확인·승인, 부적합 보완 |
| 시작조건 후보 | 해당 구간의 적용 개정과 사용 가능 상태 식별, 현장 반영, 작업면·자재·장비·안전조건 확보 |
| 계획 착수 | 2028년 3월 17일 금요일 07:00 |

| 현재 요청 | 제출 완료를 근거로 도면 Constraint를 Close해 달라는 요청 |

3월 14일과 17일의 **날짜번호 차이**는 17−14=3일이다. 그러나 상태시점인 3월 14일 10:00부터 계획 착수인 3월 17일 07:00까지의 실제 경과시간은 **2일 21시간, 즉 69시간**이다. 상태일 당일을 제외하고 착수 전에 온전히 사용할 수 있는 중간 작업일은 **3월 15일과 16일, 2작업일**이다. 날짜번호 차이 3을 곧바로 가용 작업일 3일로 사용하면 안 된다.

수량 단위는 **개소**, 기간 단위는 **작업시간**, 특정 시점을 나타내는 단위는 **시계시각**이다. 이 문제에서는 작업조(Crew) 수와 설치 생산성을 산정하지 않는다. 따라서 생산성 분모도 사용하지 않으며, 인원을 늘리면 도면 검토나 현장 반영시간이 자동으로 단축된다고 가정하지 않는다.

노무비, 연장근로비, 대기비, 재작업비, 지연비용, 계약상 보상 및 그 밖의 비용은 모두 제외한다. 따라서 추가 투입비나 EAC는 판단하지 않는다.

## 해설

### 1. 확인

설치 Activity의 물리적 범위와 도면 Constraint를 먼저 분리한다. 설치 Activity는 매립 프레임 18개소의 설치와 자체점검이다. Rev.2 제출은 이 설치 Activity의 착수나 완료 실적이 아니다.

다음 상태는 서로 다르다.

1. Rev.2가 제출·접수되었다.
2. Rev.1 또는 Rev.2 중 B2 교육구간 β에 사용할 개정이 확인되었다.
3. 그 도면이 프로젝트 절차상 사용 가능한 상태로 확인되었다.
4. 도면대장과 현장 사용본이 일치하고, 구본 식별과 작업자 전달까지 완료되었다.

현재 증빙은 첫 번째 상태만 보여 준다. 따라서 도면 Constraint를 Close할 수 없다. 다만 Rev.2가 반드시 사용되어야 한다고 확정하거나 Rev.1이 이미 무효라고 단정해서도 안 된다. 두 경우 모두 프로젝트 근거가 필요하다.

일반 현장 실무에서는 제출과 현장 사용 가능 상태를 구분한다. 구체적인 검토 결과 명칭, 승인 여부, 판단 역할과 권한은 프로젝트별 계약·도면관리·책임 절차에서 확인한다.

### 2. 계산

하루 순작업시간은 다음과 같다.

- 17시 − 7시 − 휴게 1시간 = **9작업시간/일**

상태일인 3월 14일 10:00 이후의 가용 작업시간은 다음과 같다.

- 17시 − 10시 − 휴게 1시간 = **6작업시간**

여기에 3월 15일과 16일의 순작업시간을 더하면 착수 전 이론상 가용 작업시간은 다음과 같다.

- 6시간 + 9시간 + 9시간 = **24작업시간**

이 24시간은 상태시점부터 작업할 조건이 이미 갖춰졌을 때의 달력상 가용시간이다. 도면 상태가 확인되지 않은 동안에는 현장 반영을 시작할 수 없으므로 24시간 전체를 실제 준비시간으로 사용할 수 있는 것은 아니다.

현장 반영에 연속 2작업시간이 필요하고 3월 16일 17:00까지 마쳐야 하므로, 적용 가능한 도면의 **확인 최종시각**은 다음과 같다.

- 17시 − 2시간 = **3월 16일 15:00**

여기서 계산값 15는 15시간의 기간이 아니라 **3월 16일의 시계시각 15:00**이다. 또한 이 시각은 프로젝트가 정한 공식 승인기한이나 상대방의 회신 확약시각이 아니다. 교육 사례에서 3월 17일 07:00 착수를 유지하기 위한 조건 충족 최종시각이다.

만약 확인이 3월 16일 16:00에 이루어지면 당일 종료까지 남은 연속 작업구간은 17−16=**1작업시간**이다. 필요한 2시간보다 1시간 부족하다. 연속 작업 조건이므로 16:00~17:00의 1시간을 다음 날 소요시간에서 공제할 수 없다.

다음으로 확보되는 연속 2작업시간은 3월 17일 07:00~09:00이다.

- 현장 반영 완료시각: 7시 + 2시간 = **09:00**
- 계획 착수 대비 지연: 9시 − 7시 = **2시간**

따라서 3월 16일 16:00에 도면 상태가 확인되었다면 가장 이른 설치 착수시각은 다른 시작조건도 충족된다는 전제에서 **3월 17일 09:00**이다.

### 3. 영향

- **잔량:** 전체 18개소 중 설치 실적이 0개소이므로 잔량은 18−0=**18개소**다.
- **생산성:** 작업조(Crew), 실제 설치시간과 생산성 분모가 없으므로 설치기간을 계산하지 않는다.
- **달력:** 날짜번호 차이 3일, 실제 경과 69시간, 온전한 중간 작업일 2일과 가용 작업시간 24시간을 구분해야 한다.
- **자원 충돌:** 원래 작업의 다른 조건은 충족된 것으로 가정했지만, 대체 작업면으로 바꾸려면 작업조·장비·동선 충돌을 새로 확인한다.
- **검측:** 도면 Constraint 해소는 공식 검사나 검측 완료를 뜻하지 않는다. 적용 절차는 프로젝트 문서에서 확인한다.
- **후속 Milestone:** 설치 완료 뒤 별도 확인 상태가 후속 작업의 필수조건이라면 기간 없는 상태표시인 Milestone 또는 별도 일정 통제 후보로 둔다. 실제 형식은 프로젝트 절차를 확인해 결정한다.

제출만으로 Constraint를 닫으면 적용 개정이 정해지지 않은 상태에서 설치할 수 있다. 반대로 Rev.2가 나올 때까지 무조건 대기하면, 근거상 Rev.1의 계속 사용이 가능한 경우 불필요한 지연을 만들 수 있다.

### 4. 대안

- **대안 A — Rev.2 제출을 근거로 즉시 Close:** 적용 개정과 사용 가능 상태가 입증되지 않으므로 채택할 수 없다.
- **대안 B — Rev.2 결과가 나올 때까지 무조건 보류:** 잘못된 개정 사용 위험은 낮추지만 Rev.1 사용 가능성을 확인하지 않은 과도한 보류가 될 수 있다.
- **대안 C — Rev.1 계속 사용 여부를 근거자료로 확인:** 프로젝트에서 지정한 역할과 자료로 계속 사용 가능함이 확인될 때만 조건부로 착수할 수 있다.
- **대안 D — 도면 Constraint를 유지하고 실제 해소시각으로 착수를 갱신:** 적용 개정 확인과 연속 2시간의 현장 반영이 끝난 뒤 Close한다.

| A. 제출 즉시 Close | 낮음 | 근거 없이 07:00 유지 | 실제 해소 증빙 없음 | 채택하지 않음 |
| B. Rev.2까지 무조건 대기 | 보수적이나 과도할 수 있음 | 불필요한 지연 가능 | Rev.1 사용 불가 근거 필요 | 조건부 |
| C. Rev.1 계속 사용 | 근거 확보 시 높음 | 07:00 유지 가능성 있음 | 적용 위치·사용 상태·판단 권한 확인 | 조건부 |
| D. Constraint 유지 | 높음 | 해소시각에 따라 07:00 또는 09:00 등으로 갱신 | 종결조건·증빙·확인 역할 지정 | 현재 우선안 |

**현재 판단:** Rev.2 제출만으로 도면 Constraint를 Close하지 않는다. 3월 17일 07:00 착수도 아직 확약하지 않는다. 적용 가능한 개정과 사용 가능 상태가 확인되고 연속 2작업시간의 현장 반영이 완료되어야 한다.

## 실행 및 재확인

1. Constraint 로그에 영향 Activity, 필요일시, 현재 상태, 요청 내용, 종결조건과 증빙을 기록한다.
2. 도면대장·송부기록·최신 도면관리 절차·책임분장에서 Rev.1과 Rev.2의 적용 상태와 판단 역할을 확인한다.
3. **3월 16일 15:00**을 교육 사례상의 조건 충족 최종시각으로 표시한다. 이를 상대방이 확약한 회신시각이나 대안 결정시한으로 바꾸어 기록하지 않는다.
4. 적용 개정이 확인되면 연속 2작업시간 동안 도면대장 갱신, 현장 사용본 확인, 구본 식별과 작업자 전달을 수행한다. 인원을 추가해 자동으로 단축하지 않는다.
5. 확인이 3월 16일 16:00이라면 16:00~17:00의 1시간을 다음 날에 이월한 것으로 처리하지 않는다. 3월 17일 07:00~09:00에 연속 작업을 수행하고, 완료 후 설치 착수 가능 여부를 다시 판정한다.
6. 대체 작업면을 검토한다면 해당 Activity의 도면·작업면·자재·장비·안전·품질조건과 공유자원 충돌을 모두 확인한다.
7. 일정을 맞추기 위해 안전조치, 도면 사용 상태 확인 또는 프로젝트에서 요구하는 품질 확인을 생략하지 않는다.

재확인은 다음 시점에 실시한다.

- **3월 16일 15:00:** 적용 개정 확인 여부와 연속 2시간 확보 가능 여부를 판단한다.
- **실제 사용 가능 상태 확인 시:** 적용 위치·개정·판단 근거와 확인 역할을 로그에 남긴다.
- **현장 반영 완료 시:** 도면대장, 현장 사용본, 구본 식별과 작업자 전달 상태를 현장에서 대조한다.
- **설치 착수 직전:** 작업면·자재·장비·안전조건과 프로젝트별 품질조건을 다시 확인한다.
- **18개소 설치 완료 보고 시:** 적용 도면 개정, 자체점검 기록, 미완료 사항과 후속 인계조건을 확인한다. 별도 검사·확인이 필요하면 그 상태가 확보되기 전에 후속 작업을 자동으로 풀지 않는다.

Constraint의 실제 해소일시는 제출일이 아니라 **적용 가능한 도면이 확인되고 현장 반영까지 완료된 시각**으로 기록한다. 실제 종결 역할과 권한은 프로젝트 책임체계에서 확인한다.

</details>

## 자기평가

- 제출·접수와 실제 사용 가능 상태를 구분했는가?
- Rev.2가 반드시 적용된다고 단정하거나 Rev.1이 계속 유효하다고 추정하지 않았는가?
- 날짜번호 차이 3일, 실제 경과 69시간, 온전한 중간 작업일 2일과 가용 작업시간 24시간을 구분했는가?
- 계산값 15를 기간이 아니라 3월 16일 15:00이라는 시계시각으로 해석했는가?
- 연속 2작업시간을 서로 다른 작업일의 1시간씩으로 잘못 합산하지 않았는가?
- 3월 16일 16:00 확인 시 완료시각 09:00, 계획 대비 지연 2시간을 계산했는가?
- 도면 Constraint 해소와 공식 검측 완료를 혼동하지 않았는가?
- 일정 유지를 위해 안전·품질·승인조건을 생략하지 않았는가?
