# A01-D03. 크레인 중복배차 — 1.5시간은 정말 여유인가

## 문제상황

기준 시점은 **2027년 4월 5일 월요일 12:00**이다. 가상 B2 지하 BOX의 관리구간 Z2에서 거푸집 패널 양중과 철근 하역이 4월 6일에 같은 크레인 1대와 공용 진입로를 요청했다. 공정담당자는 다음과 같이 제안했다.

> “두 작업이 합계 5.5시간이고 배정 가능시간은 7.0시간이므로 1.5시간 여유가 있습니다. 충돌을 없애기 위해 `거푸집 양중 → 철근 하역`을 FS로 연결하고 철근 시작을 13:00으로 고정하겠습니다.”

이 판단에는 두 가지 확인이 필요하다.

1. **같은 ‘시간’ 단위라도 산술 잔여시간과 Z2가 실제 사용할 수 있는 완충시간은 같은가?**
2. **15:30~16:00의 중복을 0.5시간과 30분 중 어떤 단위로 표시해도 같은 결과인가?**

이 문제의 주 학습목표는 위 두 가지 단위 판단이다. 선후관계와 실행조건은 계산 결과를 현장 결정으로 바꾸기 위한 최소 범위에서만 검토한다.

> **※ 아래 물량, 생산성, 인원, 비용 및 일정은 교육용 가정이다.**

적용 달력은 월요일부터 토요일까지 작업하고 일요일은 비작업일이며 공휴일은 없다. 주간 시간대는 08:00~17:00이고 12:00~13:00 점심시간은 비작업이므로 **명목 가용시간은 1작업일 8시간**이다.

4월 5일 월요일과 4월 6일 화요일은 포함 기준으로 2달력일이며 두 날짜 모두 작업일이다. 그러나 4월 5일 12:00부터 4월 6일 12:00까지의 경과 작업시간은 4월 5일 오후 4시간과 4월 6일 오전 4시간, 합계 8시간이다. 1작업일 8시간을 분모로 환산하면 **경과 1작업일**이다. 포함일수와 경과 작업일은 혼용하지 않는다.

검토 범위는 B2-Z2 두 작업, 같은 크레인을 사용하는 Z1 예약, 공용 진입로와 인접 동선이다. 시간 단위는 시간과 분을 사용한다. 물량당 생산성은 산정하지 않으며, 자원시간을 작업일로 환산할 때의 분모는 **크레인 1대·명목 가용 8시간/작업일**이다. 인원수는 제공되지 않았고 인원을 늘려 점유시간이 자동 단축된다고 가정하지 않는다.

비용은 산정하지 않는다. 추가 장비비, 추가 인력비, 대기비, 간접비, 세금, 금융비용, 지연 관련 비용과 계약상 지급 판단은 제외한다. 추가 장비 대안을 선택하려면 별도의 계약·비용 검토가 필요하다.

## 해설

### 1. 확인

먼저 8.0시간, 7.0시간과 Z2 완충시간의 범위를 구분한다. 8.0시간은 점심만 제외한 명목 가용시간이고, 7.0시간은 공통 점검과 공용 인계까지 제외한 **전체 작업 배정 가능시간**이다. 이 7.0시간에는 Z2뿐 아니라 Z1에 이미 예약된 시간도 포함되어 있다.

일반 현장 실무에서는 특정일의 장비 충돌만으로 영구 FS를 만들지 않는다. 물리·기술·안전·품질상 필수 순서가 확인되지 않았다면 일일 장비배치와 작업계획으로 우선 조정한다. 반대로 동시 배정도 허용되는 것은 아니다. 크레인 1대는 두 작업이 같은 시간에 함께 점유할 수 없으므로 시간 분리가 필요하다.

13:00은 최초에는 요청시각이다. 실제 착수를 위해서는 차량 도착, 게이트 확인, 대기위치 배치, 담당 인력, 동선 통제와 작업면 상태가 확인되어야 한다. 실행 결정과 날짜 Constraint 입력 권한은 프로젝트별 책임체계와 일정 운영기준에서 확인하며 임의로 확정하지 않는다.

### 2. 계산

주간 시간대는 08:00~17:00으로 9.0시간이다. 점심 1.0시간을 제외하면 명목 가용시간은 8.0시간이다. 공통 장비점검과 공용 인계는 각각 0.5시간이므로 공통업무는 합계 1.0시간이다.

- 전 구간 작업 배정 가능시간: 8.0 − 1.0 = **7.0시간**
- Z2 두 작업의 점유시간: 3.0 + 2.5 = **5.5시간**
- 산술 잔여시간: 7.0 − 5.5 = **1.5시간**
- Z1 예약시간: 17:00 − 15:30 = **1.5시간**
- Z2 실제 완충시간: 1.5 − 1.5 = **0시간**

따라서 계산 질문 1의 답은 **산술 잔여 1.5시간, Z2 실제 완충 0시간**이다. 산술 잔여 1.5시간은 이미 Z1에 예약되어 있으므로 Z2의 지연 흡수시간으로 사용할 수 없다.

역순 대안의 거푸집 시간은 13:00~16:00이고 Z1 예약은 15:30~17:00이다. 두 구간의 공통 부분은 15:30~16:00이다.

- 중복시간: **0.5시간**
- 분 환산: 0.5 × 60 = **30분**

0.5시간과 30분은 같은 기간이다. 다만 0.5를 ‘50분’으로 읽거나, 일정표의 15:30을 십진수 15.30시간으로 계산하면 안 된다. 계산에서는 15:30을 15.5시간으로 환산한다.

차량이 도착 상한인 12:40에 도착한다면 게이트 확인 10분과 대기위치 배치·착수 준비 10분, 합계 20분이 필요하다. 담당 인력과 동선 조건이 모두 확보되어야 13:00 착수가 가능하다.

날짜 환산에서는 4월 5일 12:00 이후 작업 가능시간 4시간과 4월 6일 12:00까지의 작업 가능시간 4시간을 합산한다. 8시간을 1작업일 8시간으로 나누면 상태시점부터 4월 6일 12:00까지 **1경과 작업일**이다.

### 3. 영향

산술 잔여시간을 실제 완충으로 잘못 판단하면 철근 또는 거푸집이 30분만 지연되어도 Z1 예약과 충돌한다는 사실을 놓친다. 현재 Z2 완충은 0시간이므로 차량, 인계 또는 작업 종료가 늦어지면 후속 배정을 다시 조정해야 한다.

일시적 충돌을 영구 FS로 입력하면 다른 날짜에도 두 작업이 불필요하게 직렬화될 수 있다. 반대로 관계를 입력하지 않았다는 이유로 같은 크레인을 동시에 배정하면 실행 불가능한 계획이 된다. 일정 논리와 일일 자원배정은 구분하되 서로 대조해야 한다.

인원을 늘려도 크레인 1대와 공용 진입로가 병목이면 3.0시간과 2.5시간이 자동으로 줄어들지 않는다. 안전·품질 확인이나 프로젝트별 실행 결정을 생략해 15:30 인계를 맞추는 것도 대안이 아니다.

### 4. 대안

- **A1. 거푸집 후 철근:** 08:30~11:30 거푸집, 11:30~12:00 공용 인계, 13:00~15:30 철근으로 배정한다. 산술상 가능하지만 Z2 완충은 0시간이다. 차량 도착, 점심시간 대응 인력과 동선 통제가 확인될 때만 실행할 수 있다.
- **A2. 철근 후 거푸집:** 거푸집을 13:00~16:00에 배정하면 Z1 예약과 30분 중복된다. Z1 예약 변경이 결정되지 않았으므로 현재 실행할 수 없다.
- **B. 추가 크레인 검토:** 장비가 늘어도 작업반경, 진입로, 작업면, 운영인력과 위험 영향권이 분리되지 않으면 동시작업이 가능하다고 볼 수 없다. 기술·안전·품질·계약·비용 검토 전에는 보류한다.
- **C. 반입 또는 다른 작업으로 전환:** 대체 적치면이나 전환 Activity의 위치, 시작조건, 적용 자료, 작업조, 장비와 안전·품질 조건이 확인된 경우에만 실행안이 된다.

|---|---|---|---|
| A1 | Z2 완충 0시간, 15:30 Z1 인계 | 차량 단계별 준비, 점심 담당 인력, 동선 통제 확인 | **조건부 권고**, 실행 확정 아님 |
| A2 | Z1과 0.5시간 또는 30분 중복 | Z1 예약 변경과 후속 영향 결정 필요 | 현재 제외 |
| B | 단순 시간 합계만으로 효과 판단 불가 | 작업반경·진입로·인력·계약·비용 검토 | 확인 전 보류 |
| C | 후보에 따라 재계산 필요 | 실제 실행 가능한 위치 또는 Activity 확인 | 후보 확인 전 보류 |

현재 판단은 A1을 **4월 6일에 한정된 조건부 자원배정안**으로 관리하는 것이다. 물리·기술상 선후관계가 확인되지 않았으므로 영구 FS로 확정하지 않는다. 13:00 역시 모든 착수조건과 프로젝트별 실행 결정이 확인되기 전에는 고정 Constraint로 간주하지 않는다.

## 실행 및 재확인

### 6. 실행

1. 일일 장비배치표에 A1 시간대와 **Z2 완충 0시간**을 표시한다.
2. 관계대장에는 ‘4월 6일 공유 크레인 충돌, 물리·기술 FS 근거 미확인’으로 기록한다.
3. 철근 반입조건을 `12:40까지 도착 → 12:50까지 게이트 확인 → 13:00까지 지정 대기위치 배치·착수 준비`로 구분한다.
4. 점심시간 대응 인력이나 동선 통제가 미확정이면 13:00 착수를 확정하지 않는다.
5. 하역 완료는 자재 식별·지정 적치·통로 인계 범위로 관리하고, 후속 설치 가능 여부와 구분한다.
6. 공정담당자의 조건부 권고와 프로젝트 절차상 실행 결정·승인을 같은 것으로 기록하지 않는다.

### 7. 재확인

- **4월 5일 17:00:** 점심시간 대응 인력, 일일계획 반영 여부, 전환 후보와 프로젝트별 결정 역할을 확인한다.
- **4월 6일 07:00:** 차량 출발·예상 도착, 크레인 상태, 작업면과 동선 통제조건을 다시 확인한다.
- **08:30:** 거푸집 실제 착수와 잔여 3.0시간을 갱신한다.
- **11:30:** 거푸집 완료, 통로 정리와 크레인 구역 해제를 확인한다. 미완료이면 완충 0시간 조건으로 전체 배정을 다시 계산한다.
- **12:40·12:50·13:00:** 차량 도착, 게이트 확인, 대기위치 배치·착수 준비를 각각 분리해 확인한다.
- **15:30:** 철근 하역 완료범위와 Z1 인계를 확인한다. 안전·품질 조건을 생략해 시간을 맞추지 않는다.
- **작업 종료 후:** 계획과 실제 도착·대기·가동·완료시간을 비교한다. 동일 충돌이 반복되면 영구 논리 후보인지 다시 검토하되 근거 없이 FS를 추가하지 않는다.

## 자기평가

각 항목에 ‘예/아니오’로 답한다.

- 8.0시간, 7.0시간, 1.5시간과 0시간의 범위를 구분했는가?
- 산술 잔여 1.5시간에서 Z1 예약 1.5시간을 차감했는가?
- Z2 실제 완충시간을 0시간으로 판단했는가?
- 15:30~16:00을 0.5시간이자 30분으로 올바르게 환산했는가?
- 15:30을 십진수 계산에서 15.5시간으로 처리했는가?
- 포함 2달력일과 경과 1작업일을 구분했는가?
- 일시적 자원 충돌과 영구 선후관계를 구분했는가?
- 요청시각 13:00을 착수 확정이나 날짜 Constraint로 단정하지 않았는가?
- 인원·장비 증가를 점유시간 단축으로 자동 환산하지 않았는가?
- 안전·품질·프로젝트별 결정 절차를 생략하지 않는 재확인 계획을 세웠는가?

**판단문:** 배정 가능시간에서 Z2 작업만 차감하면 1.5시간이 남지만, 그 시간은 Z1에 이미 예약되어 있다. 따라서 **Z2 실제 완충은 0시간**이다. 역순안은 Z1과 **0.5시간, 즉 30분** 중복되므로 현재 실행할 수 없다.
