# A01-D04. 작업면 미확보 — 66시간과 60%의 단위를 구분하라

## 문제상황

2027년 5월 14일 금요일 13:00, 공정계획 담당자는 **B2 지하 BOX 벽체 작업구간**의 후속 작업 착수 가능 여부를 확인하고 있다.

후속 작업의 계획 착수는 5월 17일 월요일 07:00이다. 선행 담당자는 “아직 66시간 남았고, 서측 60 m는 끝났으니 60%는 넘길 수 있다”고 설명했다. 그러나 현장 게시판에는 서측 구간이 단순히 ‘정리 완료’로 표시돼 있을 뿐, 후속 담당자와 대조한 인계기록은 보이지 않는다.

현재 확인된 WBS 사전에서는 전체 길이 100 m가 하나의 말단 WBS이자 하나의 인계 범위다. 서측 60 m와 나머지 구간을 별도 구조 경계나 독립 인계 범위로 나눈 근거는 확인되지 않았다.

이번 문제의 필수 판단은 두 가지다.

1. **66시간은 실제 작업 가능시간인가, 달력 경과시간인가?**
2. **60%는 진도율 또는 작업면 인계율인가, 단순 길이 비율인가?**

## 해설

### 1. 확인

먼저 숫자보다 **숫자의 단위와 분모**를 확인한다.

시간에는 서로 다른 의미가 있다.

- **달력 경과시간:** 두 시점 사이에 시계상 흐르는 전체 시간
- **작업일:** 적용 달력에서 작업하도록 정한 날
- **계획 가용시간:** 해당 Crew가 실제로 배치된 시간대에서 휴게를 제외한 시간
- **순가동시간:** 계획 가용시간 중 대기와 작업중단을 제외하고 실제 작업한 시간

따라서 “66시간 남았다”는 말만으로 66시간을 작업에 사용할 수 있다고 판단할 수 없다. 금요일 야간과 일요일 휴무가 포함돼 있기 때문이다. 야간·휴일작업을 별도로 확인하지 않은 상태에서 이를 작업시간으로 바꾸면 안 된다.

퍼센트도 분자와 분모를 확인해야 한다.

- 서측 60 m ÷ 전체 100 m는 **길이 비율**이다.
- 진도율은 확인된 진도 측정기준과 완료기준을 충족한 결과물을 분자로 삼아야 한다.
- 작업면 인계율은 실제 사용할 수 있도록 독립 인계된 범위와 증빙을 분자로 삼아야 한다.

현장 게시판의 ‘정리 완료’ 표시는 위치 상태를 알려 주지만, 결과물 완료나 공식 인계까지 자동으로 증명하지 않는다.

### 2. 계산

기준시점부터 계획 착수까지의 달력 경과시간은 다음과 같다.

- 금요일 13:00~24:00: 11시간
- 토요일: 24시간
- 일요일: 24시간
- 월요일 00:00~07:00: 7시간
- 합계: 11 + 24 + 24 + 7 = **66시간**

이 기간에 온전히 포함되는 작업일은 토요일 **1작업일**이다. 일요일은 휴무이고, 금요일은 기준시점 이후 일부 시간만 남아 있다. 월요일은 계획 착수가 07:00이므로 착수 전 온전한 작업일에 포함되지 않는다.

선행 정리 Crew의 계획 가용시간은 다음과 같다.

- 금요일 14:00~17:00: 3시간
- 토요일 07:00~12:00: 5시간
- 토요일 13:00~17:00: 4시간
- 합계: 3 + 5 + 4 = **12시간**

12시간도 실제 순가동시간은 아니다. 자재 대기, 접근 제한, 장비 충돌 또는 다른 작업중단이 발생하면 실제 순가동시간은 다시 확인해야 한다.

서측 표시 길이의 비율은 다음과 같다.

- 60 m ÷ 100 m × 100 = **60%**

계산값은 맞지만 명칭은 **서측 표시 길이 비율 60%**다. 현재 자료만으로는 진도율 60% 또는 작업면 인계율 60%라고 바꿔 부를 수 없다.

### 3. 영향

- **달력 판단:** 66시간을 모두 작업시간으로 사용하면 휴무와 비배치 시간을 작업 가능시간으로 잘못 포함한다.
- **작업면 판단:** 서측이 깨끗해 보여도 접근, 장애물, 인계조건과 후속 담당자의 확인이 남아 있으면 착수 가능 작업면이라고 단정할 수 없다.
- **WBS 판단:** 서측과 나머지 구간의 준비상태가 다르다는 이유만으로 WBS 경계나 구조 경계를 새로 만들 수 없다.
- **진도 판단:** 길이 1 m마다 작업량과 완료 가중치가 같다는 기준이 없다면 길이 비율을 진도율로 사용할 수 없다.
- **후속 일정:** 월요일 07:00 착수 판단은 66시간이나 60%라는 숫자가 아니라, 착수 직전 실제 작업면과 프로젝트별 시작조건을 대조해 내려야 한다.

### 4. 대안

1. **66시간을 작업 가능시간, 60%를 진도율로 입력한다.**
   계산 숫자만 보고 단위와 완료기준을 바꾸는 방법이므로 제외한다.

2. **66시간은 달력 경과시간, 12시간은 Crew 계획 가용시간, 60%는 길이 비율로 각각 분리해 기록한다.**
   서로 다른 수치를 같은 명칭으로 혼합하지 않으므로 우선 적용할 수 있다.

3. **서측이 독립 인계 가능하다고 가정해 WBS를 즉시 분할한다.**
   확인된 구조 경계·시공구획·인계 근거가 없으므로 보류한다.

4. **완료기준과 독립 인계 근거를 추가 확인한 뒤 60%의 용도를 다시 판단한다.**
   확인 결과에 따라 조건부로 진도 또는 인계 지표에 사용할 수 있다. 다만 프로젝트별 측정기준과 확인 절차를 따라야 한다.

조건부 판단은 다음과 같다.

- 확인된 진도 측정기준이 길이 기준이고 서측 60 m가 동일한 완료기준을 충족했다면, 그때 진도 계상 가능 여부를 다시 판단한다.
- 서측이 확인된 독립 인계 범위이고 필요한 현장 상태와 증빙을 갖췄다면, 그때 부분 인계 가능 여부를 판단한다.
- 기준·증빙·확인 역할 중 하나라도 미확정이면 60%는 길이 비율로만 유지한다.

재확인 후에도 **달력 경과시간, 계획 가용시간, 순가동시간을 같은 ‘시간’으로 합치지 않는다.** 또한 길이 비율을 진도율이나 인계율로 바꿀 때는 분자·분모와 완료기준을 함께 기록한다.

## 자기평가

- [ ] 66시간을 달력 경과시간으로 분류했는가?
- [ ] 계획 착수 전 온전한 작업일이 토요일 1작업일임을 확인했는가?
- [ ] Crew 계획 가용시간 12시간과 실제 순가동시간을 구분했는가?
- [ ] 60%의 분자가 완료 결과물이 아니라 길이 60 m임을 확인했는가?
- [ ] ‘정리 완료’ 표시만으로 작업면 인계 완료를 판정하지 않았는가?
- [ ] 준비상태 차이만으로 WBS를 분할하지 않았는가?
- [ ] 진도율 또는 인계율로 전환할 때 필요한 기준과 증빙을 질문했는가?
- [ ] 안전·품질·승인 또는 프로젝트별 확인 절차를 생략해 일정을 맞추지 않았는가?
