## 문제상황

※ 아래 물량, 생산성, 인원, 비용 및 일정은 교육용 가정이다.

상태시점은 **2027년 5월 10일 월요일 16:00**이다. 달력은 월요일~토요일 작업, 일요일 휴무이며 해당 기간에 별도 휴일은 없다. 주간 작업시간은 07:00~17:00, 휴게시간은 12:00~13:00이다. 야간·연장작업은 가정하지 않는다.

대상 범위는 **B2-Z3 벽체 철근 100㎡**이다. 6명으로 구성된 Crew 하나가 작업한다. 생산성 분모는 개인별 인시가 아니라 **Crew 전체의 실제 가동 1시간**이다. 인원을 늘려도 생산성이 자동으로 비례하여 증가한다고 보지 않는다.

비용은 산정하지 않는다. 추가 투입비, 대기비, 재작업비, 지연비용, 잔여원가, EAC 및 계약상 보상 여부는 모두 제외한다.

상세공정표에는 다음 두 Activity가 직접 연결되어 있다.

- B2-Z3 벽체 철근 조립·자체점검·검사 실시용 자료 준비

그러나 두 Activity 사이에 프로젝트 절차상 요구될 수 있는 공식 검측 상태가 표시되어 있지 않다. 작업일보에는 **“검측 요청 발송”**이라고만 적혀 있다.

계획담당자는 5월 12일 07:00 거푸집 착수를 유지할 수 있는지 판단해야 한다. 이 문제의 핵심 단위 판단은 다음 두 가지다.

1. **경과시간과 Crew 가동시간을 구분한다.**
2. **잔여 작업시간과 Milestone 완료 지연시간을 구분한다.**

## 해설

### 1. 확인

5월 10일 15:30에 발송한 것은 **검사 일정 편성 요청**이다. 정식 검사 실시 요청, 실제 검사, 결과 기록, 다음 단계 진행 가능 확인과는 서로 다른 상태다.

일반 현장 실무에서는 요청·실시·결과·후속 진행 가능 상태를 구분해 기록한다. 그러나 정식 문서명, 제출기한, 검사방법, 결과 확인 역할과 승인 권한은 프로젝트별 절차에서 확인해야 한다.

철근 Activity의 완료조건은 조립뿐 아니라 자체점검·발견사항 해소·검사 실시용 자료 준비까지다. 공식 검측 결과는 제외되어 있으므로 철근 진도 100%가 거푸집 착수 허용을 의미하지 않는다.

따라서 **현재 정보만으로 5월 12일 07:00 착수를 확약할 수 없다.** 물리적 작업 완료 전망뿐 아니라 정식 검사 요청조건, 검사 소요, 결과 확인시각, Crew 배정과 나머지 착수조건을 확인해야 한다.

### 2. 계산

#### 핵심 판단 1 — 경과시간과 Crew 가동시간

5월 10일 07:00~16:00의 경과시간은 **16−7=9경과시간**이다. 여기서 휴게 1시간과 휴게시간 밖에서 발생한 자재 대기 1시간을 제외하면 실제 Crew 가동시간은 **9−1−1=7 Crew 가동시간**이다.

동일 관찰기간의 신규 조립 완료량은 **70−0=70㎡**이다. 관측 생산성은 **70÷7=10㎡/Crew 가동시간**이다. 이 값은 해당 Crew와 해당 관찰기간의 시험값이며 정상 생산성 기준이나 개인별 인시 생산성이 아니다.

잔량은 **100−70=30㎡**이다. 같은 Crew와 작업조건이 유지된다는 조건에서 잔량 조립에는 **30÷10=3작업시간**이 필요하다.

5월 10일 정상 작업시간은 16:00~17:00의 1시간이 남아 있다. 이 시간에 대기 없이 같은 생산성이 유지된다는 조건에서 다음 작업일에 필요한 조립시간은 **3−1=2작업시간**이다. 따라서 5월 11일 07:00 재개 시 조립 완료 전망은 09:00이다.

이 계산은 전망일 뿐이다. 5월 10일 17:00에 실제 추가 완료량, 가동시간과 대기 사유를 확인한 뒤 다시 계산해야 한다.

조립 완료 후 자체점검·발견사항 해소·검사 실시용 자료 준비에 2작업시간이 필요하므로 철근 Activity 완료 전망은 **09:00+2시간=11:00**이다.

#### 보조 일정 계산 — 잠정 검사창

철근 Activity 완료 전망 11:00부터 잠정 검사창 시작 14:00까지는 **3경과시간**이다. 이는 Crew 생산성 시간이 아니라 검사 대기 가능 시간이다.

정식 요청이 접수되고, 14:00에 검사를 시작하며, 검사와 결과 기록 및 다음 단계 진행 가능 확인까지 총 1경과시간이 걸린다는 민감도 조건에서는 해소 후보시각이 **15:00**이다. 실제 소요와 결과 확인시각이 확인되지 않으면 해소시각은 계속 미확정이다.

### 3. 영향

#### 조건 ① 요구 상태 충족

- 철근 조립 완료 전망: 5월 11일 09:00
- 자체점검·발견사항 해소·검사 자료 준비 완료 전망: 5월 11일 11:00
- 정식 검사 요청조건 회신시한: 5월 11일 11:30
- 조건부 검사: 5월 11일 14:00~15:00
- 조건부 진행 가능 상태 확인: 5월 11일 15:00
- 거푸집 닫기: 나머지 시작조건 확인 후 5월 12일 07:00 착수

거푸집 작업은 5작업시간이므로 07:00에 착수하면 **휴게 시작시각인 12:00에 완료**한다. 다른 미결사항이 없다면 5월 13일 09:00 Milestone을 유지할 수 있다.

검측 후 5월 11일 15:00~17:00에 시간이 남더라도 거푸집 Crew가 배정되었다는 자료는 없다. 남은 시간을 자동으로 거푸집 조기 착수시간으로 바꾸지 않는다.

#### 조건 ② 2작업시간 보완과 다음 검사창 재확인

이는 확정 결과가 아니라 일정 민감도 조건이다. 5월 11일 15:00부터 2작업시간을 보완하면 17:00에 끝난다. 다음 검사창이 5월 12일 14:00~15:00으로 확인되면 5월 12일 오전 거푸집 Crew 시간대를 놓친다.

다음 Crew 사용 가능시점은 5월 13일 07:00으로, 기존 착수일보다 1작업일 늦다.

#### 핵심 판단 2 — 잔여 작업시간과 Milestone 완료 지연시간

5월 13일 07:00에 거푸집 작업을 시작하면 09:00 Milestone까지 사용할 수 있는 시간은 **2작업시간**이다. 총 5작업시간 중 2시간을 수행했으므로 09:00 현재 잔여 작업시간은 **5−2=3작업시간**이다.

같은 날 07:00부터 5작업시간을 수행하면 완료 전망은 12:00이다. Milestone 요구시각 09:00보다 **12−9=3경과시간 늦다.**

이 사례에서는 두 값이 모두 3이지만 단위와 의미가 다르다.

- **3작업시간:** 09:00 현재 앞으로 수행해야 할 작업량의 시간 환산값
- **3경과시간:** 완료 전망 12:00이 Milestone 09:00보다 늦은 시각 차이

### 4. 대안 비교

#### 대안 A — 현재 공정표를 유지하고 작업일보 메모로만 관리

철근 Activity 완료 직후 거푸집을 시작할 수 있는 것처럼 보인다. 일정 편성 요청, 정식 요청, 검사 실시, 결과 확인과 보완 가능성이 공정망에 드러나지 않는다.

#### 대안 B — 공식 검측 결과를 철근 Activity 완료조건에 모두 포함

항목 수는 늘지 않지만 물리적 작업 완료와 검사 대기·결과 상태가 한 Activity에 섞인다. 담당 역할, 증빙과 완료시각을 독립적으로 갱신하기 어렵다.

#### 대안 C — 검측 Activity 후보와 진행 가능 Milestone을 분리

잠정 검사창을 별도 검측 Activity 후보로 표시하고, 프로젝트 절차상 다음 단계 진행 가능 상태를 기간 없는 Milestone 후보로 표시한다. 거푸집은 그 상태 이후에만 착수하도록 연결한다.

| 비교항목 | 대안 A | 대안 B | 대안 C |
|---|---|---|---|
| 검사 대기시간 표시 | 어려움 | 철근 기간에 숨을 수 있음 | 별도 표시 가능 |
| 요청과 실제 해소 구분 | 어려움 | 부분 가능 | 명확함 |
| Crew 시간대 영향 확인 | 어려움 | 제한적 | 선행논리로 확인 가능 |
| 결과 미확정 상태 갱신 | 메모 의존 | 철근 완료판정과 충돌 | 조건부 상태로 관리 가능 |

이 교육 사례에서는 **대안 C가 적절하다.** 검사에 독립된 시간창이 있고, 결과가 거푸집 Crew 사용시점과 후속 Milestone을 바꿀 수 있기 때문이다.

다만 검측 Activity와 Milestone의 정식 명칭, 정식 요청 문서, 결과 확인 역할과 완료 권한은 프로젝트 절차와 책임체계에서 확인한다. 확인 전에는 후보 상태로 관리한다.

## 실행 및 재확인

1. 작업일보의 “검측 요청 발송”을 근거 문서에 맞춰 “검사 일정 편성 요청 발송”으로 구체화한다.
2. 철근 Activity 완료조건을 조립·자체점검·발견사항 해소·검사 실시용 자료 준비로 통일한다.
3. **5월 10일 17:00**에 16:00~17:00 실제 가동시간, 추가 완료량, 대기 사유와 잔량을 대조한다. 결과에 따라 5월 11일 09:00 및 11:00 전망을 갱신한다.
4. **5월 11일 11:00**에 실제 조립 잔량, 자체점검 결과, 발견사항 해소와 검사 자료 준비 상태를 확인한다.
5. **5월 11일 11:30까지** 정식 검사 요청의 제출시점·필수자료·접수 여부, 14:00 검사창의 유효성, 예상 검사시간과 결과 확인 가능시각을 확인한다.
6. 확인되지 않으면 14:00 검사를 확정 Activity로 표시하지 않고 5월 12일 07:00 착수도 확약하지 않는다.
7. 검사가 실시되더라도 결과 기록과 다음 단계 진행 가능 상태를 프로젝트 지정 역할이 확인할 때까지 Milestone을 완료 처리하지 않는다.
8. 보완이 필요하면 보완시간, 다음 검사창, 거푸집 Crew의 다음 사용 가능시점과 5월 13일 Milestone 영향을 함께 갱신한다.
9. 거푸집 착수 직전에는 적용 도면, 자재 사용 가능 상태, 장비·접근조건, 작업면 인계, 프로젝트별 안전조치와 검측 상태를 현장에서 다시 확인한다.
10. 거푸집 닫기 완료 후 실제 완료 위치·시각, 적용 도면 식별정보, 검측 결과와 남은 미결사항을 후속 담당 역할에 인계한다.
