# A01-9. 계획과 실제가 달라졌을 때 어떻게 갱신하고 재계획하는가

## Level 1. 핵심 정의

**상태일(Data Date)**은 실제 실적과 미래 전망을 나누는 기준시점이다. **기준계획(Baseline)**은 차이를 측정하는 비교 기준이므로 현재 전망으로 덮어쓰지 않는다. **Recovery**는 목표 회복을 위한 조건부 실행안이며, 물리적 작업의 단축과 Activity 전체 완료 및 B2 전체 완료 개선은 구분한다.

## Level 2. 실제 업무 장면

2026년 10월 14일 수요일 07:00, 공정담당자가 B2-Z2 BOX 본체 거푸집 조립 Activity를 갱신한다. **Activity**는 일정에서 착수·진행·완료를 관리하는 작업 단위다. 상태일은 **2026년 10월 14일 00:00**으로 고정하며, 실제 실적 마감은 10월 13일 작업 종료다. 따라서 10월 13일까지는 실제, 10월 14일부터는 전망이다.

기준계획에는 10월 12~15일 작업으로 표시됐지만 작업일보에는 10월 12일 0㎡, 10월 13일 28㎡가 기록돼 있다. 공정 막대를 옮기기 전에 28㎡의 계상 가능 여부, 날짜별 차이의 원인, 잔여 작업에서의 재발 가능성, 검측·인계조건을 따로 밝혀야 한다. **검측**은 시공 상태를 프로젝트 요구사항과 대조하는 검사이며, 요청·실시·완료는 서로 다른 상태다.

> ※ 아래 물량, 생산성, 인원, 비용 및 일정은 교육용 가정이다.
>
> 범위는 B2-Z2 거푸집 조립 120㎡, 기존 Crew(한 작업조)는 6명이다. 달력은 월~토 작업, 일요일 비작업이며 작업시간대는 08:00~17:00이다. 생산성 분모는 Crew 1개 조가 휴게·준비·대기·중단을 제외한 순가동 6.5시간을 확보한 1가동일이다. 야간작업은 제외한다. 금액은 산정하지 않았으며 임금, 할증, 최소 지급단위, 장비·관리비, 전환손실, 원구간 대체인력, 간접비와 재작업비는 제외한다. 기존 CASE의 수치와는 무관하다.

## 최초 제공 정보와 질문 후 확보한 답

07:10 최초 자료는 교육용 기준계획 V1, 작업일보 초안과 “작업면 인계가 늦었다”는 구두 설명뿐이었다. 28㎡의 측정 경계와 완료상태가 없어 잠정 실적이었다.

09:30 현장 표시도·사진·일보에서 설치 위치와 수량 표시가 일치함을 확인했다. 10:30 Activity 정의서 Rev.1에서 정해진 구획에 조립·고정되고 위치별 식별이 가능한 물량만 계상하며, 반입·임시 배치·고정 미완료·재작업 표시분은 제외한다는 기준을 읽었다. 이에 따라 28㎡를 **물리적 진행실적**으로 확정했다. 다만 필요한 검측과 후속 인계가 끝났다는 증빙은 확보되지 않았으므로 Activity 전체 완료일은 아직 산정할 수 없다.

| 날짜 | 위치 | 완료량·완료기준 | Crew | 실제 순가동 | 대기·미가동 사유 |
|---|---|---|---:|---:|---|
| 2026-10-12 | B2-Z2 | 0㎡, 생산 없음 | 6명 | 0.0시간 | 작업면 인계 15:40 |
| 2026-10-13 | B2-Z2 | 28㎡, Rev.1 계상기준과 표시도·사진·일보 일치 | 6명 | 6.5시간 | 준비·내부 작업면 조정, 세부 시간 미분류 |

## Input과 자료의 어느 칸·개정·기간·범위를 읽는가

- **기준계획 V1·직전 갱신본:** 버전, 상태일, Activity ID, B2-Z2 범위, 기준·실제 시작일, 기준·전망 완료일, 잔여기간, 달력, 선후관계와 날짜 Constraint를 읽는다. 비교기간은 10월 12일부터 13일 작업 종료까지다.
- **Activity 정의서 Rev.1·도면대장:** 물량 계상상태, 측정 경계, 제외 범위, 적용 도면번호·Rev.와 위치를 읽는다. 교육용 도면대장의 Rev.C가 실제 사용 가능한 개정인지는 배포기록으로 별도 확인한다.
- **작업일보·사진·표시도:** 날짜, 위치, 완료량, Crew, 총 투입시간, 순가동시간과 대기 사유를 같은 구획으로 맞춘다.
- **Constraint 로그·조달자료:** 필요일, 요청일, 확약일, 날짜가 출하·도착·인수·사용 가능 중 무엇인지, 실제 해소상태와 증빙을 읽는다. **Constraint**는 선행작업이 끝나도 착수·진행을 막는 미충족 조건이다.
- **프로젝트별 품질계획·검측 또는 인계기준:** 최신 적용 개정과 기간을 확인하고 대상 Activity·위치, 요청 여부, 필요일, 확인 가능 시간, 실제 확인상태, 완료 증빙과 후속 인계 대상을 읽는다. 문서 명칭, 검사빈도와 확인·승인 권한은 프로젝트 문서에서 확인하며 보편값으로 만들지 않는다.
- **자원·비용·결정 자료:** Crew 배치표에서 추가 인력의 원구간·역할·가용시점을, 작업계획과 안전자료에서 작업면·동선·동시작업 조건을 읽는다. 임금·할증·최소 지급단위·대체인력·전환손실은 비용 담당 자료로 확인한다. 실행 결정권은 프로젝트 책임체계에서 찾는다.

## 담당자의 실제 업무순서와 이유

### 1. 상태와 실적을 먼저 고정한다

상태일을 10월 14일 00:00으로 고정하고 14일 진행 중 물량은 실적에 섞지 않는다. 실제 시작일은 10월 13일로 입력하되 기준 시작일 10월 12일은 보존한다. 기준 확인 전의 28㎡는 잠정값, 확인 후의 28㎡는 물리적 진행실적으로 구분한다.

### 2. 차이·원인·영향을 날짜별로 나눈다

| 날짜 | 계획 | 실제 | 차이 | 확인된 사실 | 남은 질문과 영향 |
|---|---:|---:|---:|---|---|
| 10월 12일 | 30㎡ | 0㎡ | -30㎡ | 작업면 인계 15:40, 미가동 | 작업면은 다음 날 열렸지만 발생한 일정 영향은 남음 |
| 10월 13일 | 30㎡ | 28㎡ | -2㎡ | 순가동 6.5시간 | 준비·조정시간의 재발 여부에 따라 잔여기간 변경 |

공정담당자는 파트너사 작업책임자와 공사담당자에게 대기시간 구분과 14일 재발 가능성을 12:00까지 요청한다. 품질담당자에게는 적용 품질계획, 검측 요청상태, 확인 가능 시간과 완료 증빙을 11:30까지 요청하고, 공사담당자에게는 후속 인계 가능 판정을 14:00까지 요청한다.

### 3. 핵심 숫자를 계산하되 계산 범위를 표시한다

| 항목 | 입력·식·단위 | 결과와 해석 |
|---|---|---|
| 기준기간 | 10월 12~15일 포함, 1+1+1+1 | 4달력일이자 4작업일 |
| 균등 계획량 | 120㎡ ÷ 4작업일 | 30㎡/작업일 |
| 상태일 계획·실제 | 계획 30×2, 실제 0+28 | 60㎡ 대 28㎡, 차이 -32㎡ |
| 진도 | 실제 28÷120×100, 계획 60÷120×100 | 23.3% 대 50.0%. 기간 지연률을 뜻하지 않음 |
| 잔여물량 | 120-28 | 92㎡ |
| 관측 생산성 | 28÷1, 28÷6.5 | 28㎡/가동일, 약 4.31㎡/가동시간. 하루 관측값이며 정상 판정 기준이 아님 |
| 현행 잔여기간 | 92÷28을 올림 | 4가동일 |
| 현행 일별 부하 | 28+28+28+8 | 92㎡, 마지막 날 계획량 8㎡ |

현행 6명 조건이 유지되면 **물리적 조립 종료전망**은 10월 17일이며 기준 물리적 종료일보다 2작업일 늦다. 검측·인계의 가능일과 완료 증빙이 없으므로 Activity 전체 완료전망은 산정 보류한다.

### 4. 잔여 논리와 품질·후속 Constraint를 다시 연결한다

| 확인항목 | 상태일 현재 상태 | 확인 역할·회신시한 |
|---|---|---|
| 직접 후속 Activity와 관계 | 전체·부분 인계 여부 미확인 | 공사·공정담당, 14:00 |
| 검측 요청·필요일 | 미확인 | 품질담당, 11:30 |

| 완료 증빙·후속 착수 판정 | 미확인 | 프로젝트 절차상 담당 역할 확인, 14:00 |

| 추가 인력의 원구간·공유 장비 | 미확인 | 파트너사·공사담당, 14:00 |

후속 작업이 물리적 조립 완료와 자재 사용 가능을 모두 요구한다고만 가정하면 현행안과 Recovery안의 후속 이른 착수일은 모두 10월 19일이다. 후속 착수 개선은 0일이다. 여기에 미확인 검측·인계조건을 반영하면 더 늦어질 수 있으므로 이 값은 공식 완료전망이 아닌 제한된 조건시험이다.

### 5. 확장 분석: 현행안과 조건부 Recovery 비교

8명안의 33㎡/가동일은 **8명 통합 Crew 1개 조가 순가동 6.5시간을 확보한 1가동일**을 분모로 한 교육용 민감도 시험값이다. 유사 실적이나 승인된 작업계획으로 입증된 값이 아니며 B2-Z2의 동일 작업면에만 시험 적용한다. 10월 14일 28㎡ 시공 후 잔여 64㎡를 33㎡/가동일로 계산하면 10월 15일 33㎡, 16일 31㎡로 물리적 조립을 끝내는 시험 결과가 나온다.

| 비교항목 | 현행 6명안 | 조건부 8명안 |
|---|---|---|
| 물리적 조립 종료 | 10월 17일 | 민감도상 10월 16일 |
| Activity 전체 완료 | 검측·인계 미확인으로 산정 보류 | 동일하게 산정 보류 |
| 후속·B2 영향 | 최신 논리망 확인 필요 | 제한된 10월 19일 조건시험에서는 개선 0일 |
| 원구간 영향 | 없음 | 추가 2명의 원구간 잔여기간 재계산 필요 |
| 생산성·병목 | 28㎡/가동일 하루 관측 | 33㎡/가동일은 미입증 시험값. 역할 구성·공급·장비 병목 확인 필요 |
| 안전조건 | 현행 작업면·동선 재확인 | 작업면 수용성, 출입·양중 동선, 동시작업 간섭을 작업계획·현장 관찰·안전자료로 확인 |
| 품질조건 | 검측 가능 시간·증빙 미확인 | 인원 증가에 따른 작업구획·검측 영향과 인계 가능 시간을 품질계획으로 확인 |
| 자원·비용 | 10월 17일 6명 투입 가능성 | 추가 노출 2명×2일=4인·작업일, 10월 17일 6인·작업일 회피 가능성은 있으나 금액 효과 미확정 |
| 결정자료 | 현행 조건 유지 여부 | Crew 배치표, 원구간 재계산, 안전·품질 확인, 비용자료, 책임체계 |
| 결정시한·전환안 | 조건 유지 시 계속 | 10월 14일 15:00까지 미충족이면 보류하고 6명안 유지 |

추가 4인·작업일과 잠재적 회피 6인·작업일은 서로 상계할 금액이 아니다. 임금 지급조건, 부분일 투입 가능성, 원구간 대체비용과 전환손실이 없으므로 순추가원가·회피가능원가·준공 예상원가는 산정하지 않는다. 마지막 날 물량이 현행 8㎡, Recovery 31㎡라는 사실도 전일 인력비 지급 여부를 자동 결정하지 않는다.

- **공정담당 → 공사담당:** “후속 Activity ID와 전체·부분 인계조건, 현장 착수 가능 판정을 14:00까지 회신해 주십시오.”
- **공정담당 → 파트너사:** “추가 2명의 역할·원구간·전환시각과 원구간 완료전망, 13일 대기내역을 Crew 배치표로 제출해 주십시오.”
- **공정담당 → 공무·비용담당:** “추가 투입과 17일 투입 회피 가능성을 분리해 임금·할증·최소 지급단위·대체비용 자료를 확인해 주십시오. 일정 단축을 비용 지급 승인으로 보지 않습니다.”

## 정상상태와 이상징후

정상상태는 상태일·실적 마감·위치·단위·완료기준이 일치하고, 물리적 진행과 검측·인계 완료가 분리돼 있는 상태다. 전망에는 성립 조건, 미해소 Constraint, 확인 역할과 회신시한이 표시돼야 한다. 28㎡나 33㎡/가동일은 정상 판정 기준이 아니다.

이상징후는 기준계획을 전망으로 덮어쓰기, 물리적 조립 종료일을 Activity 완료일로 보고하기, 공급자 확약이나 검측 요청만으로 Constraint를 닫기, 추가 인력의 원구간·안전·품질·비용 영향을 생략하는 것이다.

- 검측 요청 여부, 확인 가능 시간과 완료 증빙은 무엇인가?
- 지연 원인은 날짜별로 무엇이며 잔여 작업에도 반복되는가?
- 추가 인력은 어디에서 오며 원구간과 비용은 어떻게 변하는가?
- 목표 작업 단축이 실제 후속 착수와 B2 주요 목표를 바꾸는가?
- 실적 갱신, Crew 전환, 기준계획 변경, 공기·비용 판단 권한은 각각 누구인가?

## 판단·실행과 보류사항

지금 결정할 사항은 실제 시작일 10월 13일, 물리적 실적 28㎡와 잔여 92㎡를 근거와 함께 갱신하고, 현행 물리적 조립 종료전망을 10월 17일로 표시하는 것이다. 기준계획 V1은 변경하지 않는다. Activity 전체 완료일, 후속 착수일과 B2 완료영향은 품질·인계·잔여 논리 확인 전까지 보류한다.

8명안은 10월 14일 15:00까지 원구간 재계산, 역할·작업면·동선·동시작업 위험 확인, 품질·검측 영향, 비용자료와 프로젝트상 결정권이 확인될 때만 권한 있는 역할의 결정 대상으로 올린다. 33㎡/가동일은 첫 가동일 실적으로 검증되기 전까지 실행 확정 생산성이 아니다. 조건 미충족 시 현행 6명안을 유지하며 안전·품질·승인을 줄여 일정을 맞추지 않는다.

## 잘못 판단한 결과

물리적 조립 종료를 Activity 완료로 보고하면 검측·인계가 일정망에서 사라져 후속 작업이 잘못 착수할 수 있다. 전체 -32㎡를 작업면 인계 지연 하나로 설명하면 반복 대기를 놓친다. 추가 인력의 원구간과 병목을 생략하면 목표 작업만 빨라지고 다른 구간이 늦어진다. 4인·작업일 추가와 6인·작업일 회피 가능성을 곧바로 비용절감으로 상계하면 지급조건과 전환손실을 누락한다.

## 후속공정 인계와 실행 후 재확인

후속 담당자에게 상태일, 기준계획 대비표, Activity 정의서 Rev.1, 28㎡ 증빙, 잔여 92㎡, 적용 도면 확인상태, 검측 요청·실시·완료상태, 인계 증빙, 현행 물리적 종료전망, Recovery 전제, 원구간 영향과 추가비용 자료 수령 여부를 함께 넘긴다.

첫 재확인은 10월 14일 17:00이다. 실제 완료량, 순가동시간, 대기 재발과 품질 요청상태를 확인한다. 다음 갱신 상태일은 10월 15일 00:00이며 14일 종료 실적을 반영한다. 8명안이 실행되면 15일 작업 종료 후 실제 생산성·동선 충돌·품질상태를 확인한다. 이후에는 ① 목표 작업의 물리적 종료가 빨라졌는지, ② 검측·인계를 포함한 전체 완료가 빨라졌는지, ③ 후속 착수와 B2 전망이 개선됐는지, ④ 원구간 전망과 비용자료가 악화되지 않았는지를 각각 재확인한다. 현행 10월 17일 전망도 기존 Crew, 순가동시간, 작업면, 적용 도면과 잔여 논리가 유지될 때만 유효하다.
