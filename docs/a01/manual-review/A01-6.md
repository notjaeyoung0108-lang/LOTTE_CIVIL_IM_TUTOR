# A01-6 수동 검토와 수정 명세

자동 수정 3회 후의 최종 원고와 검수 결과를 직접 대조했다. Field와 Quantitative는 PASS이며 Pedagogy가 지적한 C-02 표 머리글의 시간 의미 혼동은 타당하다. 원고 본문 계산은 맞지만 ‘종결조건과 권한 추적’ 표에서 하역·입고 완료의 마감시각을 전체 Constraint 해소 최종시각으로 표시했다.

기존 본문과 모든 실무 디테일·계산을 유지하고 해당 표의 시간 항목만 의미별로 명확히 구분한다: 사용 가능 필요일시 4/9 07:00, 준비 완료 최종시각 4/8 17:00, 하역·입고 완료 최종시각 조건부 4/8 14:00, 대안 결정시한은 대체조달 리드타임 미확인으로 미확정. 표 머리글도 각 시각의 의미를 구분하는 표현으로 바꾼다. 14:00에 전체 자재 Constraint가 해소되는 것으로 읽히지 않게 한다. 불필요한 새 예시나 수치를 추가하지 않는다.

기존 실패 이력은 보존하고 수정본은 모든 Reviewer와 최종 편집 검수를 다시 통과해야 한다. 수동 검토는 PASS를 대신하지 않는다.
