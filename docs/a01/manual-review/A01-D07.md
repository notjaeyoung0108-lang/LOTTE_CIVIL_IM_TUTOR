# A01-D07 수동 검토와 수정 명세

자동 재작성 3회 후 원고와 Field/Pedagogy/Quantitative 지적을 직접 대조했다. 산술·교육설계는 통과했으나 추가 인력의 조달 출처와 동시작업 안전조건이 실제 실행 게이트에서 빠진 점은 사용자 목표상 중요하다. 인원 증원은 기존 수치만으로 실행하면 안 된다.

기존 계산과 질문→추가 정보→조건부 판단 구조를 보존한다. 추가 기능인력 3명이 신규 확보인지 다른 Activity에서 전용되는지 미확정 정보로 추가하고, 작업책임자·자원배치 담당 역할에게 인력배치표와 Look Ahead의 전용 대상 ID·위치·필요기간·후속 완료 영향을 확인하도록 한다. 이 영향이 미확인이면 8명안 실행을 보류한다. 실제 전용구간 수치를 새로 만들어내지 않는다.

동시작업 안전조건도 게이트에 명시한다. 현행 작업계획·안전 통제자료에서 두 작업면 동시 사용, 접근·양중구역 간섭, 8명 역할배치 및 지원 역할을 공사·작업책임자·안전 역할이 검토하고 현장 반영 증빙으로 확인해야 한다. 확인 전에는 실행하지 않는다. 프로젝트별 권한과 절차를 사실처럼 창작하지 않는다.

E5/E8 비교기록은 기록일·적용 위치·역할 구성·작업면 수·공급 및 지원자원 상태를 읽어 현재 조건과 비교 가능함을 확인하는 절차를 보강한다. 기존 33과 48은 조건부 입력이라는 구분을 유지하고 새 실적을 만들지 않는다. 판단과 대안표·실행·재확인 절에 같은 조건을 일관되게 반영한다. 원래 FAIL 이력은 보존하며 독립 검수와 편집 후 검수로 다시 평가한다.
