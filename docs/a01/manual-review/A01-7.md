# A01-7 수동 검토와 수정 명세

3회 자동 수정 뒤 원고와 검수 결과를 직접 대조했다. Field/Pedagogy PASS이며 Quantitative에서 본문 계산과 계산 대장의 대응 누락이 남았다. 기존 수치와 달력은 검수에서도 정확하다고 확인했다. 실무 본문을 다시 구성하지 말고 아래 검증 가능성만 보완한다.

계산 대장에 10-7=3t(동일 범위 일일 계획 대비 미달), 48+24=72t(작업 가능 범위와 조건부 범위 합계), (17-8)-1=8시간(교육용 달력의 식사 제외)을 추가한다. 기존 모든 계산을 보존한다.

본문 초기 전망 설명에 10월 15·16·17·19·20·21·22·23일의 8작업일과 후속 10월 24·26·27·28·29일의 5작업일을 명시해 일요일 비작업 달력과 완료일 대응을 직접 확인할 수 있게 한다. 이 날짜를 가상 실적이나 확정 약속으로 바꾸지 않는다. 조건부 전망과 미확정 F구간의 구분을 유지한다.

원래 needs_manual_review 이력은 보존한다. 수정본은 모든 Reviewer와 편집 후 검수를 다시 통과해야 한다.
