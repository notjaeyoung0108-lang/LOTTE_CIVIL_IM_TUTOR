# A01-8 수동 검토와 수정 명세

3회 자동 수정 뒤 원고와 검수 결과를 직접 대조했다. Field/Quantitative는 PASS이며 Pedagogy에서 차량 배치 시각과 준비 소요시간의 대응 모호성이 남았다. 도착 상한 12:40에서 게이트 확인 10분과 지정 대기위치 배치·착수 준비 10분을 순차 적용하면 12:50은 게이트 확인 완료이고 배치·준비 완료는 13:00이다. 본문 12:50 배치 완료 조건은 모순되므로 고친다.

기존 실무 디테일과 수치를 보존하며 A1 조건, 대안 비교표, 조달담당 질문, 조정 결과표, 재확인 시점의 표현을 모두 ‘12:40까지 도착→12:50까지 게이트 확인 완료→13:00까지 지정 대기위치 배치 및 착수 준비 완료’로 일치시킨다. 도착 시간창 12:30~12:40은 유지한다. 별도의 인력 운영과 점심시간 작업 가능 조건은 미확인 시 실행 확정 금지라는 기존 조건을 유지한다. 새 대안이나 물량을 추가하지 않는다.

원래 needs_manual_review 이력은 보존한다. 수정본은 모든 Reviewer와 편집 후 검수를 다시 통과해야 한다.
