# A01-1 수동 검토와 수정 명세

3회 자동 수정 후 needs_manual_review 원고와 Field/Pedagogy/Quantitative 지적을 오케스트레이터가 직접 대조했다. FAIL을 PASS로 바꾸지 않는다. 원고의 상세 Crew시간·분 단위 자재 소진·주말 이월 계산이 A01-4 범위까지 확장되어 첫 장의 학습목표를 흐린다. 이 범위를 바로잡은 별도 수정 실행에서도 Writer→독립 Reviewer→Editor→재검수의 모든 게이트를 적용한다.

기존 원고의 문서 읽는 칸, 실제 질문, 역할 경계, 후속 인계와 재확인 절차를 보존한다. 상세 17개 계산과 11월 9일 08:00 완료전망은 A01-1에서 요구하지 않는다. 10개 중 6개 완료=60%, 잔여 4개의 단순 계산만 남긴다. 물리적 완료율과 인계 가능 상태가 다르다는 핵심을 가르친다. 생산성·정확한 완료시각 산정은 A01-4의 학습범위임을 설명한다.

시점과 정보 구분: 실물 재고량과 적용 도면 상태는 확인 사실, 공급자 통보는 예정, 재고 소진·자재 사용 가능시각은 근거와 가정이 있는 전망이다. 자료가 부족하면 완료전망을 계산하지 않고 ‘판단 보류, 추가 확인’으로 기록한다. 사실처럼 미래를 서술하지 않는다.

결정 주체: 실제 작업 지속·중단·재개는 프로젝트 책임체계상 권한 있는 공사·안전·품질 역할의 결정이다. 공정계획 담당자는 필요한 질문, 근거 수집, 영향 보고, 일정안 작성, 확약과 실행 결과 반영을 한다. 특정 회사 승인권자를 창작하지 않는다.

Rev./상태일/인계/확약은 처음 짧게 풀어 쓴다. 자재 도착 뒤 식별 확인이 끝나지 않은 장면에서 ‘누구에게 무엇을 묻는가/필요 증빙/답에 따라 바뀌는 결정/재확인시점’을 독자가 적게 한다. 결론과 답을 먼저 공개하지 않는다.

3,000~6,000자 목표를 유지하되 담당자의 실무 행동을 삭제해서 짧게 만들지 않는다. A01-4 내용을 옮겨 쓰거나 새로운 상세 일정계산을 추가하지 않는다.
