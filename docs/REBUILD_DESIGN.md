## A. 전체 목차 및 B. 성장선

배경은 가상 도심 지하차도 현장이다. 북쪽 A와 남쪽 B는 작업구획일 뿐 구조·지하수·동선의 독립성을 뜻하지 않는다. 장면 시간은 현장 배치 이후의 상대 시점이다. 장별 날짜 간격은 교육용 편집이며 공정표나 경력 인정 기간이 아니다.

| 장 | 성장 단계 / 시점 | 사건과 배울 판단 | 처음의 생각 → 획득하는 능력 |
|---|---|---|---|
| 01 | 현장을 본다 / 첫날 | 아침조회 뒤 서로 다른 지시 | 지시를 전달하면 끝 → 사람·작업면·권한 구분 |
| 02 | 현장을 본다 / 첫 주 | 먹과 레벨이 맞지 않는다 | 선이 맞으면 된다 → 기준점·도면·실측 교차 확인 |
| 03 | 작업을 이해한다 / 첫 달 | 덤프는 많은데 굴착이 느리다 | 장비 추가 → 사이클·병목·체적 상태 |
| 04 | 작업을 이해한다 / 첫 달 | 설계고에 나타난 무른 저면 | 높이가 맞으면 완료 → 지지조건·지층·여굴 |
| 05 | 작업을 이해한다 / 둘째 달 | 탁수와 보도 균열 | 물을 더 빼자 → 물·지반·주변 영향 |
| 06 | 구간을 연결한다 / 둘째 달 | 버팀 설치 전 추가 굴착 요청 | 잠깐이면 된다 → 하중경로·단계굴착 |

| 12 | 직무를 연결한다 / 여섯째 달 | 방수 뒤 되메우기 검사 누락 | 사진이 있으니 합격 → ITP·NCR·층별 인수 |
| 13 | 직무를 연결한다 / 일곱째 달 | Rev.2 조립 중 Rev.3 발견 | 새 도면 배포 → 물량·배포·공기·귀책 |
| 14 | 직무를 연결한다 / 일곱째 달 | 자재 지연과 작업면 충돌 | 야근하면 만회 → CP·Float·자원 |
| 15 | 복합 조건을 비교한다 / 여덟째 달 | 구두 변경과 추가공사 | 지시가 곧 지급 → 기술·계약 두 경로 |

18장을 선택한 이유는 한 사건의 인과를 충분히 따라가되 토공·물·지보와 배근·타설·양생의 서로 다른 판단을 억지로 묶지 않기 위해서다. 성장은 승인 권한의 확대가 아니라 관찰·연결·설명 능력의 확대다.
