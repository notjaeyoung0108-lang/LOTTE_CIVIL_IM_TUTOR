# 교재 사용법

이 교재는 숙련된 현장담당자가 사용하는 판단 순서를 훈련한다. 수료 기간을 실제 경력 5년·10년이나 현장 승인 자격으로 환산하지 않는다. 인물·현장·시간·수량은 교육용 가상 설정이다.

## 한 사건을 읽는 순서

1. **PART A. 현장소설**을 끝까지 읽는다. 안재영이 보는 공간과 듣는 말을 따라간다. 모르는 용어는 짧은 각주와 대화에서 먼저 만난다.
2. 본문을 닫고 '확인된 사실·미확인 사실·먼저 할 일·계속할 일'을 말해본다.
3. **PART B. 학습**을 열어 같은 사건을 공사담당·공무담당의 질문으로 해부한다. 인물과 연차는 학습의 기준이 아니다.
4. 조건 하나를 바꿔 통제 범위·승인·공정·비용·기록이 어떻게 달라지는지 설명한다.
5. 필요할 때 보조 카드·기존 실전 Case로 회상·전이 연습을 한다. 카드 수가 본편 진도를 뜻하지 않는다.

웹앱은 한 화면에 한 PART만 보여준다. 소설 끝의 '이 사건 학습'으로 넘어가며, 학습 뒤 '다음 사건'으로 이어진다. A/B 읽음은 따로 표시한다. 교재 전면개편 전 10장 읽음은 새 본문 읽음으로 옮기지 않는다. 기존 카드·답변·복습 기록은 유지한다.

## 현장과 인물

한빛 지하차도는 가상의 도심 굴착·철근콘크리트 현장이다. 첫날부터 열째 달까지 선택된 사건을 연결했다. 일정은 실제 공사 표준 기간이 아니다. A/B/C는 구획 이름이며 지반·구조·동선의 독립성은 사건마다 확인한다.

| 인물 | 역할과 이야기에서 보여주는 것 |
|---|---|
| 안재영 | 처음 배치된 신입 공사담당. 용어를 묻다가 영향범위·대안을 설명하게 됨 |
| 김도윤 | 첫 배치 당시 5년차 공사담당. 현재 상태·기준·통제·실행성을 질문 |
| 이수진 | 첫 배치 당시 10년차 공무담당. 사실을 계약·비용·공기·입증 자료로 연결 |
| 박성호 | 철근반장. 가공·반입·조립·인력·재작업 현실 |
| 최만식 | 토공반장. 운반·작업면·장비·되메우기 현실 |
| 정태식 | 가시설반장. 지보 설치·장비 간섭·반입 현실 |
| 오미란 | 품질담당. 검사·시험·은폐·부적합 종결 |
| 한지우 | 마지막 장의 후배. 재영이 판단 근거를 설명하는 상대 |

## 답변에 남길 것

문제 정의 → 확인 사실/미확인 → 통제와 계속할 조건 → 영향범위 → 기술검토 → 대안 → 필요한 권한·시한 → 실행·재검사 → 기록 → 공정·원가 추적의 순서로 말한다. 긴급 위험에서는 조사를 기다리지 않고 보호·보고부터 한다.

'누가 잘못했다', '모두 중지한다', '빨리 한다'만으로 끝내지 않는다. 왜 그 범위인지, 무엇이 확인되면 결론이 바뀌는지 설명한다. 실제 현장에서는 승인 도면·시방·계약·법규·업무분장·비상계획이 필요하다.
