# IM 현장 문제 해결

> 좋은 답변은 정답 하나를 고르는 말이 아니라, 선택의 근거와 실행 조건을 보여주는 말입니다.

## 현장 해결 7단계

1. **상황 파악**: 주어진 사실, 핵심 연쇄관계, 아직 확인할 가정을 구분합니다.
2. **우선순위 설정**: 위험 범위를 통제하고 법규·안전·품질 조건을 확보합니다.
3. **원인·영향 분석**: 기술 원인과 공정·원가·품질·안전·민원 영향을 연결합니다.
4. **대안 도출**: 실행 가능한 복수 대안과 조합을 제시합니다.
5. **대안 비교 및 선택**: 공기·비용·안전·품질·민원·승인을 같은 기준으로 비교합니다.
6. **실행·협의**: 누가, 언제까지, 어떤 승인을 받아 무엇을 할지 정합니다.
7. **모니터링**: 효과·위험 지표와 목표 미달 시 전환 조건을 정합니다.

앱의 모범 접근방법은 이 일곱 단계를 따릅니다. 문제 정의는 1단계, 즉시 조치는 2단계, 원인·영향은 3단계, 대안 설정은 4단계, 비교·의사결정은 5단계, 이해관계자 협의는 6단계, 사후관리는 7단계에서 확인할 수 있습니다.

## 우선순위는 기계적인 줄세우기가 아니다

기본 사고 순서는 **법규·안전 → 품질·구조 안정성 → 계약·발주처 요구 → 공정 → 원가 → 민원·이해관계자**입니다. 안전을 희생해 공기를 맞추는 안은 제외합니다. 다만 침하 민원은 안전 신호이고, 민원으로 작업시간이 제한되면 공정도 바뀝니다. 뒤 순서라는 이유로 나중에만 처리하지 않습니다.

## 도심 지하차도 예제

총사업비 4,500억 원, 공정률 55%, 잔여 18개월의 가상 현장입니다. 지하수 유입으로 약 2개월 지연 가능성, 공사비 약 7% 상승, 민원 2배 증가, 준공일 준수 요구가 함께 있습니다. 인력안은 약 80억 원, 공법 변경은 약 1.5개월 단축 가능성이 주어졌습니다.

우선 유입 위치·유량·지반·기존 배수·굴착·구조물 영향을 확인합니다. 토사 유실·주변 침하 등 안전을 통제한 뒤 해당 작업의 CP·Float·후속 병행 여부를 봅니다. 2개월 작업 지연이 바로 2개월 준공 지연이라고 가정하지 않습니다.

대안은 인력·장비, 작업조·순서 조정, 병행시공, 공법 변경, 제한 야간작업, 비핵심공정 재배치를 비교합니다. 공법 변경의 승인기간과 각 대안의 중복 효과를 반영한 공정표로 순단축을 확인합니다. 총사업비와 공사비 기준이 다를 수 있어 7% 상승액을 임의로 확정하지 않습니다.

민원은 저소음 장비·방음·고소음 시간 제한·사전공지·창구 일원화를 결합합니다. 전면 야간작업을 유일한 만회책으로 삼지 않습니다. 지연 간접비·장비 대기·인건비·후속 영향을 인력 투입비와 비교하고, 지체상금 가능성은 계약을 확인합니다.

## 선택을 조건부로 말하기

“저라면 작업순서 조정과 공법 변경 검토를 병행하고, 확인된 CP 병목에만 자원을 추가하겠습니다. 승인이나 자원 확보가 늦어질 경우에는 안전한 기존 공법과 독립 작업면을 활용하는 대체안을 준비하겠습니다.”

근거 없는 정확한 금액·일수 대신 확인할 자료와 결정 시점을 밝힙니다. 비용이 적은 안, 빨라 보이는 안, 민원이 적은 안의 효과가 동일한 물량·기간·성능 기준인지 확인합니다.

## 직접 답하고 다시 비교하기

실전 탭에서 상황을 읽고 먼저 답변을 작성하세요. 힌트는 한 번에 하나씩 확인할 수 있습니다. 모범답안 확인 후에는 문제 정의·안전품질·공정·원가·복수 대안·이해관계자·실행·모니터링의 여덟 항목을 스스로 확인합니다.

‘몰랐어요’는 1분, ‘헷갈려요’는 20분, ‘설명할 수 있어요’는 1일 뒤에 다시 돌아옵니다. 자기평가 버튼을 눌러야 연습 완료와 반복 일정이 기록됩니다. 이 앱은 자유서술 답변을 AI가 채점하지 않습니다.

## 훈련 순서

001은 지정된 고급 종합 예제입니다. 처음 학습한다면 002부터 기본 문제를 순서대로 풀고, 중급·고급으로 이동하세요. 답을 외우기보다 같은 틀을 새로운 사실에 적용하는지 확인합니다. 마지막에는 2~3분 동안 소리 내어 답하고 불필요한 나열을 줄여보세요.

## 실무 보강: 12주 훈련 운영안

주당 3회, 회당 60~90분의 학습·문서 작성에 지도자 검토와 가능한 현장 관찰을 결합하는 예시입니다. 12주 수료를 5년 경력이나 독립적인 작업 승인 자격으로 간주하지 않습니다. 목표는 담당 구간을 관리하는 사고와 결과물을 반복 훈련하는 것입니다.

| 주차 | 학습 범위 | 반드시 제출할 결과물 |
|---|---|---|
| 1~2주 | 1장, 도면·측량·업무 분장 | 위치도, 도면 대조표, 하루 인수인계 |
| 3~4주 | 4·5장, 토공·지반·가시설 | 층별 검측표, 굴착 단계도, 이상 보고 |
| 5~6주 | 6·8장, 콘크리트·품질·안전 | 타설 준비표, 시험 추적표, 부적합 처리 |
| 7~8주 | 2·3장, 공정·원가 | 선후행 공정도, 생산성 계산, 준공 예상원가 |
| 9~10주 | 7·9장, 공종 인수·변경 | 인수 점검표, RFI, 변경 증빙 묶음 |
| 11~12주 | 10장과 실전 Case | 대안 비교표, 1쪽 결정 보고, 구두 설명 |

첫 회차에는 자료를 보고 풀고, 두 번째에는 자료를 가린 뒤 설명하고, 세 번째에는 조건 하나를 바꿔 다시 판단합니다. 같은 정답을 재현하는지보다 어떤 가정이 달라져 결론이 바뀌는지 확인합니다.

## 지도자용 공통 평가표

각 항목을 0점(누락·오류), 1점(질문을 받아 보완), 2점(근거를 들어 스스로 수행)으로 평가합니다. 아래 점수는 교육 운영용 수동 평가이며 앱의 자동 점수나 자격 인증이 아닙니다.

| 항목 | 2점 행동의 예 |
|---|---|
| 사실·가정 구분 | 확인 사실과 미확인 정보를 분리한다 |
| 위치·근거 추적 | 도면·시방·시험·일보를 해당 부위에 연결한다 |
| 초기 통제 | 영향 범위와 안전한 첫 조치를 정한다 |
| 기술 이해 | 공법·순서·하중·물의 영향을 설명한다 |
| 공정·생산성 | 병목과 준공 영향을 구분해 계산한다 |
| 원가·계약 | 동일 범위 비용과 승인·통지를 구분한다 |
| 실행 책임 | 담당자·기한·필요 회신·대체안을 정한다 |
| 완료 확인 | 재검사·재개·인수·재발 방지를 정한다 |

교육상 진급 예시는 16점 중 12점 이상과 초기 통제·기술 이해 항목 각 2점입니다. 무단 지보 제거, 위험 구간 진입, 허위 검측, 승인 없는 구조 변경을 제안하면 총점과 관계없이 해당 과제를 다시 훈련합니다. 실제 업무 배치는 현장 책임자의 관찰과 권한 기준으로 결정합니다.

## 종합 실습: 우천 뒤 BOX 기초 타설 준비

**가상 상황:** 내일 BOX 기초 120m³를 타설할 계획입니다. 어제 비가 왔고 저면 한쪽에 연약화가 의심됩니다. 저면 검측은 완료되지 않았으며 배근 완료 예정과 레미콘 예약만 확보돼 있습니다. 다른 독립 구간의 배수로 작업은 승인·자재·인원이 준비되어 있습니다.

**일정 가정:** 원래 저면 확인·배근·검측을 오늘 끝내고 내일 타설할 계획입니다. 문제 해결에 추가 2작업일이 필요하며, 해당 경로의 기존 총여유는 1작업일입니다. 다른 달력·경로·자원 제약은 없다고 가정합니다.

**비용 가정:** 기술적으로 모두 적합하다고 확인된 뒤 비교할 두 안이 있습니다. A는 추가비 300만 원으로 추가 2일이 들고, B는 추가비 500만 원으로 추가 1일이 듭니다. 준공이 실제 늦어질 때만 늘어나는 현장비는 100만 원/일입니다. 지체상금과 기타 비용은 이 계산에서 제외합니다.

**과제:** 지금의 조치, 확인 자료, 일정 영향, 두 안의 비용, 담당자별 요청, 재개 조건을 한 페이지로 작성하세요. 계산 전에 어떤 정보가 부족한지도 적으세요.

## 종합 실습 해설

1. **즉시 조치:** 저면 성능이 미확인인 해당 구간의 후속 은폐·타설을 보류하고 접근·장비 조건을 확인합니다. 공급사와 타설 예약 조정 가능 시간을 협의합니다. 다른 구간은 안전·자원 독립성을 확인한 뒤 진행합니다.
2. **기술 확인:** 연약화 범위·깊이·배수·설계 지지조건·현장 조사와 검사 방법을 관련 기술자와 검토합니다. 지도자가 제공한 A·B는 비용 계산용 조건이지 실제 치환·개량 공법의 승인 상세가 아닙니다.
3. **공정 분석:** A의 추가 2일 중 여유 1일을 소진하므로 준공 영향은 1일입니다. B의 추가 1일은 여유 안에서 흡수돼 준공 영향은 0일입니다. 실제 프로젝트에서는 갱신 공정표로 확인합니다.
4. **비용 비교:** A는 300 + 100 × 1 = 400만 원, B는 500 + 100 × 0 = 500만 원입니다. 주어진 비용만 보면 A가 100만 원 저렴합니다. 준공일 준수가 필수 제약이면 B를 우선 검토해야 하며 일정 요구를 확인하기 전 최종안을 확정하지 않습니다.
5. **실행:** 공사는 현황·처리 작업 준비, 품질은 검사·시험과 재검사, 공정 담당은 경로 갱신, 공무는 변경·비용·통지, 해당 검토·승인자는 기술 적합성과 진행 조건을 확인합니다.
6. **재개·완료:** 승인된 저면 처리와 검사, 배근·거푸집·매립물 검측, 공급·양생 준비가 충족된 뒤 타설합니다. 처리 결과와 적용 도면·시험·일보를 묶어 후속 구간에 전달합니다.

**조건 변경 질문:** 여유가 0일이면 A 총비용은 500만 원, B는 600만 원입니다. 반대로 기간성 비용이 300만 원/일이고 원래 여유 1일이면 A는 600만 원, B는 500만 원입니다. 금액이 바뀌어도 기술 적합성·승인이라는 전제는 없어지지 않습니다.

## 현장에서 쓰는 1쪽 결정 보고 틀

- **결정 요청:** 누구에게 무엇을 언제까지 결정받아야 하는가.
- **확인 사실:** 위치·시간·수량·도면·검사 결과와 미확인 사항.
- **현재 통제:** 작업·접근·자재·후속 공정의 제한 범위.
- **대안 비교:** 동일 성능을 전제로 순공기·총비용·위험·승인·민원 비교.
- **권고안과 조건:** 선택 이유, 추가 확인 사항, 불성립 시 대체안.
- **실행·종료:** 담당자·기한·검사·재개 승인·감시·완료 증거.

말하기는 이 문서를 바탕으로 “문제와 즉시 조치 → 선택 근거 → 실행과 확인” 순서로 연습합니다. 확신이 없는 숫자를 유창하게 말하는 것보다 모르는 사실과 필요한 결정 시점을 정확히 밝히는 것이 중요합니다.
