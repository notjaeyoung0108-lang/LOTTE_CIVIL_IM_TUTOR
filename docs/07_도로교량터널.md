# 도로·교량·터널

> 공종마다 병목이 다릅니다. 작업 순서를 알아야 공기만회 대안이 현실적인지 판단할 수 있습니다.

## 도로: 아래층과 통행을 함께 관리

노상은 포장을 지지하는 지반이고 보조기층·기층은 포장 구조의 일부로 하중 분산·지지·배수 등에 기여합니다. 층별 재료·두께·다짐·배수 확인 후 다음 층을 시공합니다. 위 포장이 좋아도 아래층의 약점이 사라지지 않습니다.

아스팔트는 플랜트·운반·포설·다짐 생산량을 맞춰 적합한 시공 조건을 유지해야 합니다. 콘크리트 포장은 양생·강도·줄눈과 개방 조건이 일정에 영향을 줍니다. 맨홀 높이와 접속 표고, 배수구배는 포장 전부터 확인합니다.

도심 도로의 실제 작업창은 차단·안전시설 설치·복구 시간을 제외한 시간입니다. 전면 차단은 작업 효율을 높일 수 있지만 접근성을 해치고, 구간 분할은 통행을 유지하지만 이음·재동원·통제 전환을 늘릴 수 있습니다. 관계기관과 보행·긴급차량·배송 동선을 함께 협의합니다.

## 교량: 공장과 현장을 하나의 공정으로

기초 → 교대·교각 → 받침·거더 가설 → 바닥판·접속·부대공 → 검사·인수의 흐름을 이해합니다. 실제 순서와 병행 범위는 형식·공법에 따라 달라집니다. 거더 제작·검사·운반과 하부공 준비는 서로 맞물립니다.

PSC는 미리 압축력을 도입하는 콘크리트입니다. 긴장력·신장량·순서·콘크리트 조건과 장비 교정을 기록합니다. 이론 명칭 암기보다 실제 긴장 결과가 계획과 다를 때 누가 무엇을 확인하는지 설명할 수 있어야 합니다.

가설공법에는 작업공간, 크레인 지지면, 운반 경로, 하천·교통 제약, 단계별 구조 안정이 중요합니다. 완성된 구조가 같아도 시공 순서가 바뀌면 중간 단계의 하중과 지지조건이 달라집니다. 인양 중지·재개는 해당 장비 지침·계획·현장 조건으로 판단합니다.

## 터널: 굴진과 지보는 한 사이클

NATM은 실제 지반 거동을 관찰하며 적절한 지보와 시공을 적용하는 터널 시공 개념입니다. 굴착·버력처리·관찰·숏크리트·록볼트 등 지보·계측이 연결됩니다. 굴진량만 늘려 지보가 뒤처지면 안정성이 나빠질 수 있습니다.

터널 TBM은 Tunnel Boring Machine입니다. 기계식 굴착도 지질 변화·마모·장애물·세그먼트 공급·유지보수의 제약을 받습니다. 안전활동의 Tool Box Meeting과 구분하세요.

발파는 굴진과 함께 진동·비산·여굴·주변 영향을 관리합니다. 시험발파·계측·지질 확인을 통해 조건을 조정하며, 임의 장약량이나 진동 판정 수치를 외우는 것이 이 앱의 목적은 아닙니다.

## 지하차도와 지하구조물

방수의 연속성·관통부·보호 상태는 은폐 전 검측과 후속 인수인계가 중요합니다. 개통에는 구조물 외에도 배수·전기·방재·통합 시험과 운영 인수가 필요합니다. 토목 본체 공정률이 높아도 설비 납기나 인허가가 주공정일 수 있습니다.

## 공통 판단 연결

**공법 → 시공·조달·승인 순서 → 직접비·대기비 → 성능 확인 → 단계별 안전 → 교통·진동·탁수 → 기관·감리·설계사 협의**를 각 공종에 적용하세요.

터널의 지하수·지반 위험을 더 살필 때는 [FHWA 도로터널 기술 매뉴얼](https://highways.dot.gov/media/180616)을 참고할 수 있습니다. 적용 기준은 현장 설계·국내 시방을 우선 확인합니다.
