# 도로·교량·터널

> 공종마다 병목이 다릅니다. 작업 순서를 알아야 공기만회 대안이 현실적인지 판단할 수 있습니다.

## 도로: 아래층과 통행을 함께 관리

노상은 포장을 지지하는 지반이고 보조기층·기층은 포장 구조의 일부로 하중 분산·지지·배수 등에 기여합니다. 층별 재료·두께·다짐·배수 확인 후 다음 층을 시공합니다. 위 포장이 좋아도 아래층의 약점이 사라지지 않습니다.

아스팔트는 플랜트·운반·포설·다짐 생산량을 맞춰 적합한 시공 조건을 유지해야 합니다. 콘크리트 포장은 양생·강도·줄눈과 개방 조건이 일정에 영향을 줍니다. 맨홀 높이와 접속 표고, 배수구배는 포장 전부터 확인합니다.

도심 도로의 실제 작업창은 차단·안전시설 설치·복구 시간을 제외한 시간입니다. 전면 차단은 작업 효율을 높일 수 있지만 접근성을 해치고, 구간 분할은 통행을 유지하지만 이음·재동원·통제 전환을 늘릴 수 있습니다. 관계기관과 보행·긴급차량·배송 동선을 함께 협의합니다.

## 교량: 공장과 현장을 하나의 공정으로

기초 → 교대·교각 → 받침·거더 가설 → 바닥판·접속·부대공 → 검사·인수의 흐름을 이해합니다. 실제 순서와 병행 범위는 형식·공법에 따라 달라집니다. 거더 제작·검사·운반과 하부공 준비는 서로 맞물립니다.

PSC는 미리 압축력을 도입하는 콘크리트입니다. 긴장력·신장량·순서·콘크리트 조건과 장비 교정을 기록합니다. 이론 명칭 암기보다 실제 긴장 결과가 계획과 다를 때 누가 무엇을 확인하는지 설명할 수 있어야 합니다.

가설공법에는 작업공간, 크레인 지지면, 운반 경로, 하천·교통 제약, 단계별 구조 안정이 중요합니다. 완성된 구조가 같아도 시공 순서가 바뀌면 중간 단계의 하중과 지지조건이 달라집니다. 인양 중지·재개는 해당 장비 지침·계획·현장 조건으로 판단합니다.

## 터널: 굴진과 지보는 한 사이클

NATM은 실제 지반 거동을 관찰하며 적절한 지보와 시공을 적용하는 터널 시공 개념입니다. 굴착·버력처리·관찰·숏크리트·록볼트 등 지보·계측이 연결됩니다. 굴진량만 늘려 지보가 뒤처지면 안정성이 나빠질 수 있습니다.

터널 TBM은 Tunnel Boring Machine입니다. 기계식 굴착도 지질 변화·마모·장애물·세그먼트 공급·유지보수의 제약을 받습니다. 안전활동의 Tool Box Meeting과 구분하세요.

발파는 굴진과 함께 진동·비산·여굴·주변 영향을 관리합니다. 시험발파·계측·지질 확인을 통해 조건을 조정하며, 임의 장약량이나 진동 판정 수치를 외우는 것이 이 앱의 목적은 아닙니다.

## 지하차도와 지하구조물

방수의 연속성·관통부·보호 상태는 은폐 전 검측과 후속 인수인계가 중요합니다. 개통에는 구조물 외에도 배수·전기·방재·통합 시험과 운영 인수가 필요합니다. 토목 본체 공정률이 높아도 설비 납기나 인허가가 주공정일 수 있습니다.

## 공통 판단 연결

**공법 → 시공·조달·승인 순서 → 직접비·대기비 → 성능 확인 → 단계별 안전 → 교통·진동·탁수 → 기관·감리·설계사 협의**를 각 공종에 적용하세요.

터널의 지하수·지반 위험을 더 살필 때는 [FHWA 도로터널 기술 매뉴얼](https://highways.dot.gov/media/180616)을 참고할 수 있습니다. 적용 기준은 현장 설계·국내 시방을 우선 확인합니다.

## 실무 보강: 도로 공정별 인계 지점

| 인계 | 확인 내용 | 놓쳤을 때 나타나는 문제 |
|---|---|---|
| 노상 → 보조기층 | 지지 상태·다짐·표고·배수·연약부 처리 | 상부 포장 침하와 조기 손상 |
| 하부층 → 포장 | 재료·두께·평탄·구배·청소·작업 조건 | 두께 부족·접착 불량·물고임 |
| 포장 → 통행 | 적용 검사·표면 상태·접속부·표지·개방 조건 | 단차·미끄럼·혼선·초기 손상 |
| 배수 → 운영 | 관저고·구배·연결·청소·유출입·시험 | 역구배·막힘·침수 |

맨홀과 집수정은 뚜껑 표고뿐 아니라 연결 관로의 관저고와 배수 방향을 확인합니다. 준공 시 물이 고이면 포장면, 집수 위치, 관로, 방류 조건을 순서대로 조사합니다. 바로 포장만 덧씌우면 접속 표고가 더 나빠질 수 있습니다.

**계산 예제:** 교육용 직선 관로 길이 40m, 계획 구배 0.5%이면 필요한 관저고 차는 40 × 0.005 = 0.20m입니다. 상류 관저고가 EL.10.20m라면 하류는 EL.10.00m입니다. 실제 설계에서는 접속 관로·토피·유량·지장물 등을 함께 확인해야 하며 이 구배는 권장 설계값이 아닙니다.

## 교량 가설: 들어 올리기 전과 손을 놓기 전

들어 올리기 전에는 부재 식별·중량·인양점, 인양구와 장비 구성, 실제 작업반경, 지지지반·받침, 운반·선회 간섭, 신호와 통제구역을 승인 계획과 대조합니다. 크레인 명목 톤수만으로 가능 여부를 판단하지 않습니다. 장비 성능표와 실제 구성·반경 및 부속 하중 등을 해당 계획 작성·검토자가 확인해야 합니다.

거치 후 인양구를 해제하기 전에는 받침 위치·표고·방향, 거더 위치, 임시 고정과 횡방향 안정, 다음 단계의 연결을 확인합니다. 부재가 받침에 닿았다는 사실만으로 자립 안정이 확보된 것은 아닙니다. 작업 중 바람·지반·장비 조건 변화에 대한 중지·재개 기준은 승인 계획과 장비 조건에서 확인합니다.

PSC 긴장에서는 긴장 순서·정착 상태·장비 교정·콘크리트 조건을 먼저 확인하고 압력/하중과 신장량을 함께 대조합니다. 두 값이 맞지 않으면 목표 숫자에 맞추려고 추가 긴장하지 말고 원인 검토를 요청합니다. 그라우팅은 재료·작업·배출·충전 기록을 텐던별로 남깁니다.

## 터널: 막장 기록을 다음 굴착에 연결

막장 관찰 기록에는 위치·굴진장·암질·불연속면·풍화·용수·붕락 흔적을 도면과 사진으로 연결합니다. 관찰은 안전한 접근 조건과 지보 계획 안에서 수행하며 기록을 위해 미지보 구간에 진입하지 않습니다.

관찰 결과와 내공 변위·천단 침하·지보 상태를 함께 검토하고 설계 지보 패턴과의 적합성을 판단받습니다. 불량 지반·용수·변위 증가가 확인되면 굴진장·지보·보조공법 등을 권한 있는 기술자가 검토하도록 합니다. 지보를 뒤로 미뤄 굴진 실적을 맞추지 않습니다.

굴착 방식과 관계없이 환기, 분진·가스, 차량 동선, 배수, 통신과 대피 체계를 작업 전 확인합니다. 기계식 터널에서는 배토·막장 관리·세그먼트·뒤채움·장비 상태를 해당 장비와 지반 조건의 계획에 따라 관리합니다.

## 준공이 늦어지는 이유: 본체 밖의 인수 항목

구조물 완료 → 개별 기능 시험 → 연동 시험 → 보완 → 운영자 인수의 흐름을 공정표에 넣습니다. 지하차도 배수는 펌프 단독 가동뿐 아니라 수위 감지, 자동 운전, 예비 설비·전원과 경보 등 설계된 기능을 승인 시험 절차로 확인해야 합니다. 실제 침수나 정전을 임의로 일으켜 시험하지 않습니다.

준공도면, 매립부 기록, 시험 성적, 장비 매뉴얼, 유지관리 접근, 잔여 보완 목록을 실물과 대조합니다. 문서 제출 완료와 기능 시험 합격을 별도로 추적합니다.

## 훈련 문제와 해설

**문제:** 야간 통행 차단 5시간 중 안전시설 설치 40분, 청소·시설 철거·개방 점검 50분이 필요합니다. 순수 포장 작업에 쓸 수 있는 시간은 얼마인가요?

**해설:** 300 − 40 − 50 = 210분, 즉 3.5시간입니다. 공급 대기·시험·장비 전환이 있으면 실제 포설 가능 시간은 더 줄어듭니다. 계획 물량을 이 시간에 맞추고, 중단 시 마감·안전 확보와 개방 여부를 결정할 조건을 미리 정합니다.

**통과 기준:** 공종의 선후행뿐 아니라 인계·인수 조건을 설명하고, 가설·통행·운영 시험의 준비기간을 일정에 반영할 수 있어야 합니다.
