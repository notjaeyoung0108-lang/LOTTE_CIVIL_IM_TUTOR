# 샘플 이미지 생성 기록

내장 `image_gen` 도구로 생성하고 원본 PNG를 저장했다. 교육용 개념도로 실제 시공도·축척·시험 결과를 나타내지 않는다. 시추공 그림의 관 형태는 조사 구멍을 단순화한 표현이며, 모든 지층에서 동일한 코어가 회수된다는 뜻은 아니다.

## s2-201

```text
Use case: scientific-educational. 교육용 토목 플래시카드용 이미지. 스타일: 깔끔한 기술 인포그래픽, 단순 개념도. 4:3 가로 구도, 흰색 배경, 단순한 색상, 최소한의 한글 라벨. 초급 학습자가 직관적으로 이해할 목적. 금지: 장식, 복잡한 배경, 인물, 회사 로고, 수치 및 설계 기준. 주제: 여굴. 구성: 흙 지반의 굴착 단면, 파란 점선으로 계획 굴착선, 그보다 조금 더 깊고 넓은 실제 굴착 윤곽, 두 선 사이의 초과 굴착 영역만 주황색 해칭. 계획선보다 깊게 파인 바닥 부분에 명확한 지시선. 텍스트는 "계획 굴착선", "실제 굴착면", "초과 굴착" 세 라벨만 정확히 사용. 단순 수직 단면의 교육 도식이며 시공 지침으로 보이지 않게.
```

## s2-202

```

```
