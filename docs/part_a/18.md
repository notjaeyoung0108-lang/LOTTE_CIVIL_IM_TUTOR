# 18. 왜 전부 멈춰야 한다고 생각해

## PART A. 현장소설

열째 달 08:30, 지하차도 접속부 집수정 옆. 안재영은 새로 배치된 한지우와 포장 전 확인을 하고 있었다. 지우가 물고임 사진을 보여줬다.

“여기 이상한데, 전부 멈춰야 합니까?”

재영은 처음 현장에서 들었던 질문을 떠올렸다. “왜 전부 멈춰야 한다고 생각해?”

지우는 사진을 다시 봤다. “물이 안 빠져서요.”

“좋아. 그럼 어디의 물이 어디로 가야 하는데?”

두 사람은 안전한 보행 동선에서 상류 집수부와 연결 관로를 확인했다. 지우는 덮개 높이를 쟀다고 했지만 관저고¹ 기록은 아직 못 찾았다. 재영은 정답 숫자를 말하지 않고 평면도와 종단도에서 같은 위치를 찾게 했다.

최만식 반장은 포장 장비가 오후에 들어온다고 말했다. “여기만 비켜서 하면 됩니까?”

재영은 영향 경계와 동선을 확인한 뒤 권한자에게 해당 배수 연결부 은폐를 보류하고 독립 인수 완료 구간을 진행하는 안을 올렸다. 경계 밖이라는 이유만으로 기능적으로 독립됐다고 보지는 않았다.

10:20, 준공도면 초안과 실측 기록에서 서로 다른 값이 발견됐다. 지우가 도면 숫자를 현장값으로 고치려 하자 재영이 물었다. “지금 값이 맞다는 근거하고, 설계 기능을 만족한다는 근거가 같은 걸까?”

지우는 펜을 내려놓았다. 조사·처리·재검사와 도면 반영의 순서를 다시 적었다. 품질담당은 배수 기능시험의 미완료 항목을 가져왔고, 이수진은 해당 인수와 기성·정산 항목을 연결했다. 문서만 고쳐서 닫을 일이 아니었다.

오후, 김도윤이 다른 공구에서 온 인수 기록을 보여줬다. 교량 거더가 받침에 닿은 사진과 터널 막장 기록이었다. 재영은 교량이나 터널의 전문가가 된 척하지 않았다. 임시 안정 확인 없이 인양을 해제했는지, 다음 굴착 전에 지보 조건을 확인했는지 물어볼 수는 있다고 답했다.

17:30, 지우가 오늘 일보를 내밀었다. '문제 발견 후 보고' 한 줄 뒤에 미확인 사항과 결정 요청, 내일 재확인 시각이 붙어 있었다.

재영은 마지막으로 물었다. “네가 내일 없으면, 다음 사람이 뭘 보고 이어갈 수 있겠어?”

지우가 검사 기록 번호를 적었다. 재영은 첫날 자신의 수첩이 생각났다. 현장을 다 알게 된 것은 아니었다. 모르는 부분을 어디에 표시하고 누구에게 어떤 판단을 요청할지는 이제 말할 수 있었다.

¹ 관저고: 관의 안쪽 바닥 높이. 덮개나 지표 높이와 구별한다.
