# 12. 덮기 전에 남겨야 할 것

## PART A. 현장소설

여섯째 달 08:50, A구간 외벽 방수면. 보호재를 붙이는 작업 옆으로 되메우기 장비가 대기하고 있었다. 안재영은 방수 완료 사진을 넘기다 검사 결과 칸이 비어 있는 것을 발견했다.

“사진은 있는데 검측 결과는 어디 있습니까?”

최만식 반장이 휴대전화를 내밀었다. “어제 확인 요청은 보냈어요. 오늘 흙 들어오는데요.”

재영은 품질담당 오미란에게 연락했다. 검사 요청과 진행 확인은 다른 상태라고 답이 왔다. 검사·시험계획, ITP에서 이 지점은 확인 없이 다음 공정으로 넘어갈 수 없는 Hold Point로 지정돼 있었다.

“Witness Point면 다르게 움직입니까?” 재영이 물었다.

“그것도 통지와 불참 때 처리 절차를 봐야 해요. 이름만 보고 마음대로 덮는 건 아니고요.”

재영은 미확인 방수면의 은폐를 보류하고 반장과 토사 반입 순서를 다시 맞췄다. 이미 일부 덮인 짧은 구간도 있었다. 사진이 있으면 괜찮다고 둘 수 없었다. 오미란은 부적합 절차로 확인 범위와 처리 방법을 검토하겠다고 했다.

11:10, 다른 인수 완료 구간에서 다짐 시험 준비를 보던 재영은 반입 흙이 전날보다 젖어 있다는 말을 들었다. 반장은 “한 번 더 밀면 되겠죠”라고 했지만, 재영은 함수 상태와 층두께, 적용 시험 조건부터 확인했다. 오전에 서류 하나를 찾던 일이 흙의 상태를 보는 일로 이어졌다.

이수진은 되메우기 수량 산출표에 층번호가 없다고 알려왔다. “오늘 묻은 양과 검사된 양이 같다고 쓸 수 있어요?”

재영은 위치와 층별로 다시 나눴다. 아직 조치가 끝나지 않은 구간은 기성 확인과 따로 추적했다. 반장이 기다린 시간, 다른 구간으로 전환한 시간도 구분했다.

17:10, 미확인 구간은 내일 재확인 대상으로 남았다. 재영은 NCR¹을 접수했다는 사실만으로 문제를 완료 표시하지 않았다. 처리하고 다시 검사하고 다음 공정에 넘기는 것까지 닫혀야 했다.

¹ NCR: Nonconformance Report, 부적합을 식별하고 처리·확인을 추적하는 보고서.
