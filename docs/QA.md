## 내용 검토

대표 13장으로 분리 구조를 정한 뒤 전 장을 같은 사건 단위로 썼다. 소설의 장 번호 자기참조를 사건 시점 표현으로 수정했고, 버팀 해체의 예정시점을 전체 공정과 혼동하지 않게 조정했다. 보조 카드 연결을 주제별로 검토해 사면·지지력·말뚝이 콘크리트 강도 장으로 잘못 연결되지 않도록 수정했다. 카드 답변·ID는 그대로 유지했다.

계산 예제는 [기술검증 대장](../reference/기술검증.md)의 체적·운반·공급·밀도·일정망·원가·관저고 산술을 독립 확인했다. 첫 용어·반복 사건·등장인물은 [설계서](REBUILD_DESIGN.md)와 대조했다. 반복되는 10절 구조는 유지하되 동일한 긴 설명 문단은 반복하지 않았다.

[성장형 목차](qa/rebuild-curriculum.png)와 [모바일 소설](qa/rebuild-story-mobile.png)을 직접 열어 시각 확인했다. [모바일 학습](qa/rebuild-study-mobile.png)은 같은 사건의 별도 화면이다. 전체 화면 캡처에 보이는 고정 하단 메뉴는 실제 화면 하단의 내비게이션이다.

## 한계

문자열·링크·산술·브라우저 검증은 기술적 적합성이나 문학적 완성도를 자동 인증하지 않는다. 특정 현장의 설계 수치·검사기준·법규·계약 조항·기술자 감수는 별도로 필요하며 확인 범위를 [기술검증](../reference/기술검증.md)에 공개했다. 원문 열람이 제한된 공식 자료는 확인 완료로 과장하지 않았다.

기존 education-results.json과 education-*.png는 개편 전 10장 교재의 역사적 기록이다. 현행 성과로 인용하지 않는다.
