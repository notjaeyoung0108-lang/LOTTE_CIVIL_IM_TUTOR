## 별도 확인과 한계

- 본문 건너뛰기 링크는 hash 라우팅을 바꾸지 않고 main에 초점을 이동하도록 구현했습니다.
- 원격 GitHub 저장소 생성·GitHub Pages 실제 배포는 하지 않았습니다. 루트 파일과 상대경로·hash 구성 및 하위경로 정적 제공을 검증했습니다.
- 실제 iOS Safari / Android Chrome 실기기, 음성 읽기 속도, 스크린리더 전체 동작은 검증하지 않았습니다.
- file:// localStorage의 브라우저별 정책 차이와 사용자 파일 이동은 이 앱이 보장할 수 없습니다.
- 여러 탭의 동시 변경은 자동 병합하지 않습니다. 한 탭에서 사용하며 변경 알림 후 필요한 기록을 보존하고 새로고침합니다.
- 학습 콘텐츠는 일반 원칙과 가상 시나리오입니다. 현장별 기술 검토·법적 해석·계약 판정을 대신하거나 전문가 감수를 완료했다고 주장하지 않습니다.
- 자유서술 자동 채점·로그인·클라우드 동기화·백업 가져오기 UI는 없습니다.
