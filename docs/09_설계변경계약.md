# 설계변경·계약 관리

> 기술적으로 맞는 해결책을 계약상 실행 가능한 결정으로 연결합니다.

## 발견 → 질의 → 검토 → 승인 → 반영

도면과 현장이 다르면 위치·치수·사진·조사자료를 남기고 어떤 정보가 부족한지 명확히 합니다. RFI는 불명확한 사항을 질의하는 수단이지, 추가비·공기 변경을 자동 승인하는 문서가 아닙니다.

회신의 기술 내용, 승인 권한, 적용 범위를 확인하고 필요하면 변경도면·내역·공정·계약 절차로 연결합니다. 변경 후 승인본을 작업자·협력업체에 배포하고 구도면 사용을 통제합니다. 이미 시공하거나 발주한 부분의 영향도 확인합니다.

## 현장조건 변경

예상 지층과 실제 지층의 차이가 모두 보상 사유가 되는 것은 아닙니다. 계약의 위험 배분과 통지·증빙 요건을 확인해야 합니다. 동시에 안전조치와 현장 보존을 진행합니다. 긴급 안전조치를 서류 승인까지 미루는 것과, 일반 변경을 승인 없이 강행하는 것은 구분해야 합니다.

자료에는 위치·표고·발견 시각·기존 조사와의 차이·실제 투입·생산량·중단 시간·영향 공종을 연결합니다. 나중에 기억으로 작성한 기록보다 당시의 일보·사진·지시·회신이 유용합니다.

## 승인기간도 공기

변경안의 시공기간만 비교하면 잘못된 결정을 할 수 있습니다. 조사·설계·검토·시험·보완·승인·발주·제작·반입의 전체 기간을 공정표에 반영합니다. 필요한 회신일은 작업 착수일에서 역산합니다.

검토 지연은 자료 누락인지, 권한자 판단 대기인지, 기술 쟁점 미해결인지 나눕니다. 쟁점별 필요한 자료·책임자·회신일을 제시하면 단순 독촉보다 실행 가능성이 높아집니다. 독립 구간의 단계 승인은 검토할 수 있지만 승인 범위 밖의 본시공은 피합니다.

## 협력업체 추가비

원계약 범위, 지시 이력, 추가물량, 실제 투입, 대기 원인, 중복 계상을 확인합니다. 원청의 도면·자재·작업면 제공 지연도 원인이 될 수 있습니다. 인정 가능 항목, 이견 항목, 자료 부족 항목을 분리해 협의합니다.

원청이 발주처에서 아직 못 받았다는 사실만으로 협력업체에 대한 의무가 모두 사라지는 것은 아닙니다. 적용 계약과 법적 의무를 해당 담당자가 검토해야 합니다. 이 교재는 구체적인 지급 기한이나 보상률을 제시하지 않습니다.

## 회의와 클레임

회의록에는 확정·보류·이견, 담당자·완료일·권한을 구분합니다. 클레임은 감정적인 비난이 아니라 사실·계약 근거·영향·요청사항·완화 노력을 설명하는 절차입니다. 통지기한과 공기연장·가격조정 요건은 현장 계약을 확인합니다.

## 준공 정산까지

승인 변경, 최종 수량, 누적 기성·지급, 준공도면을 대조합니다. 미확정 추가비는 쟁점별 해결 경로를 관리하고, 실물과 도면·시험·검측 기록이 일치하는지 확인합니다.

면접에서는 “설계사에 질의하고 끝내겠다”가 아니라 “기술 회신과 계약 변경·공정·원가 반영을 연결하고 승인본 배포까지 확인하겠다”고 답해보세요.

## 실무 보강: 문서마다 해결하는 문제가 다르다

| 문서 | 해결하려는 질문 | 작성만으로 확정되지 않는 것 |
|---|---|---|
| RFI·기술질의 | 어떤 상세·재료·방법으로 시공할 것인가? | 추가금액·공기연장 승인 |
| 현장 사실 기록 | 어디에서 무엇이 언제 달랐는가? | 원인·귀책의 최종 판정 |
| 변경·영향 통지 | 계약 절차상 어떤 사건과 영향을 알리는가? | 청구 전액의 인정 |
| 검토·변경 승인 | 누가 어떤 범위의 변경을 승인했는가? | 승인 범위 밖의 작업 |
| 물량·단가·기간 산출 | 얼마의 수량·비용·일정 영향이 있는가? | 산출액 전부의 계약 반영 |
| 변경 계약·정산 | 권한 있는 당사자가 무엇을 합의했는가? | 미포함 쟁점의 자동 해결 |

명칭과 효력은 사업별 계약·문서체계를 확인합니다. 국가계약, 지방계약, 민간계약, 하도급의 조항을 서로 바꿔 적용하지 않습니다. 적용 계약 문서와 개정·시행 조건부터 특정합니다.

## 제출 연습: 기술질의 한 장 작성하기

**교육용 상황:** 측점 0+240에서 기존 관로가 설계 관로와 간섭합니다. 확인된 위치와 도면상 위치가 다르며 기존 시설의 관리기관 확인이 필요합니다.

- 제목: 측점 0+240 기존 관로 간섭에 따른 설계 관로 시공 상세 질의.
- 근거: 해당 도면 번호·개정번호, 측량 성과, 탐사·시험굴착 기록, 위치 사진.
- 확인 사실: 실제 확인된 좌표·관저고·규격을 기재하고 미확인 사항은 별도 표시.
- 질의: 우회 또는 높이 조정 가능 여부, 구조·배수·이격·시설 보호 조건과 변경 상세 요청.
- 필요 회신일: 예정 시공일에서 자재 조달·작업 준비·검측 기간을 역산해 제시.
- 영향: 해당 구간 작업 보류 범위, 독립 구간 진행 가능성, 추가 조사·공정·비용 검토 필요.

해결안은 비교 초안으로 제시하고 승인된 것처럼 현장에 지시하지 않습니다. 기존 관로의 기능·재질·압력 등이 미확인인데 임의로 절단하거나 옮기지 않습니다.

## 증빙 묶음 만들기

사건번호 하나에 발생 경위, 위치·사진, 계약·도면 대비표, 지시·회신, 물량 산출, 실제 투입, 공정 영향, 완화 조치를 연결합니다. 장비 대기비를 설명할 때는 장비·기간·대기 사유·계약 조건·대체 사용 여부를 확인합니다. 일보의 장비 출근만으로 전일 대기를 증명할 수는 없습니다.

공기 영향은 사건 발생일, 영향받은 작업, 당시 잔여 공정, 여유, 동시 발생 사건, 재배치 노력을 구분합니다. 작업이 멈춘 날짜의 합계와 준공 지연일수는 별개이며, 금액 인정과 기간 인정도 나누어 검토합니다.

## 회의록을 결정 문서로 쓰기

“설계사 검토 예정” 대신 담당자·제출자료·회신일·회신 전 허용 작업·지연 시 보고 경로를 적습니다. 기술 검토 의견과 계약 변경 권한자의 결정을 구분하고 참석자가 했다는 이유만으로 승인 권한을 추정하지 않습니다. 이견은 합의로 바꿔 적지 않습니다.

긴급 위험이 있으면 사람과 시설 보호 조치를 우선하고 시행 이유·범위·시간·지시·실적을 남깁니다. 긴급조치의 필요성과 비용 정산의 인정은 별도로 판단될 수 있습니다.

## 훈련 문제와 해설

**문제:** 감리 담당자가 회의 중 “현장에 맞춰 바꾸라”고 말했습니다. 협력업체가 추가비 2,000만 원과 공기 4일을 요구합니다. 두 요구를 바로 승인할 수 있을까요?

**해설:** 발언 내용·지시 범위·권한·기술 상세를 문서로 확인합니다. 원계약 범위와 변경 수량, 단가 근거, 실제 투입·중복, 공정의 여유와 준공 영향을 각각 검토합니다. 기술 지시가 금액·기간을 자동 확정하지 않습니다. 확인 중에도 필요한 통지와 기록은 계약 절차에 맞춰 진행합니다.

**통과 기준:** 사실 → 기술 질의 → 계약 통지 → 산출·검토 → 승인 → 도면·예산·공정·작업자 반영까지 누락 없이 설명할 수 있어야 합니다.

공식 참고: [국가 공사계약 이행 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=5&cciNo=1&cnpClsNo=1&csmSeq=519)는 국가 공사계약의 이행과 변경 관련 규정으로 연결됩니다. 이를 민간·지방·하도급 계약의 공통 약정으로 적용하지 않습니다.
