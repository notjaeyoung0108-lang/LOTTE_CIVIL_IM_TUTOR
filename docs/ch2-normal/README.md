# 챕터 2 — 올바른 상황

공종별로 **정상적인 순서**가 무엇인지 익힌다. 왜 그 순서인지, 되돌릴 수 없는 지점은 어디인지, 무엇이 보이면 이상인지를 다룬다.

정상을 모르는 사람은 이상을 알아볼 수 없다. 챕터 3의 판단문제는 여기서 배운 순서 위에서 풀린다.

## 각 절의 공통 서식

```text
① Flow 도식             정상 순서
② 왜 이 순서인가         각 칸이 앞뒤로 바뀌면 무슨 일이 생기는가
③ Hold Point           되돌릴 수 없는 지점은 어디인가
④ 정상 판정 기준         무엇이 확인되면 제대로 된 것인가
⑤ 다음 공종에 넘기는 것   인계 대상과 증빙
⑥ 이상의 신호와 그 의미   무엇이 보이면 무엇을 의심하는가
```
