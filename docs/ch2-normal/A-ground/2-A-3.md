# 2-A-3. 계측관리

## 계측은 왜 하는가

흙막이 설계는 **가정 위에 서 있다.** 지층은 몇 개의 시추공에서 이어 그린 추정이고(2-D-1 ①), 토압 계산에 쓰는 흙의 성질도 시료 몇 개에서 나온 값이다. 시공은 도면대로 되었다고 가정한다.

가정이 맞는지는 **파 봐야만** 알 수 있다. 그런데 파는 도중에는 이미 사람이 그 아래에 있다.

> **계측은 설계 가정이 맞는지를 공사 중에 확인하는 유일한 수단이다.**

그리고 하나 더. 흙막이는 **무너지기 전에 반드시 움직인다.** 흙과 강재는 어느 순간 갑자기 사라지지 않는다. 밀리고, 휘고, 가라앉는다. 그 움직임이 커지고 빨라지다가 파괴에 이른다.

```text
   변형 없는 붕괴는 없다  →  변형을 읽으면 예고를 읽는다
```

그래서 계측은 기록 업무가 아니다. **다음 단을 팔지 말지를 정하는 의사결정의 입력**이다(2-A-2 ⑧).

### 계측과 검측은 다르다

자주 섞이므로 먼저 갈라 둔다.

| | 무엇을 보는가 | 언제 |
|---|---|---|
| **검측** | 시공된 것이 도면·시방과 맞는가 | 그 시점의 합격 여부 (1-7) |
| **계측** | 구조물과 지반이 어떻게 거동하는가 | 계속. 값의 변화가 의미다 |

검측은 **한 번 합격하면 끝**이지만, 계측은 **어제 괜찮았다는 것이 오늘의 근거가 되지 않는다.**

---

## 무엇을 재는가

계측 항목은 크게 네 묶음이다.

### 1. 벽체와 지반이 얼마나 움직였는가

| 계기 | 재는 것 |
|---|---|
| **지중경사계** | 벽체 또는 지반의 수평변위를 **깊이별로** 잰다 |
| **지표침하핀** | 배면 지표면이 얼마나 내려앉았는가 |
| **지중침하계** | 땅속 각 깊이의 침하 |

**지중경사계가 흙막이 계측의 중심이다.** 다른 계기가 "얼마나"만 말할 때, 이것은 **어느 깊이에서** 움직이는지를 말한다. 위쪽이 밀리는 것과 굴착면 근처가 배부르는 것과 하단이 밀려 나가는 것은 원인이 전혀 다르다.

```text
   위가 크게 기울면        상부 지보 부족 · 배면 상재하중
   굴착면 부근이 배부르면   그 단의 지보 미설치 · 과굴착
   하단이 안으로 밀리면     근입장 부족 · 수동저항 부족
```

### 2. 버티는 것이 얼마나 받고 있는가

| 계기 | 재는 것 |
|---|---|
| **변형률계** | 스트럿의 축력 |
| **하중계** | 어스앵커의 긴장력 |

### 3. 물은 어떤가

| 계기 | 재는 것 |
|---|---|
| **지하수위계** | 배면 지하수위 |
| **간극수압계** | 흙 속 물이 누르는 압력 |

수위는 **수압의 원인**이다. 수위가 오르면 벽에 걸리는 힘이 는다. 반대로 배면 수위가 예상보다 많이 내려가 있으면, 그만큼 물이 어딘가로 빠져나가고 있다는 뜻이다 — 차수가 깨졌거나 배수가 과하다(2-D-1).

### 4. 옆은 괜찮은가

| 계기 | 재는 것 |
|---|---|
| **건물경사계** | 인접 구조물이 기울었는가 |
| **균열계** | 기존 균열이 벌어지는가 |
| **진동·소음계** | 항타·발파의 영향 |

**인접 구조물 계측은 성격이 다르다.** 우리 구조물의 안전이 아니라 **남의 재산과 안전**을 다루고, 분쟁이 생기면 그대로 증거가 된다. 그래서 착공 전 사전조사와 초기치가 특히 중요하다(3-03).

## 항목은 서로 설명이 되어야 한다

계측을 처음 보는 사람이 가장 많이 하는 실수는 **항목을 하나씩 따로 보는 것**이다.

계측 항목들은 하나의 현상을 여러 각도에서 본 것이다. 그래서 **서로 앞뒤가 맞아야 한다.**

| 이런 조합이면 | 해석 |
|---|---|
| 변위 증가 + 축력 증가 | 정상적인 거동. 벽이 밀리며 지보가 받고 있다 |
| **변위 증가 + 축력 그대로** | 지보가 일을 안 하고 있다. 밀착 불량이나 계기 문제 |
| **변위 그대로 + 축력 증가** | 온도 영향, 또는 다른 곳의 하중이 넘어왔다 |
| 변위 증가 + 배면 침하 증가 | 서로 맞는다. 벽이 밀린 만큼 뒤가 따라 내려온다 |
| **변위 작은데 배면 침하 큼** | 벽 때문이 아니다. 물과 함께 흙이 빠져나가는지 의심 |
| 수위 하강 + 배면 침하 | 배수로 인한 압밀 침하 가능성 (2-D-1) |

> **한 계기만 튀면 계기를 의심하고, 여러 계기가 같은 이야기를 하면 구조를 의심한다.**

이 한 줄이 계측 판독의 출발점이다.

## 관리기준치 — 단계로 나누는 이유

계측값은 "안전 / 위험" 둘로 나누지 않는다. 대개 **여러 단계**로 나눈다. 흔히 쓰는 형태는 이렇다.

```text
   1차 기준 (주의)   →  관찰 강화. 원인 확인. 측정 빈도 상향
   2차 기준 (경고)   →  작업 조정. 보강 검토. 관련자 소집
   3차 기준 (위험)   →  작업 중지. 대피. 긴급 보강
```

**단계로 나누는 이유는 시간을 벌기 위해서다.** 위험 하나만 있으면 넘는 순간 이미 늦다. 앞에 주의와 경고를 두어 **조치할 여유를 만든다.**

### 값은 어디서 오는가

**이 교재는 구체적인 수치를 제시하지 않는다.** 관리기준치는 프로젝트마다 다르고, 다음에서 나온다.

- 흙막이 설계가 계산한 **허용 변위**
- 부재의 **허용 응력** (스트럿·띠장·앵커)
- 인접 구조물이 견딜 수 있는 **허용 침하와 각변위**
- 설계 기준과 시방서

> **관리기준치와 설계 허용치는 다르다.** 관리기준치는 대개 허용치에 여유를 두고 그보다 낮게 잡는다. 1차를 넘었다고 구조가 위험한 것이 아니라, **지켜보던 상태에서 개입하는 상태로 넘어간 것**이다.

### 단계마다 누가 무엇을 하는지가 먼저 정해져 있어야 한다

기준치보다 중요한 것이 **조치 체계**다.

| 정해 둬야 할 것 |
|---|
| 각 단계에서 누가 판단하는가 |
| 누구에게 언제까지 알리는가 |
| 어떤 작업을 멈추는가 |
| 재개는 누가 어떤 조건으로 결정하는가 |

**넘고 나서 정하면 늦다.** 기준치를 넘은 상황은 대개 급하고, 그때 회의부터 시작하면 그사이 굴착은 계속된다. 무엇을 멈출지, 누가 멈출 수 있는지는 계측계획에 미리 쓰여 있어야 한다. **구체적인 권한과 보고 경로는 프로젝트 문서에서 확인한다.**

## 변화율이 절대값보다 먼저다

이 절에서 하나만 가져간다면 이것이다.

> **얼마인가보다 어떻게 변하고 있는가가 먼저다.**

### 왜인가

파괴는 값에서 오지 않고 **가속**에서 온다. 굴착을 하면 변위는 반드시 생긴다. 정상적인 거동은 이런 모양이다.

```text
   변위
    │           ┌─────────  수렴 (정상)
    │       ┌───┘
    │   ┌───┘
    │ ┌─┘
    └─┴────────────────────  시간
      굴착      지보 설치 후 안정

   변위
    │                    ╱   가속 (위험)
    │                 ╱
    │             ╱
    │       ╱
    │  ╱
    └────────────────────── 시간
```

**한 단을 파면 변위가 늘고, 지보를 넣으면 멎는다.** 이 "늘었다가 멎는" 모양이 정상이다. 늘기만 하고 멎지 않으면, 지금 값이 기준 안이어도 곧 넘는다.

### 두 가지 함정

**함정 1 — 기준 안이니 괜찮다.**
절대값이 기준의 절반이어도, 하루 변화량이 계속 커지고 있다면 며칠 뒤를 계산해 봐야 한다. **기준을 아직 안 넘었다는 것은 안전의 증거가 아니라 시간의 문제일 수 있다.**

**함정 2 — 값이 크니 위험하다.**
반대도 있다. 값은 크지만 몇 주째 변하지 않는다면, 이미 일어난 일이 멈춰 있는 상태다. 위험의 성격이 다르다. 물론 값 자체가 허용치를 넘었다면 별개의 문제다.

### 수렴과 정지는 다르다

**수렴**은 증가폭이 점점 줄며 일정한 값에 가까워지는 것이다. **정지**는 값이 전혀 안 변하는 것이다.

계측값이 **갑자기 완전히 평평해지면 계기를 의심한다.** 실제 지반은 미세하게라도 움직이고, 온도에 따라 값이 조금씩 흔들린다. 그 흔들림마저 사라졌다면 센서나 결선이 죽었을 가능성이 있다. **평평한 선이 안심의 근거가 되어서는 안 된다.**

## 어디에 설치하는가

계측기는 많이 달수록 좋은 것이 아니라 **맞는 자리에 달아야** 한다. 대표성이 없는 자리의 정상값은 아무것도 보장하지 않는다.

| 우선 설치 위치 | 왜 |
|---|---|
| 굴착 **장변의 중앙부** | 변위가 가장 크게 나는 곳 |
| **인접 구조물 근접부** | 피해가 실제로 발생하는 곳 |
| 지반이 약하거나 지층이 급변하는 구간 | 설계 가정이 깨지기 쉬운 곳 |
| **굴착 깊이가 가장 깊은 구간** | 하중이 가장 큰 곳 |
| 시공 이력이 특이한 구간 | 문제가 있었던 곳은 계속 본다 |
| 지장물·기존 매설물 인접부 | 영향이 번지는 경로 |

반대로 **모서리 근처는 변위가 작게 나온다.** 벽이 서로 붙잡아 주기 때문이다. 모서리에만 계기가 있으면 현장은 늘 안전해 보인다.

그리고 현실적인 문제 하나. **계측기는 작업에 방해되는 자리에 있으면 뽑히거나 부서진다.** 장비 동선, 자재 야적, 되메움 계획을 보고 자리를 잡아야 데이터가 끊기지 않는다.

## 얼마나 자주 재는가

원칙은 하나다. **거동이 빠를 때 자주 잰다.**

| 시점 | 빈도 |
|---|---|
| 굴착 진행 중, 지보 설치 전후 | 가장 잦게 |
| 굴착 완료 후 안정 구간 | 줄인다 |
| **기준치 초과 후** | 다시 올린다 |
| **강우·해빙·인접 발파 후** | 임시로 올린다 |
| 해체 단계 | 다시 올린다 |

**해체 단계에서 빈도를 줄이는 것이 흔한 실수다.** 지지를 걷어내는 중이므로 거동이 다시 시작된다(2-A-2 ⑩).

## 자동화 계측

센서를 상시 연결해 자동으로 측정하고 전송하는 방식이다.

| 장점 | 한계 |
|---|---|
| 실시간. 야간·휴일 공백이 없다 | 센서 고장·결측을 사람이 안 보면 모른다 |
| 임계값 자동 알림 | 알림이 잦으면 무시하게 된다 |
| 이력이 촘촘해 변화율을 정확히 본다 | 전원·통신이 끊기면 통째로 빈다 |
| 위험 구간에 사람이 안 가도 된다 | 계기 이상인지 실제 거동인지 구분이 필요하다 |

> **자동화 계측은 측정을 자동화한 것이지 판단을 자동화한 것이 아니다.**

데이터가 서버에 쌓이는 것과 누군가 그것을 읽는 것은 다른 일이다. 자동화 현장일수록 **정해진 주기에 사람이 그래프를 보는 절차**와 **수동 계측 병행 검증**이 필요하다.

## 계측 Flow

```text
 ①계측계획 수립            항목 · 위치 · 빈도 · 기준치 · 조치체계
    ↓
 ②계측기 설치 · 검교정
    ↓
 ③초기치 측정              ◆ 굴착 착수 전
    ↓
 ┌──→ ④정기 측정
 │       ↓
 │    ⑤데이터 검증          결측 · 이상치 · 계기 상태
 │       ↓
 │    ⑥판독                절대값 · 변화율 · 항목 간 정합성
 │       ↓
 │    ⑦기준치 대비 판정
 │       ↓
 │    ⑧해당 단계 조치 발동   ◆ 굴착 계속 여부가 여기서 갈린다
 │       ↓
 │    ⑨조치 후 확인         수렴하는가
 │       ↓
 └───── 공사가 계속되는가
         ↓ (해체 · 되메움 완료)
 ⑩최종 기록 · 인계 · 계기 철거
```

### ⑤ 데이터 검증이 판독보다 앞에 있는 이유

**틀린 데이터로 한 옳은 판단은 틀린 판단이다.** 그래서 읽기 전에 데이터 자체를 본다.

| 확인 | 의미 |
|---|---|
| 결측 구간이 있는가 | 그 사이에 무슨 일이 있었는지 모른다 |
| 한 계기만 튀는가 | 계기 문제 가능성 |
| 값이 물리적으로 가능한가 | 하루에 급변한 값은 계기부터 확인 |
| 측정 시각·기온이 기록되었는가 | 축력은 온도에 따라 변한다 |
| 측정자·방법이 일정한가 | 수동 계측은 사람이 바뀌면 값이 흔들린다 |

## Hold Point

```text
 ③ 초기치 확보 전 굴착 착수 금지     → 기준점이 없으면 이후 값에 의미가 없다
 ⑧ 기준치 초과 시 다음 단 굴착 금지   → 지나면 계산에 없는 상태로 들어간다
 ⑩ 되메움·해체 완료 전 계기 철거 금지  → 마지막 구간이 가장 안 보인다
```

## 정상 판정 기준

| 항목 | 정상 |
|---|---|
| **초기치** | 굴착 전에 확보. 검교정 기록 존재 |
| **측정 주기** | 계획대로 지켜짐. 결측 없음 |
| **변위** | 굴착 단계마다 증가 후 **수렴** |
| **변화율** | 단계 진행과 함께 감소 |
| **축력** | 설계 범위 내. 온도 변동을 감안해도 추세가 안정 |
| **항목 간 정합성** | 변위·축력·침하·수위가 서로 모순되지 않음 |
| **인접 구조물** | 초기치 대비 변화 없음 또는 허용 범위 내 |
| **판독** | 정해진 주기에 사람이 읽고 기록을 남김 |

## 이상의 신호와 그 의미

| 보이는 것 | 의심할 것 | 왜 |
|---|---|---|
| **변위가 수렴하지 않고 계속 증가** | 지보 부족, 과굴착, 지반 상이 | 값이 기준 안이어도 위험 |
| 변화율이 단계마다 커진다 | 누적 손상 또는 설계 전제 이탈 | 가속은 파괴의 전조 |
| **굴착을 안 했는데 변위가 늘었다** | 강우, 수위 변화, 배면 상재하중, 인접 공사 | 원인이 우리 작업 밖에 있다 |
| 지중경사계에서 **하단이 안으로 밀린다** | 근입장·수동저항 부족 | 히빙·보일링과 이어진다 (2-A-2) |
| 변위는 느는데 **축력이 그대로** | 띠장 밀착 불량, 지보 미작동, 계기 이상 | 버티는 것이 일을 안 한다 |
| 한 스트럿 축력만 급감 | 그 지보의 이완 | 인접 지보로 하중이 넘어간다 |
| **앵커 하중계가 서서히 하강** | 정착부 이완, 릴랙세이션, 배면 변형 | 원인마다 조치가 다르다 |
| 축력이 주기적으로 오르내린다 | 기온 | 추세와 구분해서 본다 |
| **배면 침하가 벽체 변위보다 크다** | 물과 함께 흙이 유실 중 | 벽 변형으로 설명되지 않는다 |
| 배면 수위가 계속 내려간다 | 차수 파괴 또는 과배수 | 압밀 침하로 번진다 (2-D-1) |
| **값이 갑자기 완전히 평평해진다** | 센서·결선 고장 | 안정이 아니라 결측 |
| 특정 계기만 늘 정상값 | 설치 위치가 대표성이 없거나 계기 불량 | 모서리 근처는 원래 작게 나온다 |
| 결측 구간이 반복된다 | 계기 손상, 접근 곤란, 측정 누락 | 그 사이의 거동을 영영 모른다 |
| 인접 건물 균열계가 벌어진다 | 실제 영향 발생 | 즉시 통지·기록 사안 (3-03) |

## 자주 혼동하는 개념

| | | 차이 |
|---|---|---|
| 계측 | 검측 | 거동을 계속 보는 것과 시공 결과를 한 번 판정하는 것 |
| 절대값 | 변화율 | 얼마인가와 어떻게 변하는가. 후자가 먼저 |
| 관리기준치 | 설계 허용치 | 전자는 여유를 두고 낮게 잡은 개입 시점 |
| 초기치 | 계기 영점 | 전자는 굴착 전 현장 상태, 후자는 기기 자체의 기준 |
| 수렴 | 정지 | 줄어들며 안정되는 것과 전혀 안 변하는 것 |
| 자동화 계측 | 무인 관리 | 측정이 자동일 뿐, 판독은 사람이 한다 |
| 데이터 수집 | 판독 | 쌓여 있는 것과 누군가 읽은 것 |
| 계측 빈도 | 계측 정밀도 | 자주 재는 것과 정확히 재는 것 |

## 잘못 이해하면 생기는 일

**계측을 보고 업무로 여기면** — 값을 적어 올릴 뿐 판단에 쓰이지 않는다. 다음 단 굴착 여부가 계측과 무관하게 정해진다.

**초기치를 굴착 후에 잡으면** — 이미 생긴 변위가 0이 된다. 이후 모든 값이 실제보다 작고, 기준치를 넘어도 안 넘은 것으로 보인다.

**절대값만 보면** — 가속하고 있는 작은 값을 놓친다. 넘고 나서 대응하면 이미 늦다.

**한 계기 값만 보면** — 계기 고장을 구조 문제로 착각하거나, 반대로 실제 거동을 계기 탓으로 넘긴다.

**모서리에만 계기를 달면** — 현장은 늘 안전해 보인다. 대표성 없는 정상값이다.

**자동화했으니 됐다고 여기면** — 센서가 죽어도 모른다. 평평한 그래프를 안정으로 읽는다.

**기준치만 정하고 조치 체계를 안 정하면** — 넘은 뒤 회의부터 시작한다. 그사이 굴착은 계속된다.

**측정 시각과 기온을 안 남기면** — 온도 때문에 오른 축력과 실제로 오른 축력을 구분할 수 없다.

**해체 단계에서 빈도를 줄이면** — 지지를 걷어내는 중에 눈을 감는 것이다.

**계기를 일찍 철거하면** — 마지막 구간의 거동이 기록에 남지 않는다. 문제가 나중에 드러나면 설명할 자료가 없다.

## 스스로 확인

1. 계측과 검측은 어떻게 다른가.
2. "변형 없는 붕괴는 없다"가 계측의 근거가 되는 이유는 무엇인가.
3. 지중경사계가 다른 계기보다 중요한 이유는 무엇인가.
4. 변위는 느는데 축력이 그대로일 때 무엇을 의심하는가.
5. 배면 침하가 벽체 변위보다 클 때 무엇을 의심하는가.
6. 관리기준치를 여러 단계로 나누는 이유는 무엇인가.
7. 관리기준치와 설계 허용치는 어떻게 다른가.
8. 왜 변화율이 절대값보다 먼저인가. 두 가지 함정은 무엇인가.
9. 수렴과 정지는 어떻게 다르고, 그래프가 갑자기 평평해지면 무엇을 의심하는가.
10. 계측기를 어디에 설치해야 하는가. 모서리만 보면 왜 안 되는가.
11. 자동화 계측의 한계는 무엇인가.
12. 해체 단계에서 측정 빈도를 유지해야 하는 이유는 무엇인가.
