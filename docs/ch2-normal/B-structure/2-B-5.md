# 2-B-5. 방수 · 배수

## 이 공종의 위치

방수는 **구조물이 다 만들어진 뒤, 흙으로 덮이기 전**에 한다. 앞에는 콘크리트가 있고 뒤에는 되메우기가 있다.

이 위치가 이 공종의 모든 성격을 결정한다.

> **방수는 공정의 마지막이고, 되메우면 다시 볼 수 없다.**

그래서 방수는 늘 두 가지 압박 사이에 놓인다.

```text
   앞에서  콘크리트 공정이 밀리면 방수 시작이 늦어진다
   뒤에서  되메우기와 후속 공정이 기다린다
              ↓
   방수에 주어진 시간만 줄어든다
```

**방수 하자는 준공 이후에 드러난다.** 물이 스며들어 눈에 보이기까지 시간이 걸리기 때문이다. 그때는 이미 흙 아래에 있고, 확인하려면 다시 파야 한다. 이것이 방수를 다른 공종보다 계약적으로 민감하게 만든다.

---

## 방수와 배수는 한 쌍이다

이름이 붙어 있는 이유가 있다.

| | 무엇을 하는가 | 한계 |
|---|---|---|
| **방수** | 물이 구조물 안으로 들어오지 못하게 막는다 | 수압을 그대로 받는다 |
| **배수** | 구조물 주변의 물을 모아 빼낸다 | 주변 지하수위가 내려간다 |

2-D-1에서 본 차수와 배수의 관계와 같은 구조다. **둘 다 공짜가 아니다.**

```text
   방수만 한다        →  수압을 전부 방수층이 받는다
                         작은 결함에서 새기 시작한다

   배수만 한다        →  물이 오기 전에 빼낸다
                         배수가 막히면 곧바로 수압이 걸린다
                         주변 지반이 압밀침하 (2-D-1)

   둘을 함께 쓴다     →  배수로 수압을 낮추고, 방수로 남은 것을 막는다
```

어느 쪽을 어떤 비중으로 쓸지는 **지하수위와 설계가 정한다.** 현장이 바꾸는 사안이 아니다.

### 배수 방식의 두 갈래

| 방식 | 내용 |
|---|---|
| **영구 배수** | 구조물이 사용되는 내내 물을 계속 빼낸다 |
| **비배수(완전 방수)** | 물을 빼지 않고 방수와 구조로 수압을 전부 견딘다 |

전자는 유지관리가 필요하고 배수가 막히면 설계 전제가 깨진다. 후자는 초기 비용이 크고 결함 허용도가 낮다.

**어느 쪽인지 현장이 알아야 한다.** 영구 배수 방식이면 배수층과 유공관이 **영구 구조의 일부**이고, 되메우기 중에 막히면 안 된다. 이 사실을 모르면 되메우기 담당이 그냥 흙으로 덮는다.

---

## 방수가 실패하는 자리는 정해져 있다

**넓은 면이 새는 경우는 드물다.** 거의 모든 누수는 특정한 곳에서 시작된다.

| 자리 | 왜 |
|---|---|
| **이어치기부(시공이음)** | 두 번에 나눠 친 경계. 원래 하나가 아니다 |
| **관통부** | 배관·슬리브가 벽을 뚫고 지나간다 |
| **모서리와 구석** | 방수재가 꺾이는 자리. 들뜨기 쉽다 |
| **단부 · 마감부** | 방수층이 끝나는 자리 |
| **폼타이 자국** | 거푸집 긴결재가 있던 구멍 |
| **균열** | 특히 관통 균열 |
| **후속 공정 중 손상** | 되메우기 장비, 자재 낙하 |

그래서 방수 관리는 "면을 잘 바르는 것"이 아니라 **"이 자리들을 어떻게 처리했는가"** 다.

> **방수는 면으로 실패하지 않고 선과 점으로 실패한다.**

## 기본 Flow

```text
 ①설계 확인 — 방수 형식 · 배수 방식
    ↓
 ②자재 승인 · 반입
    ↓
 ③바탕면 처리                    ◆ 여기서 대부분이 결정된다
    ↓
 ④바탕 상태 확인                 ◆ 방수 착수 전
    ↓
 ⑤취약부 보강 (이음 · 관통 · 모서리)
    ↓
 ⑥방수층 시공
    ↓
 ⑦검사 (외관 · 두께 · 필요 시 시험)
    ↓
 ⑧보호층 · 배수층 설치
    ↓
 ⑨되메우기 전 최종 확인          ◆ 마지막 되돌릴 기회
    ↓
 ⑩되메우기로 인계
```

### ① 설계 확인

| 확인할 것 | 왜 |
|---|---|
| **방수 형식** | 도막, 시트, 복합 등. 자재와 공법이 다르다 |
| **배수 방식** | 영구 배수인가 비배수인가 |
| 적용 범위 | 바닥·벽·상부 슬래브. 면마다 조건이 다르다 |
| **외방수인가 내방수인가** | 물이 오는 쪽에서 막는가, 반대쪽에서 막는가 |
| 보호층·배수층 사양 | 방수층을 지키는 층 |
| 설계 지하수위 | 수압의 전제 |

**외방수와 내방수의 차이는 결정적이다.** 물이 오는 바깥쪽에서 막으면 수압이 방수층을 구조물 쪽으로 눌러 붙인다. 안쪽에서 막으면 수압이 방수층을 구조물에서 **떼어내는 방향**으로 작용한다. 그래서 지하 구조물은 원칙적으로 외방수다. 그리고 외방수는 **되메우기 전에만 할 수 있다.**

### ② 자재 승인 · 반입

방수재는 종류가 많고 성능이 제각각이다. 승인된 자재와 다른 것이 오면 성능을 보증할 수 없다.

- 승인된 제품·규격과 일치하는가
- 유효기한이 지나지 않았는가
- 보관 조건 (직사광선·동결·습기)
- 부속 자재 (프라이머, 보강 테이프, 실링재)가 같은 계열인가

**부속 자재의 계열을 섞으면 안 되는 경우가 있다.** 주재료는 승인품인데 프라이머가 다른 제품이면 붙지 않는다.

### ③ 바탕면 처리 — 이 공종의 실질

**방수의 성패는 대부분 여기서 결정된다.** 방수재가 나빠서 새는 경우보다 바탕이 나빠서 새는 경우가 훨씬 많다.

| 처리할 것 | 왜 |
|---|---|
| **레이턴스·이물 제거** | 붙는 대상이 약한 층이면 그 층째로 떨어진다 |
| **곰보·공극 충전** | 빈 곳 위에서는 방수층이 지지받지 못한다 |
| **돌출물 제거** | 시트가 찢어지고 도막이 얇아진다 |
| **폼타이 자국 처리** | 그 자체가 관통 경로 |
| **균열 처리** | 움직이는 균열과 아닌 균열의 처리가 다르다 |
| **모서리 면처리** | 직각으로 꺾이면 그 지점이 얇아지고 들뜬다 |
| **함수 상태 조정** | 자재마다 허용 함수 조건이 있다 |

**함수 상태가 현장에서 가장 자주 부딪히는 문제다.** 콘크리트가 아직 젖어 있으면 방수재가 붙지 않거나, 붙었다가 나중에 수증기 압력으로 들뜬다. 그런데 공정은 기다려 주지 않는다.

> **바탕이 조건을 만족하지 않은 상태에서 시작한 방수는, 제대로 시공해도 실패한다.**

이것이 방수 공정 판단의 핵심이다. 시작할 수 없는 조건이면 시작하지 않는 것이 맞고, 그 판단은 공정 지연으로 기록되어야 한다. 시작해 놓고 나중에 실패하면 **책임이 방수 시공으로 넘어간다.**

### ④ 바탕 상태 확인 — Hold Point

방수를 덮기 전에 바탕을 확인한다. 덮으면 바탕은 보이지 않는다.

**→ 넘어가는 조건:** 바탕이 자재가 요구하는 조건을 만족한다. 만족하지 못하면 그 사실이 기록되고, 진행 여부가 결정되어 있다.

### ⑤ 취약부 보강

위에서 본 "선과 점"을 먼저 처리한다. **면보다 먼저 한다.**

- 이어치기부 — 지수재, 보강층
- 관통부 — 밀착 처리와 보강
- 모서리·구석 — 보강 테이프 또는 추가 도포
- 단부 — 마감 처리와 고정

**이 칸을 면 작업과 같이 진행하면 대충 지나간다.** 순서를 나누는 이유가 여기 있다.

### ⑥ 방수층 시공

자재별 사양을 지킨다. 공통으로 관리하는 것은 다음이다.

| 항목 | 내용 |
|---|---|
| **두께 또는 도포량** | 얇으면 그 부분만 뚫린다. 도막은 물량으로 관리 |
| **겹침 폭** | 시트는 겹침이 생명이다 |
| **접착 상태** | 들뜸·기포 |
| **횟수와 간격** | 도막은 여러 번 나눠 바른다. 마르기 전에 덧바르면 안 된다 |
| **기상 조건** | 비·저온·고습에서는 못 한다 |

**기상 조건 때문에 방수는 자주 멈춘다.** 이것이 방수 공정이 밀리는 주된 이유 중 하나이고, 미리 공정에 반영되어야 하는 Constraint다(1-2 ⑥).

### ⑦ 검사

외관, 두께, 겹침, 들뜸을 본다. 방식에 따라 시험을 하기도 한다.

**무엇을 어떻게 검사하는지는 프로젝트의 검사·시험계획이 정한다.**

### ⑧ 보호층 · 배수층 설치

**방수층은 약하다.** 되메우기 장비와 흙, 돌이 직접 닿으면 찢어지고 눌린다. 그래서 보호층을 덮는다.

배수층은 물을 모아 흘려보내는 층이다. 영구 배수 방식이면 **이것이 영구 구조의 일부**다.

| 항목 | 주의 |
|---|---|
| 보호층 | 빠짐없이, 특히 모서리와 단부 |
| 배수층·배수판 | 연속성. 중간에 끊기면 그 위는 물이 고인다 |
| 유공관 | 경사, 연결, 집수 지점 |
| 필터 | 흙이 들어가 막히는 것을 막는다 |

**유공관이 막히면 배수 방식 전체의 전제가 깨진다.** 그리고 막힌 것은 오랫동안 보이지 않는다.

### ⑨ 되메우기 전 최종 확인 — 마지막 되돌릴 기회

```text
   지금    방수층이 보인다      → 고칠 수 있다
   되메운 뒤  흙 아래에 있다     → 다시 파야 확인된다
```

**확인하고 사진을 남긴다.** 이것이 나중에 누수가 생겼을 때 "방수는 제대로 되어 있었다"를 말할 수 있는 유일한 근거다(1-10 ④).

### ⑩ 되메우기로 인계

되메우기 담당에게 넘긴다. 이때 **무엇을 건드리면 안 되는지**를 함께 넘겨야 한다(2-B-6).

## Hold Point — 되돌릴 수 없는 지점

```text
 ④ 바탕 상태 확인       → 덮으면 바탕은 못 본다
 ⑤ 취약부 처리         → 면을 덮으면 확인 불가
 ⑨ 되메우기 전 확인     → 되메우면 다시 못 본다
 (되메우기 착수)        → 손상되어도 모른다
```

**⑨가 이 교재에서 가장 늦게 오는 Hold Point 중 하나다.** 그리고 지나친 대가가 가장 늦게 드러난다.

## 정상 판정 기준

| 항목 | 정상 |
|---|---|
| **자재** | 승인품, 유효기한 안, 부속재 계열 일치 |
| **바탕** | 이물·레이턴스 없음, 곰보 충전, 돌출 제거, 모서리 면처리 |
| **함수 상태** | 자재가 요구하는 조건 만족 |
| **취약부** | 이음·관통·모서리·단부가 개별 처리됨 |
| **두께 / 도포량** | 사양 충족. 도막은 실투입량으로 확인 |
| **겹침** | 규정 폭 이상, 들뜸 없음 |
| **외관** | 기포·핀홀·찢김 없음 |
| **보호층** | 전면 설치, 단부·모서리 포함 |
| **배수층** | 연속, 유공관 경사·연결 정상, 필터 설치 |
| **기록** | 되메우기 전 상태가 사진으로 남았다 |

## 이상의 신호와 그 의미

| 보이는 것 | 의심할 것 | 왜 |
|---|---|---|
| **바탕이 아직 젖어 있다** | 양생 잔여 수분, 유입수 | 시작하면 안 되는 조건일 수 있다 |
| 바탕에 곰보가 많다 | 콘크리트 다짐 부족 (2-B-4) | 방수층이 지지받지 못한다 |
| **이어치기부에서 물이 스민다** | 지수 처리 불량 | 가장 흔한 누수 경로 |
| 폼타이 자국이 처리되지 않았다 | 바탕 처리 누락 | 그 자체가 관통 경로 |
| 도막에 기포·핀홀 | 바탕 함수, 시공 조건 | 그 점에서 뚫린다 |
| 시트가 들떠 있다 | 접착 불량, 바탕 수분 | 수압이 걸리면 벌어진다 |
| 겹침 폭이 부족하다 | 시공 관리 | 이음에서 샌다 |
| 모서리에서 방수층이 얇다 | 면처리 없이 직각으로 꺾음 | 취약부의 전형 |
| **도막 실투입량이 계획보다 적다** | 두께 미달 | 눈으로는 확인이 어렵다 |
| 되메우기 후 배수량이 급감 | 유공관 막힘·손상 | 설계 전제가 깨졌다 |
| 되메우기 중 자재가 떨어졌다 | 방수층 손상 | 덮기 전에 확인해야 한다 |
| 준공 후 벽면에 얼룩·백화 | 누수 진행 | 위치가 원인을 가리킨다 |
| **누수 위치와 결함 위치가 다르다** | 물이 층 사이를 타고 이동 | 새는 곳과 들어온 곳은 다르다 |
| 공정이 밀려 방수 기간이 잘렸다 | 조건 미충족 시공 위험 | 지금 기록해야 한다 (1-10) |

**마지막에서 두 번째 항목이 방수 하자 조사를 어렵게 만드는 이유다.** 물은 방수층과 구조체 사이를 타고 흘러 엉뚱한 데서 나온다. **새는 곳을 막는 것으로 끝나지 않는다.**

---

## 자주 혼동하는 개념

| | | 차이 |
|---|---|---|
| 방수 | 배수 | 막는 것 / 빼내는 것. 한 쌍으로 설계된다 |
| 외방수 | 내방수 | 수압이 눌러 붙이는가, 떼어내는가 |
| 영구 배수 | 비배수 | 계속 빼는가, 수압을 전부 견디는가 |
| 보호층 | 방수층 | 지키는 것 / 막는 것 |
| 배수층 | 되메움재 | 물을 흘려보내는 층 / 채우는 흙 |
| 누수 위치 | 결함 위치 | 물은 이동한다. 같지 않다 |
| 도막 두께 | 도포 횟수 | 횟수를 채워도 두께가 부족할 수 있다 |
| 바탕 불량 | 방수재 불량 | 원인이 전혀 다르고 책임도 다르다 |
| 정지 균열 | 거동 균열 | 처리 방법이 다르다 |

## 잘못 이해하면 생기는 일

**방수를 "면을 바르는 일"로 보면** — 취약부 처리가 면 작업에 묻혀 지나간다. 누수는 그 자리에서 난다.

**바탕 조건을 안 맞추고 시작하면** — 제대로 시공해도 실패한다. 그리고 실패의 책임이 시공으로 넘어간다.

**함수 상태를 무시하면** — 붙었다가 나중에 들뜬다. 들뜬 것은 되메운 뒤에 보이지 않는다.

**프라이머를 다른 계열로 쓰면** — 주재료가 승인품이어도 붙지 않는다.

**도막 실투입량을 안 세면** — 두께 미달을 잡을 방법이 없다. 눈으로는 구분되지 않는다.

**보호층을 생략하면** — 되메우기 중에 찢어진다. 찢어진 것을 아무도 모른다.

**배수층·유공관을 후속 공종에 안 알리면** — 되메우기 중에 막히거나 끊긴다. 설계가 전제한 배수가 작동하지 않는다.

**영구 배수 방식인 줄 모르면** — 유지관리 대상을 관리하지 않는다. 수압이 설계 전제를 넘는다.

**되메우기 전 사진을 안 남기면** — 나중에 누수가 났을 때 방수 시공이 옳았음을 증명할 방법이 없다. 이 공종에서 가장 치명적인 기록 누락이다.

**누수 위치만 막으면** — 물이 들어온 곳은 다른 데다. 막은 자리 옆에서 다시 나온다.

## 스스로 확인

1. 방수 공정이 놓인 위치가 이 공종의 성격을 어떻게 결정하는가.
2. 방수와 배수가 한 쌍인 이유는 무엇인가. 각각의 대가는 무엇인가.
3. 외방수와 내방수는 수압에 대해 어떻게 다르게 작용하는가.
4. 방수가 실패하는 자리들을 말해 보라. 왜 "면으로 실패하지 않는가".
5. 바탕면 처리가 이 공종의 실질인 이유는 무엇인가.
6. 바탕 함수 상태가 조건을 만족하지 않을 때 현장은 무엇을 해야 하는가.
7. 취약부 보강을 면 작업보다 먼저 하는 이유는 무엇인가.
8. 보호층이 필요한 이유는 무엇인가.
9. 영구 배수 방식일 때 되메우기 담당에게 반드시 알려야 하는 것은 무엇인가.
10. 되메우기 전 최종 확인이 가장 늦은 Hold Point인 이유와, 지나쳤을 때의 대가는 무엇인가.
11. 누수 위치와 결함 위치가 다를 수 있는 이유는 무엇인가.
