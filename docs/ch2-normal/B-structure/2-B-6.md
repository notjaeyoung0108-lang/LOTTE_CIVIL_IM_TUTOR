# 2-B-6. 되메우기 · 복공

## 되메우기는 "치우는 일"이 아니다

현장에서 되메우기는 마무리 작업으로 취급되기 쉽다. 구조물은 다 만들었고, 이제 흙으로 덮고 정리하면 끝나는 것처럼 보인다.

그런데 되메우기에는 다른 어떤 공종에도 없는 성질이 두 개 있다.

> **① 되메우기는 구조물에 하중을 거는 행위다.**
> **② 되메우면 그 아래의 모든 것을 다시 볼 수 없다.**

### ① 하중을 거는 행위

흙을 벽 옆에 쌓으면 그 흙은 벽을 옆으로 민다. **되메움토는 채우는 재료가 아니라 하중이다.**

```text
   한쪽만 먼저 되메운다
        ↓
   그쪽에서만 토압이 걸린다
        ↓
   벽이 반대쪽으로 밀린다
        ↓
   구조물이 설계에 없던 힘을 받는다
```

그래서 되메우기에는 **순서와 균형**이 있다. 양쪽을 번갈아, 비슷한 높이로 올린다. 그리고 구조물이 그 토압을 받을 수 있는 상태가 된 뒤에 시작해야 한다.

**중간 슬래브나 버팀이 아직 없는 상태의 벽**은 설계가 가정한 지지 조건이 아니다. 완성 상태에서는 슬래브가 벽을 잡아 주지만, 되메우기 시점에 그것이 없으면 벽은 혼자 토압을 받는다. 이것이 되메우기 시점을 함부로 앞당길 수 없는 이유다.

### ② 다시 볼 수 없다

되메움 아래에는 **방수층, 배수층, 유공관, 구조물 외벽, 지장물**이 있다. 덮고 나면 확인하려면 다시 파야 한다.

그래서 되메우기는 **여러 공종의 Hold Point가 동시에 닫히는 지점**이다.

```text
   2-D-1 ⑨   되메우기 전 방수 · 배수 확인
   2-B-5 ⑨   되메우기 전 최종 확인
   2-B-1     말뚝 · 기초 주변 상태
   2-D-2     지장물 이설 · 보호 상태
              ↓
         전부 여기서 닫힌다
```

## 되메움재가 갖춰야 하는 것

되메우기가 요구하는 것은 굴착에서 나온 흙을 도로 넣는 것이 아니다.

| 요구 | 왜 |
|---|---|
| **다져지는 재료여야 한다** | 다져지지 않으면 나중에 가라앉는다 |
| **구조물에 해롭지 않아야 한다** | 큰 돌은 방수층을 찢고 벽을 때린다 |
| **배수를 막지 않아야 한다** | 배수층 주변은 특히 |
| **유해물이 없어야 한다** | 폐기물, 오염토, 유기물 |
| **함수비가 관리 가능해야 한다** | 너무 젖은 흙은 다져지지 않는다 |

**유용토**(현장에서 나온 흙을 다시 쓰는 것)는 경제적이지만, 그 흙이 위 조건을 만족하는지 확인해야 쓸 수 있다. 확인 절차와 승인 없이 쓰기 시작하면, 나중에 부적합으로 판정되어도 **이미 덮여 있다.**

> **되메움재 승인은 뒤로 미룰 수 있는 절차가 아니다. 미루면 승인의 대상이 이미 사라진다.**

## 다짐의 원리

2-A-1의 성토와 원리가 같다. 다만 되메우기에는 조건이 더 붙는다.

```text
   재료 승인 → 포설(층 두께 준수) → 함수비 조정 → 다짐 → 다짐도 확인 → 다음 층
                                                             ↑
                                                        층마다 반복
```

| 원리 | 내용 |
|---|---|
| **층으로 나눈다** | 두껍게 깔면 아래까지 다져지지 않는다. 겉만 단단해진다 |
| **최적함수비** | 너무 마르면 안 조여지고, 너무 젖으면 흙이 붙지 않는다 |
| **다짐도로 판정한다** | 실험실 최대 밀도 대비 현장 밀도 |

### 되메우기에만 있는 어려움

**구조물 옆은 다지기 어렵다.**

| 어려움 | 왜 |
|---|---|
| **공간이 좁다** | 큰 다짐 장비가 못 들어간다 |
| **구조물을 때리면 안 된다** | 큰 장비의 진동이 벽과 방수층에 전달된다 |
| **방수층이 있다** | 장비와 돌이 직접 닿으면 찢어진다 |
| **지장물이 있다** | 관로 위는 세게 다질 수 없다 |

그래서 구조물 근접부는 **작은 장비로, 얇은 층으로, 여러 번** 한다. 생산성이 떨어지고, 이것이 되메우기 공정이 예상보다 오래 걸리는 주된 이유다.

**그리고 이 구간이 가장 자주 침하한다.** 나중에 구조물 옆 지반만 꺼지는 현상이 여기서 나온다.

## 기본 Flow

```text
 ①되메우기 착수 조건 확인          ◆ 구조물이 토압을 받을 수 있는가
    ↓
 ②선행 공종 확인 · 기록            ◆ 방수 · 배수 · 지장물 — 마지막 확인
    ↓
 ③되메움재 승인 · 반입
    ↓
 ④보호층 · 배수층 손상 확인
    ↓
 ┌──→ ⑤포설 (층 두께 준수 · 좌우 균형)
 │       ↓
 │    ⑥함수비 조정 · 다짐
 │       ↓
 │    ⑦다짐도 확인               ◆ 층마다
 │       ↓
 └───── 계획고까지 남았는가
         ↓
 ⑧마무리 · 표면 정리
    ↓
 ⑨복공 · 포장 또는 원상복구
    ↓
 ⑩침하 관찰
```

### ① 되메우기 착수 조건 확인 — Hold Point

**구조물이 되메움 토압을 받을 수 있는 상태인가**를 확인한다.

| 확인할 것 | 왜 |
|---|---|
| **콘크리트 강도** | 필요 강도에 도달했는가 (2-B-4 ⑨) |
| **지지 조건** | 슬래브·버팀 등 설계가 가정한 지지가 있는가 |
| 가시설 존치 여부 | 스트럿을 언제 걷는가와 맞물린다 (2-A-2) |
| 되메우기 순서 계획 | 좌우 균형, 단계별 높이 |
| 지하수 상태 | 부력 판단 (2-D-1 ⑧) |

**부력을 여기서 다시 본다.** 구조물이 아직 가벼운데 배수를 멈추면 뜬다. 되메우기는 구조물에 무게를 더해 주는 일이기도 하므로, **배수 중단 시점과 되메우기 진행이 함께 판단된다.**

### ② 선행 공종 확인 · 기록 — 결정적 Hold Point

**이 칸이 이 절에서 가장 중요하다.**

덮기 전에 마지막으로 본다. 그리고 **본 것을 기록으로 남긴다.**

| 확인 대상 | 무엇을 |
|---|---|
| **방수층** | 손상·들뜸·미시공 구간 (2-B-5 ⑨) |
| **보호층** | 전면 설치 여부 |
| **배수층 · 유공관** | 연속성, 경사, 막힘, 연결 |
| 구조물 외벽 | 균열, 결함, 마감 상태 |
| 지장물 | 이설·보호 상태, 위치 |
| 가설재 잔존 | 남겨 두면 안 되는 것이 남아 있지 않은가 |
| 굴착면 · 배면 | 공동, 이완 구간 |

**사진의 요건이 있다.** 나중에 근거가 되려면 **어디를 찍은 것인지, 언제 찍은 것인지** 알 수 있어야 한다(1-10 ④). 전경과 상세를 함께 남기고, 위치를 알 수 있는 기준물이 들어가게 찍는다.

**→ 넘어가는 조건:** 선행 공종의 확인이 끝났고, 기록이 남았고, 미결 사항이 정리되었다.

### ③ 되메움재 승인 · 반입

승인된 재료를 쓴다. 유용토면 시험과 승인을 거친 것이어야 한다.

**반입 때마다 같은 재료인지 확인한다.** 유용토는 굴착 위치에 따라 성질이 달라진다. 처음 승인받은 흙과 나중에 나온 흙이 다를 수 있다.

### ④ 보호층 · 배수층 손상 확인

되메우기 장비가 들어오기 직전에 한 번 더 본다. 자재 야적이나 장비 이동 중에 손상되는 일이 흔하다.

### ⑤ 포설

| 관리 항목 | 내용 |
|---|---|
| **층 두께** | 시방이 정한 1층 포설 두께 |
| **좌우 균형** | 한쪽만 올리지 않는다 |
| **구조물 근접부** | 큰 돌 배제, 장비 접근 제한 |
| **배수층 주변** | 세립분이 배수층에 섞여 막히지 않게 |
| 덤프 주행 | 방수층·관로 위를 직접 지나지 않게 |

**좌우 균형이 이 칸의 핵심이다.** 단계별로 양쪽 높이 차의 한도를 정해 두고 지킨다.

### ⑥ 함수비 조정 · 다짐

마른 흙에는 물을 뿌리고, 젖은 흙은 말린다. 구조물 근접부는 소형 장비로 얇게 여러 번.

**비 온 뒤에는 그대로 다져지지 않는다.** 장비를 더 돌린다고 되는 것이 아니라 함수비 문제다(2-A-1).

### ⑦ 다짐도 확인 — 층마다의 Hold Point

다음 층을 올리면 그 층은 덮인다.

**구조물 근접부와 관로 주변을 반드시 포함해서 확인한다.** 넓고 다지기 쉬운 곳만 시험하면, 정작 문제가 생기는 곳은 확인되지 않는다. 시험 위치가 결과를 결정한다.

### ⑧ 마무리 · 표면 정리

계획고까지 채우고 표면을 정리한다. 물이 고이지 않게 기울기를 잡는다.

### ⑨ 복공 · 포장 또는 원상복구

**복공(覆工)** 은 위를 덮어 원래 기능을 회복시키는 것이다. 도로면이면 포장, 인도면 보도, 그 밖의 시설이면 그 시설.

여기서 확인할 것은 **원래 무엇이 있었는가**다. 착공 전 상태 기록이 없으면 원상복구의 기준이 없다. 그래서 착공 전 조사와 사진이 마지막에 쓰인다.

### ⑩ 침하 관찰

**되메우기는 끝나고 나서도 끝나지 않는다.** 다짐이 부족했던 곳은 시간이 지나면서 가라앉는다. 특히 구조물 근접부와 관로 주변.

포장 후에 꺼지면 포장을 걷고 다시 해야 한다. 그래서 **되메우기 완료와 포장 사이에 관찰 기간**을 두는 경우가 있다.

## Hold Point — 되돌릴 수 없는 지점

```text
 ① 착수 조건 확인        → 이르면 구조물에 설계에 없는 힘이 걸린다
 ② 선행 공종 확인 · 기록  → 덮으면 다시 못 본다. 여러 공종이 여기서 닫힌다
 ③ 되메움재 승인         → 부적합재로 채우면 걷어내야 한다
 ⑦ 층별 다짐도 확인      → 다음 층을 올리면 덮인다
 ⑨ 포장                 → 꺼지면 걷어내야 한다
```

**②는 성격이 특별하다.** 다른 Hold Point는 자기 공종의 것이지만, ②는 **앞선 여러 공종의 Hold Point가 한꺼번에 닫히는 자리**다. 되메우기 담당이 무엇을 확인해야 하는지 모르면, 방수·배수·지장물의 마지막 확인이 통째로 빠진다.

## 정상 판정 기준

| 항목 | 정상 |
|---|---|
| **착수 조건** | 강도·지지 조건 확인됨. 부력 판단 완료 |
| **선행 확인** | 방수·배수·지장물 상태 확인 및 기록 완료 |
| **재료** | 승인된 되메움재. 유해물·과대 입자 없음 |
| **층 두께** | 시방 기준 이내 |
| **좌우 균형** | 단계별 높이차가 계획 범위 안 |
| **함수비** | 다짐 가능 범위 |
| **다짐도** | 층마다 기준 충족. **근접부·관로부 포함 확인** |
| **배수층** | 막힘·단절 없음 |
| **방수층** | 되메우기 중 손상 없음 |
| **표면** | 계획고, 배수 기울기 확보 |
| **복공** | 원상 기준 충족 |
| **침하** | 관찰 기간 중 허용 범위 |

## 이상의 신호와 그 의미

| 보이는 것 | 의심할 것 | 왜 |
|---|---|---|
| **되메우기 중 벽체가 밀렸다** | 좌우 불균형, 조기 착수, 과다 다짐 | 구조물에 설계에 없는 힘이 걸렸다 |
| 벽체에 균열이 새로 생겼다 | 토압 또는 장비 충격 | 되메우기 중 발생은 시기가 증거다 |
| **승인 없이 되메움이 시작됐다** | 절차 누락 | 이미 덮인 부분은 확인 불가 |
| 반입된 흙에 큰 돌·폐기물 | 재료 관리 | 방수층 손상과 다짐 불량 |
| 반입 재료가 매번 다르다 | 유용토의 위치별 차이 | 처음 승인과 다른 재료일 수 있다 |
| 다짐도가 계속 미달 | 함수비, 층 두께, 재료, 장비 | 원인을 나눠 본다 (2-A-1) |
| **근접부만 다짐도가 안 나온다** | 공간·장비 제약 | 가장 자주 침하하는 구간 |
| 다짐도 시험 위치가 넓은 곳뿐 | 시험 계획 문제 | 정작 위험한 곳이 확인 안 됐다 |
| **관로 주변이 다져지지 않는다** | 관로 보호와 다짐 기준의 충돌 | 두 요구가 같은 구간에 걸린다 |
| 되메운 뒤 배수량이 급감 | 유공관 막힘·손상 | 배수 방식의 전제가 깨졌다 (2-B-5) |
| 배수층에 흙이 섞여 있다 | 포설 방법, 필터 누락 | 시간이 지나면 막힌다 |
| 되메우기 후 구조물이 떠올랐다 | 부력, 배수 중단 시점 오판 | 되메움 하중이 아직 부족 (2-D-1 ⑧) |
| 포장 후 노면이 꺼졌다 | 다짐 부족 | 걷어내고 다시 해야 한다 |
| 구조물 옆만 길게 꺼진다 | 근접부 다짐 불량 | 전형적인 패턴 |
| 되메우기 전 사진이 없다 | 기록 누락 | 누수 하자 시 방어 근거가 없다 |

## 자주 혼동하는 개념

| | | 차이 |
|---|---|---|
| 되메우기 | 성토 | 구조물 주변을 채우는가, 흙을 쌓아 올리는가 |
| 되메움재 | 굴착토 | 굴착토가 곧 되메움재가 되는 것은 아니다 |
| 유용토 | 사토 | 다시 쓰는 흙 / 밖으로 버리는 흙 |
| 다짐 | 다짐도 | 행위 / 그 결과의 판정값 |
| 채우는 재료 | 하중 | 되메움토는 구조물에 힘을 건다 |
| 복공 | 포장 | 원래 기능 회복 / 그중 노면 처리 |
| 되메우기 완료 | 침하 종료 | 완료 후에도 가라앉는다 |
| 착수 조건 | 공정상 가능 시점 | 전자는 구조 조건, 후자는 일정 |

## 잘못 이해하면 생기는 일

**되메우기를 마무리 작업으로 보면** — 확인해야 할 여러 공종의 Hold Point가 통째로 지나간다.

**착수 조건을 안 보고 시작하면** — 구조물이 지지 없이 토압을 받는다. 밀리거나 갈라진다.

**한쪽만 먼저 되메우면** — 편토압으로 벽이 밀린다. 되돌릴 수 없다.

**되메움재 승인을 미루면** — 승인의 대상이 이미 덮여 있다. 부적합이면 걷어내야 한다.

**큰 돌이 섞인 흙으로 벽 옆을 채우면** — 방수층이 찢어진다. 찢어진 것을 아무도 모른다.

**구조물 근접부를 큰 장비로 다지면** — 벽과 방수층이 손상된다. 반대로 안 다지면 나중에 꺼진다.

**다짐도 시험을 다지기 쉬운 곳에서만 하면** — 합격 기록은 쌓이는데 정작 위험한 구간은 확인되지 않는다.

**배수층 주변을 일반 흙으로 채우면** — 배수가 막힌다. 막힌 것은 몇 년 뒤에 누수로 나타난다.

**부력을 잊고 되메우기와 배수 중단 시점을 따로 보면** — 구조물이 뜬다.

**되메우기 전 사진을 안 남기면** — 방수와 배수가 제대로 되어 있었음을 증명할 수 없다. 하자가 생기면 전부 시공 책임으로 귀결되기 쉽다.

**침하 관찰 없이 바로 포장하면** — 꺼진 뒤에 걷어내고 다시 한다. 비용과 민원이 함께 온다.

## 스스로 확인

1. 되메우기가 다른 공종에 없는 두 가지 성질은 무엇인가.
2. "되메움토는 재료가 아니라 하중이다"라는 말의 뜻은 무엇인가.
3. 좌우 균형을 지켜야 하는 이유를 설명해 보라.
4. 되메우기 착수 조건에서 무엇을 확인하는가. 부력은 왜 여기서 다시 보는가.
5. 선행 공종 확인 칸이 이 절에서 가장 중요한 이유는 무엇인가.
6. 되메움재가 갖춰야 할 조건들을 말해 보라. 유용토를 쓸 때 주의할 점은 무엇인가.
7. 되메움재 승인을 미루면 안 되는 이유는 무엇인가.
8. 구조물 근접부의 다짐이 어려운 이유 네 가지는 무엇인가.
9. 다짐도 시험 위치가 결과를 결정한다는 말의 뜻은 무엇인가.
10. 배수층 주변을 일반 흙으로 채우면 무엇이 문제인가. 언제 드러나는가.
11. 되메우기 완료 후에도 침하를 관찰하는 이유는 무엇인가.
