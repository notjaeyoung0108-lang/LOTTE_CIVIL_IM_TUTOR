# 2-B-3. 거푸집 · 동바리

## 이것은 구조물이 아니지만 구조물이다

거푸집과 동바리는 **완성되면 사라진다.** 콘크리트가 굳으면 뜯어내고, 도면에도 남지 않는다.

그래서 "임시로 대충"이라는 인식이 생기기 쉽다. 그런데 사실은 반대다.

> **굳지 않은 콘크리트의 무게를 전부 받는 것은 동바리다.**

콘크리트가 스스로 설 수 있게 되기 전까지, 구조물의 하중은 오직 가설물이 지탱한다. 그 시간 동안 **동바리가 곧 구조체**다. 붕괴 사고가 이 시간대에 집중되는 이유가 여기 있다.

거푸집과 동바리는 역할이 다르다.

| | 무엇인가 | 무엇을 견디는가 |
|---|---|---|
| **거푸집** | 콘크리트를 원하는 모양으로 담는 틀 | **측압** — 옆으로 미는 힘 |
| **동바리** | 거푸집과 콘크리트를 아래에서 받치는 지지대 | **연직하중** — 아래로 누르는 힘 |

두 힘의 성질이 다르므로 관리 항목도 다르다.

---

## 측압 — 거푸집을 터뜨리는 힘

굳지 않은 콘크리트는 액체에 가깝다. 액체는 옆으로 민다. 이 힘이 **측압**이다.

측압을 키우는 것들:

| 요인 | 왜 |
|---|---|
| **타설 속도** | 빨리 부을수록 아래가 굳기 전에 위가 쌓인다 |
| **타설 높이** | 높이 쌓일수록 아래쪽 압력이 크다 |
| **온도(낮을수록)** | 응결이 느려 액체 상태가 오래간다 |
| 슬럼프·유동성 | 묽을수록 액체에 가깝다 |
| 다짐(과다 진동) | 굳어가던 것을 다시 풀어 놓는다 |

여기서 현장이 가장 자주 놓치는 것이 **타설 속도**다.

```text
   계획 타설 속도로 치면   아래가 어느 정도 굳으면서 측압이 제한된다
   빨리 치면              전체가 액체인 채로 높이만 쌓인다 → 측압 급증
```

**거푸집 설계는 특정 타설 속도를 전제로 한다.** 그 전제를 현장에서 깨면 거푸집이 설계 이상을 받는다. 배부름과 터짐은 거푸집이 약해서가 아니라, **약속한 속도보다 빨리 쳤기 때문인 경우가 많다.**

---

## 동바리가 무너지는 이유

동바리는 대개 **재료가 부러져서** 무너지지 않는다. 다음 셋 중 하나다.

| 원인 | 설명 |
|---|---|
| **좌굴** | 가늘고 긴 기둥이 힘을 받으면 옆으로 휘면서 갑자기 꺾인다 |
| **지지 지반의 침하** | 받치는 바닥이 내려앉으면 힘이 몰린다 |
| **수평력을 못 받음** | 연직으로는 버텨도 옆으로 밀리면 전체가 넘어간다 |

### 좌굴과 수평 연결재

가느다란 막대를 세워 놓고 위에서 누르면, 재료가 부서지기 전에 **휘어서 꺾인다.** 이것이 좌굴이다. 그리고 **길수록 훨씬 약해진다.**

그래서 동바리 중간을 서로 묶는다. 수평 연결재가 들어가면 **하나의 긴 기둥이 짧은 기둥 여럿으로 나뉘는 효과**가 난다.

```text
   연결재 없음   ┃   긴 기둥 하나 → 쉽게 좌굴
   연결재 있음   ╫   짧은 기둥 여럿 → 훨씬 강함
```

**현장에서 수평 연결재는 가장 자주 빠지는 부재다.** 통행에 걸리적거리고, 없어도 당장은 서 있기 때문이다. 없어도 서 있다가 타설 하중이 걸리는 순간 무너진다.

### 지지 지반

동바리가 흙 위에 서 있으면 그 흙이 하중을 받는다. 젖으면 물러지고, 물러지면 내려앉는다. 한 곳이 내려앉으면 그 옆으로 하중이 몰리고, 연쇄가 시작된다.

**그래서 동바리 하부는 받침판과 기초 처리가 필요하고, 배수가 유지되어야 한다**(2-D-1).

## 기본 Flow

```text
 ①구조도면 · 시공계획 확인
    ↓
 ②거푸집 · 동바리 구조검토 및 승인   ◆ 가설물도 설계다
    ↓
 ③자재 반입 · 상태 확인
    ↓
 ④지지 지반 · 하부 처리
    ↓
 ⑤동바리 설치
    ↓
 ⑥거푸집 조립 · 위치 확인
    ↓
 (철근 배근 · 배근검측 — 2-B-2 ⑦)
    ↓
 ⑦설치 검측                        ◆ 타설 전
    ↓
 ⑧타설 중 감시
    ↓
 ⑨양생 · 존치
    ↓
 ⑩해체                             ◆ 강도 확인 후
```

**⑥과 배근이 맞물린다.** 한쪽 거푸집을 세우고, 철근을 넣고, 검측을 받고, 반대쪽을 닫는다. 그래서 거푸집 담당과 철근 담당은 서로의 일정에 묶여 있다(1-8).

### ① 구조도면 · 시공계획 확인

부재의 형상과 치수, 타설 구획과 순서, 이어치기 위치를 확인한다.

**이어치기 위치는 거푸집이 정하는 것이 아니다.** 구조적으로 어디서 끊어도 되는지는 설계가 정한다. 거푸집 구획을 먼저 정하고 거기 맞춰 끊는 것이 아니다.

### ② 구조검토 및 승인 — Hold Point

**가설물에도 설계가 있다.** 무엇을 얼마나 받는지 계산하고, 배치와 규격을 정하고, 승인을 받는다.

| 검토에 들어가는 것 | 왜 |
|---|---|
| 연직하중 (콘크리트 자중, 거푸집 자중, 작업하중) | 동바리 규격과 간격 |
| **측압** (타설 속도·높이 전제) | 거푸집 강성과 긴결재 간격 |
| 수평하중 (풍하중, 작업 충격) | 가새·연결재 |
| 지지 지반 조건 | 하부 처리 방법 |
| 해체 시점 조건 | 존치 기간 판단 기준 |

**여기서 정해진 전제를 현장이 기억해야 한다.** 특히 타설 속도와 타설 높이는 승인 조건이다. 현장에서는 이 조건이 도면에 적혀 있어도 읽히지 않는 경우가 많다.

**→ 넘어가는 조건:** 구조검토가 승인되었고, 타설 속도 등 전제 조건이 관계자에게 공유되었다.

### ③ 자재 반입 · 상태 확인

가설 자재는 **여러 현장을 돌아다닌 중고인 경우가 많다.** 그래서 신품과 다른 것을 본다.

| 보는 것 | 왜 |
|---|---|
| 변형 · 휨 · 찌그러짐 | 휘어 있는 동바리는 좌굴 저항이 크게 떨어진다 |
| 나사부 손상 (조절식) | 하중 전달이 안 된다 |
| 용접부 균열 | 갑작스러운 파단 |
| 심한 부식 | 단면 감소 |
| 거푸집 판 표면 상태 | 콘크리트 표면 품질에 그대로 나온다 |
| 규격 혼용 | 다른 제품을 섞으면 연결이 안 맞는다 |

**휘어 있는 동바리를 "그래도 서 있으니까" 쓰면 안 된다.** 좌굴은 처음부터 휘어 있을 때 훨씬 빨리 온다.

### ④ 지지 지반 · 하부 처리

받침 바닥을 다지고, 받침판을 깔고, 물이 고이지 않게 한다. **이 칸이 빠지면 나머지가 다 소용없다.**

### ⑤ 동바리 설치

승인된 배치대로 세운다. 여기서 현장이 가장 자주 바꾸는 것이 **간격**과 **수평 연결재**다.

```text
   승인 도면    일정 간격 + 전 단수 수평 연결재
   현장 실제    통로 확보를 위해 몇 개 빼고, 연결재 일부 생략
```

**빼는 순간 그것은 승인된 가설물이 아니다.** 장비나 통행을 위해 배치를 바꿔야 한다면 그것은 기술질의 사안이다(1-6).

### ⑥ 거푸집 조립 · 위치 확인

**거푸집의 위치가 곧 구조물의 위치다.** 5cm 밀려 있으면 구조물이 5cm 밀려서 만들어진다. 콘크리트를 친 뒤에는 고칠 수 없다.

| 확인 | 왜 |
|---|---|
| 평면 위치 · 높이 | 구조물의 최종 위치 |
| 수직·수평 정밀도 | 기울어진 채 굳는다 |
| 긴결재 (폼타이 등) 간격 | 측압에 대한 저항 |
| 이음부 밀실도 | 벌어지면 시멘트풀이 새어 표면이 곰보가 된다 |
| 박리제 도포 | 해체 시 표면 손상 방지 |
| 청소 | 안의 이물 |

### ⑦ 설치 검측 — Hold Point

타설 직전, 거푸집과 동바리 전체를 확인한다. 배근검측과는 별개다.

**타설이 시작되면 안으로 들어갈 수 없다.** 동바리를 보강하려 해도 이미 하중이 걸린 상태에서의 보강은 위험하다.

### ⑧ 타설 중 감시

**이 칸이 거푸집·동바리에만 있는 특별한 칸이다.** 다른 공종은 시공이 끝나고 확인하지만, 가설물은 **하중이 걸리는 동안 실시간으로 본다.**

| 보는 것 | 무엇의 신호인가 |
|---|---|
| 거푸집의 배부름 | 측압 과다 |
| 긴결재 주변의 변형 | 국부 과응력 |
| 동바리의 휨·기울어짐 | 좌굴 전조 |
| 하부 침하 | 지지 지반 문제 |
| 시멘트풀 누출 | 이음부 벌어짐 |
| **타설 속도** | 승인 전제를 지키고 있는가 |

**이상이 보이면 타설을 멈출 수 있어야 한다.** 그리고 멈출 권한이 누구에게 있는지가 미리 정해져 있어야 한다. 콘크리트가 오고 있다는 이유로 계속 치는 것이 사고로 이어진다.

### ⑨ 양생 · 존치

콘크리트가 강도를 낼 때까지 거푸집과 동바리를 그대로 둔다. **존치기간은 "며칠"이 아니라 "강도"로 정해진다.**

| 판단 근거 | 설명 |
|---|---|
| **강도 확인** | 현장 양생 공시체 등으로 필요 강도 도달을 확인 |
| 시방 최소 기간 | 조건별 최소값 |
| 부재 종류 | 측면 거푸집과 바닥 동바리는 조건이 다르다 |
| 기온 | 추우면 훨씬 늦게 굳는다 |

**측면 거푸집과 받치는 동바리는 다르다.** 옆판은 콘크리트가 형상을 유지할 정도면 떼도 된다. 그러나 **아래에서 받치는 동바리는 부재가 자기 무게와 작업하중을 스스로 받을 수 있을 때**까지 있어야 한다. 이 둘의 시점이 크게 다르다.

### ⑩ 해체 — Hold Point

**해체는 하중을 구조물에 넘기는 행위다.** 동바리를 걷는 순간 그 하중은 콘크리트가 받는다. 아직 못 받으면 처지거나 갈라진다.

해체 순서도 있다. 한쪽부터 몰아서 걷으면 남은 동바리에 하중이 집중된다.

**상부에서 계속 타설이 진행 중이라면**, 아래층의 동바리를 걷는 순간 그 층이 상부 하중을 받게 된다. 여러 층을 동시에 진행할 때는 **몇 개 층의 동바리를 남길 것인가**가 구조검토 사항이다. 현장이 "굳었으니 걷자"로 정할 수 없다.

## Hold Point — 되돌릴 수 없는 지점

```text
 ② 구조검토 승인      → 지나면 그 조건으로 전부 설치한다
 ⑦ 타설 전 검측       → 타설이 시작되면 손댈 수 없다
 ⑧ 타설 중 중단 판단   → 계속 치면 하중이 계속 는다
 ⑩ 해체 시점 판단     → 걷으면 하중이 구조물로 넘어간다
```

⑩은 성격이 특이하다. **되돌릴 수 없는 것이 아니라, 너무 일찍 하면 되돌릴 수 없는 손상이 남는다.**

## 정상 판정 기준

| 항목 | 정상 |
|---|---|
| **구조검토** | 승인된 최신본. 현장 설치가 그것과 같다 |
| **자재 상태** | 변형·손상·심한 부식 없음. 규격 혼용 없음 |
| **하부** | 지지 지반 처리됨, 받침판 설치, 물 고임 없음 |
| **동바리 배치** | 승인 간격. 수평 연결재·가새 전부 설치 |
| **연직도** | 동바리가 수직. 편심 없음 |
| **거푸집 위치** | 측량 기준 대비 허용오차 안 |
| **긴결재** | 승인 간격, 조임 상태 양호 |
| **이음부** | 밀실. 시멘트풀이 새지 않음 |
| **타설 속도** | 승인 전제 범위 안 |
| **존치** | 강도 확인 근거가 있다 |
| **해체** | 순서와 시점이 검토 결과에 따랐다 |

## 이상의 신호와 그 의미

| 보이는 것 | 의심할 것 | 왜 |
|---|---|---|
| **타설 중 거푸집이 배부른다** | 측압 과다 — 타설 속도 · 높이 | 설계 전제를 넘고 있다 |
| 긴결재 주변이 변형됐다 | 국부 과응력, 간격 부족 | 그 지점부터 터진다 |
| **시멘트풀이 새어 나온다** | 이음부 벌어짐 | 표면 결함 + 벌어짐이 커진다 |
| **동바리가 휘어 보인다** | 좌굴 진행 | 갑자기 꺾인다. 즉시 통제 |
| 동바리 하부가 내려앉았다 | 지지 지반 연약화 | 하중이 옆으로 몰린다 |
| 수평 연결재가 빠져 있다 | 통행·작업 편의로 제거 | 좌굴 저항이 크게 준다 |
| 동바리가 기울어 있다 | 편심 하중 | 연직 지지 능력이 크게 준다 |
| 받침판 없이 흙 위에 서 있다 | 하부 처리 누락 | 젖으면 내려앉는다 |
| **승인 도면과 배치가 다르다** | 현장 임의 변경 | 승인된 가설물이 아니다 (1-6) |
| 휘어 있는 동바리를 쓴다 | 자재 검수 누락 | 좌굴이 훨씬 빨리 온다 |
| 해체 후 부재가 처졌다 | 조기 해체, 강도 미달 | 되돌릴 수 없는 변형 |
| 해체 후 표면이 뜯겼다 | 박리제 미도포 또는 조기 해체 | 피복 손상 가능 (2-B-2) |
| 해체 후 곰보·재료분리 | 이음부 누출, 다짐 부족 | 2-B-4와 함께 본다 |
| 존치기간을 줄여 달라고 한다 | 공정 압박 | 판단 근거는 강도이지 일정이 아니다 |

## 자주 혼동하는 개념

| | | 차이 |
|---|---|---|
| 거푸집 | 동바리 | 모양을 만드는 것 / 받치는 것 |
| 측압 | 연직하중 | 옆으로 미는 힘 / 아래로 누르는 힘 |
| 좌굴 | 파단 | 휘어 꺾이는 것 / 재료가 끊어지는 것 |
| 존치기간 | 양생기간 | 전자는 가설물을 두는 기간, 후자는 콘크리트를 보호하는 기간 |
| 측면 거푸집 해체 | 지지 동바리 해체 | 조건과 시점이 크게 다르다 |
| 일수 기준 | 강도 기준 | 판단의 근거는 강도다. 일수는 보조 |
| 가설물 | 임시 구조물 | 임시지만 구조물이다. 검토와 승인이 있다 |
| 타설 속도 | 타설 물량 | 전자는 시간당 높이. 측압을 좌우한다 |

## 잘못 이해하면 생기는 일

**가설물을 "임시"로 보면** — 구조검토 없이 세우고, 승인 배치를 임의로 바꾼다. 굳지 않은 콘크리트의 하중을 전부 받는 것이 이것이다.

**수평 연결재를 빼면** — 긴 기둥 하나가 되어 좌굴 저항이 급격히 떨어진다. 없어도 서 있다가 타설 중에 무너진다.

**휘어 있는 동바리를 쓰면** — 처음부터 휘어 있으면 좌굴이 훨씬 빨리 온다.

**하부 처리를 생략하면** — 흙이 젖어 내려앉고, 그 하중이 옆으로 몰려 연쇄가 시작된다.

**타설 속도를 안 지키면** — 측압이 설계 전제를 넘는다. 거푸집이 약한 것이 아니라 약속을 깬 것이다.

**타설 중 감시를 안 하면** — 배부름과 침하를 놓친다. 이 공종에서 유일하게 실시간으로만 잡히는 신호다.

**멈출 권한을 정해 두지 않으면** — 이상이 보여도 "레미콘이 대기 중"이라는 이유로 계속 친다.

**존치를 일수로만 판단하면** — 기온이 낮으면 같은 날짜에도 강도가 훨씬 덜 나온다. 해체 후 처진다.

**해체 순서를 무시하면** — 남은 동바리에 하중이 몰려 그쪽이 먼저 무너진다.

**상부 타설 중 아래층 동바리를 걷으면** — 그 층이 상부 하중을 받게 된다. 아무도 계산하지 않은 하중 경로가 생긴다.

## 스스로 확인

1. 거푸집과 동바리가 각각 견디는 힘은 무엇인가.
2. "굳지 않은 콘크리트 하중을 전부 받는 것은 동바리다"가 뜻하는 바는 무엇인가.
3. 측압을 키우는 요인들을 말하고, 현장이 가장 자주 깨는 전제가 무엇인지 설명해 보라.
4. 좌굴이란 무엇이고, 수평 연결재가 왜 효과가 있는가.
5. 동바리가 무너지는 세 가지 경로를 말해 보라.
6. 타설 중 감시가 이 공종에만 있는 특별한 칸인 이유는 무엇인가.
7. 존치기간의 판단 근거가 일수가 아니라 강도인 이유는 무엇인가.
8. 측면 거푸집과 지지 동바리의 해체 조건이 다른 이유는 무엇인가.
9. 해체가 "하중을 구조물에 넘기는 행위"라는 말의 뜻은 무엇인가.
10. 상부 층 타설이 진행 중일 때 아래층 동바리를 걷으면 무엇이 문제인가.
