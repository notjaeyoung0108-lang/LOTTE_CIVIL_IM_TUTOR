# 2-B-2. 철근공사

## 철근이 하는 일

콘크리트는 **누르는 힘에는 강하고 당기는 힘에는 약하다.** 눌러 부수려면 큰 힘이 들지만, 잡아당기면 쉽게 갈라진다.

구조물에는 두 힘이 다 걸린다. 보가 휘면 위쪽은 눌리고 아래쪽은 당겨진다. 그래서 **당겨지는 쪽에 철근을 넣는다.**

```text
   보에 하중이 걸린다
        ↓
   위는 압축, 아래는 인장
        ↓
   압축 = 콘크리트가 받는다
   인장 = 철근이 받는다
```

여기서 철근공사의 모든 원칙이 나온다.

> **철근은 "당겨지는 자리에, 당기는 방향으로, 힘을 전달할 수 있게" 들어가야 한다.**

세 가지가 다 필요하다. 양이 맞아도 자리가 틀리면 소용없고, 자리가 맞아도 이어지지 않으면 힘이 끊긴다.

---

## 철근이 제 역할을 하기 위한 네 가지

이것이 이 절의 뼈대다. 현장에서 보는 것 대부분이 이 넷 중 하나다.

| | 무엇인가 | 안 되면 |
|---|---|---|
| **① 위치** | 설계가 지정한 자리에 있는가 | 힘을 받아야 할 곳에 없다 |
| **② 피복** | 콘크리트가 철근을 얼마나 덮고 있는가 | 부식된다. 내화·부착 성능이 떨어진다 |
| **③ 정착** | 끝이 충분히 묻혀 힘을 넘겨받는가 | 뽑힌다. 철근이 있어도 힘이 전달 안 된다 |
| **④ 이음** | 이어진 부분이 힘을 계속 전달하는가 | 그 지점에서 끊긴다 |

### ② 피복이 왜 중요한가

**피복(被覆)** 은 철근 바깥면에서 콘크리트 표면까지의 거리다. 초보자는 "조금 모자라도 되겠지"라고 생각하기 쉽다. 그러나 피복은 세 가지를 동시에 한다.

| 하는 일 | 설명 |
|---|---|
| **부식 방지** | 콘크리트는 알칼리성이라 철근을 보호한다. 얇으면 공기·염분·물이 빨리 도달한다 |
| **부착 확보** | 철근과 콘크리트가 붙어야 힘이 넘어간다. 얇으면 그 부분이 터져 나간다 |
| **내화** | 화재 시 철근에 열이 전달되는 시간을 번다 |

**철근은 녹슬면 부피가 는다.** 늘어난 부피가 덮고 있는 콘크리트를 밀어내고, 콘크리트가 떨어져 나가면 철근이 더 빨리 녹슨다. 한 번 시작되면 가속된다.

그래서 피복은 **물과 염분이 닿는 조건일수록 크게** 정해진다. 흙에 접하는 면, 물에 접하는 면, 외기에 노출되는 면이 실내보다 두껍다. **같은 구조물 안에서도 면마다 값이 다르다.** 도면에서 그 면의 값을 읽어야 한다.

### ③ 정착과 ④ 이음

철근은 콘크리트 속에 충분히 묻혀 있어야 힘을 주고받는다. 끝이 어중간하게 끊겨 있으면 당길 때 그냥 빠진다.

| 용어 | 무엇인가 |
|---|---|
| **정착길이** | 철근이 힘을 온전히 전달받기 위해 콘크리트에 묻혀 있어야 하는 길이 |
| **이음(겹침이음)** | 두 철근을 겹쳐 나란히 두어 힘을 넘기는 방식 |
| **기계적 이음 · 용접이음** | 커플러나 용접으로 직접 잇는 방식 |
| **표준갈고리** | 끝을 구부려 뽑힘 저항을 더하는 처리 |

**이음 위치는 아무 데나가 아니다.** 힘을 많이 받는 구간에서 잇는 것은 약한 지점을 가장 위험한 곳에 두는 것이다. 그래서 설계는 **힘이 작은 구간에 이음이 오도록** 배치한다. 그리고 여러 철근의 이음이 같은 단면에 몰리지 않도록 **엇갈리게** 둔다.

> **이음 위치를 현장에서 바꾸는 것은 길이 조정이 아니라 설계 변경이다.**

철근이 짧아서, 혹은 반입 길이가 안 맞아서 위치를 옮기고 싶은 상황은 자주 생긴다. 그때 필요한 것은 현장의 판단이 아니라 1-6의 기술질의다.

## 기본 Flow

```text
 ①설계도서 · 구조도면 확인
    ↓
 ②시공상세도(배근시공도) 작성 · 승인   ◆ 승인 없이 가공하지 않는다
    ↓
 ③자재 반입 · 검수
    ↓
 ④가공 (절단 · 절곡)
    ↓
 ⑤조립 (배근 · 결속 · 스페이서)
    ↓
 ⑥자체점검
    ↓
 ⑦배근검측                          ◆ 거푸집을 닫기 전
    ↓
 ⑧거푸집 마감 · 매립물 확인
    ↓
 ⑨콘크리트 타설로 인계
```

이 Flow는 1-1의 시공 기본 Flow와 거의 그대로 겹친다. **철근공사는 시공 기본 Flow가 가장 교과서적으로 드러나는 공종**이다.

### ① 설계도서 · 구조도면 확인

구조도면, 구조일반사항, 시방서를 본다.

**구조일반사항**에 정착길이, 이음길이, 피복, 표준갈고리 형상, 이음 허용 위치가 정리되어 있는 경우가 많다. 개별 부재 도면만 보고 이것을 놓치면 전체가 어긋난다.

| 읽어야 하는 것 | 왜 |
|---|---|
| 부재별 철근 규격·개수·간격 | 물량과 배치의 근거 |
| **피복 두께 (면별로)** | 면마다 다르다 |
| 정착·이음 길이와 허용 위치 | 현장이 정할 수 없는 값 |
| 개구부·단부·접합부 보강 | **가장 자주 누락되는 부분** |
| 매립물·관통 슬리브 위치 | 철근과 자리를 다툰다 |

### ② 시공상세도 작성과 승인 — 첫 번째 Hold Point

구조도면은 "무엇이 어디에 몇 개"를 말하지, **"이 철근을 몇 미터로 잘라 어떻게 구부려 어떤 순서로 넣는가"** 를 말하지 않는다. 그것을 그리는 것이 시공상세도다(1-1 ②).

여기서 결정되는 것이 **가공 치수**다. 그리고 가공은 되돌리기 어렵다. 잘못 자른 철근은 짧아진 채로 남고, 잘못 구부린 철근은 펴서 다시 쓰면 성능이 떨어진다.

**그래서 승인 전에 가공하지 않는다.** 공정이 급하다는 이유로 미리 가공하면, 승인 과정에서 도면이 바뀔 때 그만큼이 손실이 된다.

**→ 넘어가는 조건:** 시공상세도가 승인되었다. 조건부 승인이면 조건이 무엇인지 확인되었다(1-7).

### ③ 자재 반입 · 검수

| 보는 것 | 왜 |
|---|---|
| **규격 · 강도 등급 · 지름** | 설계와 같은가 |
| **품질 증명서류** | 그 재료가 기준을 만족하는가 |
| 실물 표시 (각인 · 표시) | **서류와 실물이 이어지는가** |
| 외관 (심한 녹 · 휨 · 손상) | 부착과 단면에 영향 |
| 보관 상태 | 땅에 닿게 두면 녹슨다 |

**서류와 실물의 연결이 이 칸의 핵심이다.** 서류상 규격과 실물 표시가 다르면, 그것은 "서류 오류"일 수도 있고 "다른 물건이 온 것"일 수도 있다. 둘의 결과가 완전히 다르므로 **현장에서 판단하지 않고 확인 절차를 탄다.**

가벼운 표면 녹은 대개 문제가 되지 않는다. 문제는 **단면이 줄어들 정도의 부식**과 **떨어져 나오는 층상 녹**이다. 판정 기준은 시방서가 정한다.

### ④ 가공

절단하고 구부린다. 승인된 시공상세도대로 한다.

구부릴 때 **구부림 반지름**이 중요하다. 너무 급하게 꺾으면 그 지점의 철근이 손상된다. 규격별 최소 반지름이 기준에 정해져 있다.

**이미 구부린 철근을 펴서 다시 구부리는 것**은 원칙적으로 안 된다. 그 부분은 이미 한 번 소성변형을 겪었다.

### ⑤ 조립

도면대로 배치하고 결속한다. 이 칸에서 실제로 하는 일이 넷의 ①~④를 물리적으로 구현하는 것이다.

**스페이서**가 피복을 만든다. 철근을 거푸집에서 띄워 주는 받침이다. 이것이 부족하거나 밀리면 철근이 거푸집에 붙고, 그 자리는 피복이 0이 된다. 타설 중 사람이 밟고 다니면 위쪽 철근이 처져 피복이 바뀐다.

**간격**도 봐야 한다. 너무 좁으면 콘크리트의 굵은 골재가 사이로 못 들어가서 **속이 빈다**. 철근을 촘촘히 넣는 것이 항상 안전한 것이 아니다.

### ⑥ 자체점검

검측을 부르기 전에 스스로 본다(1-7). 자체점검이 부실한 채로 검측을 부르면 지적사항이 쌓이고, 결국 공정이 더 늦는다.

### ⑦ 배근검측 — 결정적 Hold Point

**이 절에서 가장 중요한 한 칸이다.**

거푸집을 닫고 콘크리트를 치면 철근은 영원히 보이지 않는다. 문제가 있어도 확인할 방법이 없고, 고치려면 콘크리트를 깨야 한다.

```text
   검측 전   철근이 보인다      → 고칠 수 있다. 비용: 사람과 시간
   은폐 후   철근이 안 보인다   → 깨야 한다. 비용: 구조물과 공정
```

**검측에서 보는 것**

| 항목 | 내용 |
|---|---|
| 규격 · 개수 · 간격 | 도면과 대조 |
| **피복** | 면별 기준값. 스페이서 상태 |
| 정착 · 이음 길이 | 기준 충족 |
| **이음 위치** | 허용 구간 안, 엇갈림 |
| 보강근 | 개구부·단부·접합부 |
| 결속 상태 | 타설 중 흐트러지지 않는가 |
| 매립물 · 슬리브 | 위치, 주변 보강 |
| 청소 상태 | 바닥의 이물·물·흙 |

**검측 통보와 대기 시간은 프로젝트 절차가 정한다**(1-7). "다 됐으니 지금 봐 달라"가 통하지 않는 경우가 많다. 이것을 공정계획에 넣지 않으면 매번 하루씩 밀린다.

**→ 넘어가는 조건:** 검측에 합격했다. 조건부면 조건이 이행되고 확인되었다.

### ⑧ 거푸집 마감 · 매립물 확인

거푸집을 닫는다. **이 순간부터 철근은 보이지 않는다.**

닫기 직전에 마지막으로 보는 것이 있다.

- 안에 떨어진 이물 (결속선 토막, 자재, 물, 흙)
- 매립 앵커·슬리브·전기박스의 위치
- 스페이서가 밀리지 않았는가

### ⑨ 콘크리트 타설로 인계

배근이 확인된 상태를 콘크리트 담당에게 넘긴다. 다만 **타설 중에도 철근공사는 끝나지 않는다.** 타설 중 배근이 흐트러지면 그것은 철근의 문제로 남는다. 그래서 타설 중 배근 감시가 필요하다.

## Hold Point — 되돌릴 수 없는 지점

```text
 ② 시공상세도 승인     → 지나면 그 치수로 전량 가공한다
 ④ 가공              → 자르면 짧아진 채로 남는다
 ⑦ 배근검측           → 지나면 거푸집을 닫는다
 ⑧ 거푸집 마감         → 닫으면 다시 못 본다
 (콘크리트 타설)       → 치면 깨야만 확인된다
```

**⑦이 이 교재 전체에서 가장 전형적인 Hold Point다**(1-7). 이유가 순수하게 비가역성이기 때문이다. 검측을 지나기 전과 후의 수정 비용 차이가 수십 배가 된다.

## 정상 판정 기준

| 항목 | 정상 |
|---|---|
| **시공상세도** | 승인된 최신본이고, 현장 적용본과 같다 |
| **자재** | 규격·등급 일치, 증명서류와 실물 표시가 연결된다 |
| **가공** | 승인 치수, 구부림 반지름 준수 |
| **위치 · 간격** | 도면 범위 안. 굵은 골재가 통과할 간격 확보 |
| **피복** | 면별 기준값 충족. 스페이서 충분·고정 |
| **정착 · 이음 길이** | 기준 이상 |
| **이음 위치** | 허용 구간 안, 같은 단면에 몰리지 않음 |
| **보강근** | 개구부·단부·접합부 누락 없음 |
| **결속** | 타설 중 이동하지 않을 정도 |
| **청소** | 이물·물·흙 없음 |
| **검측** | 합격 기록이 있고, 지적사항이 조치·확인됨 |

## 이상의 신호와 그 의미

| 보이는 것 | 의심할 것 | 왜 |
|---|---|---|
| **피복이 안 나온다** | 스페이서 부족·밀림, 거푸집 위치, 철근 간섭 | 원인이 여럿이고 조치가 다르다 |
| 한 면만 피복이 부족하다 | 거푸집 위치 또는 철근망 전체가 밀렸다 | 단순 스페이서 문제가 아니다 |
| **이음 위치가 도면과 다르다** | 자재 길이 맞춤을 위해 현장이 옮겼다 | 설계 사안이다. 현장 재량이 아니다 (1-6) |
| 이음이 한 단면에 몰려 있다 | 시공 편의 | 그 단면이 약해진다 |
| 철근 간격이 너무 좁다 | 도면 해석 오류 또는 겹침 | 골재가 못 들어가 속이 빈다 |
| **개구부 주변에 보강근이 없다** | 상세도 누락 또는 조립 누락 | 가장 자주 빠지는 항목 |
| 매립물 자리에 철근이 지나간다 | 도면 간 간섭 | 어느 쪽을 옮길지는 설계 판단 |
| 서류와 실물 표시가 다르다 | 자재 혼입 또는 서류 오류 | 추적성이 끊긴다. 현장 판단 금지 |
| 심하게 녹슬어 켜가 일어난다 | 보관 불량 | 단면 감소와 부착 저하 |
| **검측 전에 거푸집이 닫혔다** | 공정 압박, 절차 인식 부족 | Hold Point를 지나쳤다 (1-7) |
| 타설 중 철근이 흔들린다 | 결속 부족, 지지 부족 | 타설 후 위치가 달라진다 |
| 타설 후 표면에 철근 자국 | 피복 미확보 | 이미 은폐된 상태의 증거 |
| 도면 개정본이 늦게 왔다 | 형상관리 문제 | 이미 가공·조립된 것이 있다 (1-8) |
| 결속선 토막이 바닥에 남아 있다 | 청소 미흡 | 표면 녹 자국과 결함의 원인 |

## 자주 혼동하는 개념

| | | 차이 |
|---|---|---|
| 구조도면 | 시공상세도 | 전자는 무엇이 어디에, 후자는 어떻게 만들어 넣는가 |
| 피복 | 간격 | 전자는 표면까지 거리, 후자는 철근 사이 거리 |
| 정착 | 이음 | 전자는 끝을 묻는 것, 후자는 둘을 잇는 것 |
| 겹침이음 | 기계적 이음 | 겹쳐 두는가, 커플러로 직접 잇는가 |
| 이음길이 | 이음위치 | 길이는 얼마나, 위치는 어디서 |
| 자체점검 | 검측 | 전자는 스스로, 후자는 정해진 주체가 (1-7) |

## 잘못 이해하면 생기는 일

**승인 전에 가공하면** — 도면이 바뀌면 그만큼이 버려진다. 공정을 당기려다 자재와 시간을 함께 잃는다.

**피복을 "조금 모자라도 되는 것"으로 보면** — 부식이 시작되고, 시작되면 가속된다. 완공 몇 년 뒤에 드러난다.

**철근을 많이 넣으면 안전하다고 생각하면** — 간격이 좁아져 콘크리트가 못 들어간다. 속이 빈 부재가 된다.

**이음 위치를 현장에서 옮기면** — 힘을 많이 받는 구간에 약한 지점이 생긴다. 겉으로는 아무 차이가 없어 보인다.

**개구부 보강근을 빠뜨리면** — 그 모서리에서 균열이 시작된다. 작아 보이는 누락이 구조 문제가 된다.

**검측 전에 거푸집을 닫으면** — 확인 방법이 사라진다. 뜯든가, 위험을 안고 가든가 둘 중 하나다. 어느 쪽도 현장이 혼자 정할 수 없다.

**타설 중 배근을 안 보면** — 검측은 합격했는데 실제 구조물의 배근은 다르다. 검측 기록이 실제를 증명하지 못한다.

**은폐 전 사진을 안 남기면** — 나중에 "제대로 했다"를 증명할 수 없다(1-10 ④). 잘했어도 증명 못 하면 잘한 것이 아니게 된다.

**검측 통보 시간을 공정에 안 넣으면** — 매 부재마다 반나절씩 밀린다. 누적되면 큰 지연이다(1-2).

## 스스로 확인

1. 철근을 콘크리트에 넣는 이유를 힘의 관점에서 설명해 보라.
2. 철근이 제 역할을 하기 위한 네 가지는 무엇인가.
3. 피복이 하는 세 가지 일은 무엇인가. 왜 면마다 값이 다른가.
4. 철근이 녹슬면 왜 가속되는가.
5. 정착과 이음은 어떻게 다른가.
6. 이음 위치를 설계가 지정하는 이유는 무엇인가. 현장이 옮기면 무엇이 문제인가.
7. 시공상세도 승인 전에 가공하지 않는 이유는 무엇인가.
8. 배근검측이 이 Flow에서 가장 결정적인 Hold Point인 이유는 무엇인가.
9. 철근을 촘촘히 넣는 것이 항상 안전하지 않은 이유는 무엇인가.
10. 검측에 합격했는데도 타설 중 배근을 봐야 하는 이유는 무엇인가.
11. 자재 서류와 실물 표시가 다를 때 현장이 판단하면 안 되는 이유는 무엇인가.
