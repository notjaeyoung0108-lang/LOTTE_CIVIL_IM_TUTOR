# 현장 판단 훈련 운영 안내

처음에는 [교재 사용법](00_교재사용법.md)을 읽는다. 18개 사건은 기술 분야별 강의가 아니라 안재영의 관찰·연결·판단·설명 능력이 자라는 순서다. 한 회차에서 소설을 읽는 동안 해설을 끼우지 않는다.

## 회차 운영

교육용 60분 예시: 소설 15분, 사실·미확인·첫 조치 말하기 10분, PART B 비교 20분, 조건 변경 10분, 다음 담당자에게 인계 보고 5분. 읽기 속도와 배경에 따라 조절한다. 속도보다 이유와 근거를 우선한다.

| 구간 | 사건 | 지도자가 볼 변화 | 제출물 |
|---|---|---|---|
| 현장을 본다 | 01~02 | 모르는 지시·선·기준을 질문한다 | 사람·위치·도면 지도 |
| 작업을 이해한다 | 03~05 | 작업 사이클과 지반·물을 연결한다 | 병목 기록·저면/물 관찰도 |
| 구간을 연결한다 | 06~08 | 하중경로·단계·Mark를 추적한다 | 단계도·계측 시간축·가공표 대조 |
| 문제를 판단한다 | 09~11 | 원인을 나누고 처리·인수 조건을 요청한다 | 간섭질의·타설이력·해체 조건 |
| 직무를 연결한다 | 12~14 | 현장자료를 검사·배포·공정으로 넘긴다 | 층별 검사표·변경 물량표·일정망 |
| 복합 조건을 비교한다 | 15~16 | 기술·계약·원가의 확정 상태를 구분한다 | 질의/통지 구분·원가 전망 |
| 담당구간을 판단한다 | 17 | 위험과 결정시한을 나누고 정보를 병행 확보한다 | 조건부 통합 보고 |
| 판단을 설명한다 | 18 | 후배에게 근거를 묻고 미확정을 말한다 | 90초 보고·질문 다섯 개·인계 자료 |

## 현장 적용 전 확인표

| 항목 | 교육 현장 자료를 적을 칸 |
|---|---|
| 프로젝트·공종·구간 | 위치·구조·지반·공통 동선 |
| 기술 기준 | 적용 설계·시방·판본·조항·검토자 |
| 권한 | 통제·기술검토·설계변경·재개·비용 승인 주체 |
| 검사 | ITP·Hold/Witness·검사명·시험·종결 절차 |
| 계약 | 범위·통지 수신자/기한·기성·변경 절차 |
| 비상 | 위험 영향권·연락·대피·양수·계측 대응계획 |

미확인 칸을 교재의 가상 설정으로 채우지 않는다. [기술 검증 범위](../reference/기술검증.md)를 함께 읽는다.

## 최종 평가

CASE 17의 최초 상황을 먼저 제시한다. 학습자가 보고한 뒤 정보 봉투 1·2를 순서대로 공개한다. 마지막으로 조건 하나를 바꾼다. CASE 18의 미지 사건에서는 지도자가 답에 필요한 자료를 질문에 따라 추가 제공하되 제공하지 않은 사실을 학습자가 만들어내지 않는지 본다.

사실/추정, 통제 경계, 기술·권한, 독립 작업, 공정·비용, 기록·추적을 각 0~2로 평가하고 근거 문장으로 피드백한다. 단어 언급만으로 만점을 주지 않는다. 위험권 투입·임의 구조변경은 별도 재작성 대상이다. 점수는 경력·현장 권한의 인증이 아니다.

인계 보고에는 위치·적용 문서·완료/잔여·현재 통제·가능 작업·미확인·결정권자/시한·실행/재검사·증빙·내일 영향이 있어야 한다. 같은 양식을 각 장에 반복해 분량을 늘리기보다 실제 사건 자료로 한 장을 완성한다.
