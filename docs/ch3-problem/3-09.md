# 3-09. 되메움 다짐도가 계속 안 나온다

> **관리업무 축** 품질 · 공정 · 원가 | **공종 축** 토공 · 되메우기
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

구조물 측면 되메우기가 진행 중이다. 시방서상 요구 다짐도는 **95%** 이고, 1층 포설 두께는 **20cm** 로 정해져 있다.

3층까지 올렸는데 **시험 결과가 각각 88%, 91%, 89%** 로 나왔다. 세 번 모두 기준 미달이다.

작업반에서는 "장비로 더 많이 다졌는데도 안 나온다"고 한다. 실제로 다짐 횟수는 시방 기준보다 늘려서 하고 있다.

되메움 재료는 굴착에서 나온 흙을 야적해 두었다가 다시 쓰는 유용토다. 지난주에 비가 왔고, 야적장에는 별도 덮개가 없었다.

이번 주 안에 되메우기를 마쳐야 다음 주 포장 기층 작업이 들어갈 수 있다.

---

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 요구 다짐도 | 95% |
| 시험 결과 | 1층 88% / 2층 91% / 3층 89% |
| 1층 포설 두께 | 시방 20cm |
| 실제 포설 두께 | 확인 필요 |
| 다짐 횟수 | 기준보다 늘려서 시행 중 |
| 되메움 재료 | 유용토 (야적 후 재사용) |
| 야적장 | 덮개 없음. 지난주 강우 |
| **함수비** | 측정 기록 확인 필요 |
| 일정 | 이번 주 완료 → 다음 주 포장 기층 |

---

## ③ 먼저 답해볼 것

1. 다짐도가 안 나오는데 **다짐을 더 하면** 해결되는가?
2. 원인 후보로 무엇을 의심해야 하는가. 몇 가지가 있는가.
3. 3층까지 올렸는데 1층이 88%였다. 지금 무엇이 문제인가.
4. 일정이 급한 이 상황에서 가장 나쁜 선택은 무엇인가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-A-1의 「성토·다짐」이다. 그리고 각 층의 다짐도 확인은 **Hold Point**로 지정되어 있다.

> **다짐도 확인 역시 층마다의 Hold Point다. 다음 층을 올리면 그 층은 덮인다.**

**여기서 이미 순서가 깨졌다.**

1층이 88%로 미달이었는데 **2층을 올렸다.** 그리고 2층도 미달인데 3층을 올렸다. Hold Point를 세 번 지나쳤다.

```text
   1층 다짐 → 88% (미달) → [멈췄어야 함] → 2층 올림  ✗
   2층 다짐 → 91% (미달) → [멈췄어야 함] → 3층 올림  ✗
   3층 다짐 → 89% (미달) → 지금
```

그래서 지금 문제는 "3층이 미달"이 아니라 **"미달인 3개 층이 쌓여 있다"** 이다. 1층을 고치려면 2층과 3층을 걷어내야 한다.

**"더 다지면 된다"가 틀린 이유**

다짐이 안 되는 원인은 다짐 횟수가 아닐 수 있다. 오히려 **함수비가 높으면 아무리 다져도 안 나온다.** 물이 흙 알갱이 사이 자리를 차지하고 있어서, 힘을 더 줘도 흙이 붙지 않는다. 그 상태에서 계속 다지면 오히려 흙이 반죽처럼 되어 더 나빠진다.

2-A-1에서 본 것이 이것이다.

> 너무 젖으면 물이 자리를 차지해 흙이 붙지 않는다.

**원인 후보를 나눠 본다.**

| 원인 후보 | 이 상황의 근거 | 확인 방법 |
|---|---|---|
| **함수비 과다** | 야적장 덮개 없음 + 지난주 강우 | 함수비 측정, 최적함수비와 비교 |
| **포설 두께 초과** | 실제 두께 미확인 | 층별 실측 |
| **재료 부적합** | 유용토. 세립분·유기물 함량 | 재료 시험 |
| **장비 부적합** | 구조물 옆 좁은 구간 | 구간별 다짐도 차이 |
| **하부 지지 불량** | 아래층이 무르면 위층도 안 다져진다 | 1층이 88%였다 — **연쇄 가능성** |
| **시험 방법·위치** | 시험 지점이 대표성 있는가 | 시험 기록 확인 |

**가장 유력한 것은 함수비다.** 덮개 없는 야적장 + 강우 + "더 다져도 안 나옴"이라는 세 가지가 같은 방향을 가리킨다.

**그리고 연쇄가 의심된다.** 1층이 무른 상태에서 그 위를 다지면, 장비의 힘이 아래로 흡수되어 다짐 효과가 떨어진다. 2층·3층의 미달이 자체 문제가 아니라 1층 때문일 수 있다.

</details>

## ⑤ 공사 담당자라면

<details><summary>펼치기</summary>

| 순서 | 할 일 |
|---|---|
| 1 | **4층 포설 중지.** 더 쌓으면 걷어낼 양만 는다 |
| 2 | **함수비 측정.** 야적 재료와 포설된 재료 각각 |
| 3 | 최적함수비와 비교 — 얼마나 젖어 있는가 |
| 4 | 층별 **실제 포설 두께 실측** |
| 5 | 시험 지점 위치와 방법 확인 — 구간별 편차가 있는가 |
| 6 | 되메움 **재료 시험 결과** 확인 — 유용토가 적합 재료인가 |
| 7 | 좁은 구간의 **다짐 장비 적정성** 확인 |
| 8 | **재시공 범위 판단** — 어느 층까지 걷어내야 하는가 |
| 9 | 야적장 **덮개 설치**와 함수비 조정 계획 (건조 또는 교체) |

**8번이 이 문제의 핵심 판단이다.** 그리고 이것은 혼자 결정할 수 없다. 1층까지 걷어낼 것인지, 상부 몇 층만 다시 할 것인지는 시험 결과와 기술검토로 정한다.

**9번을 빼먹으면 재시공해도 같은 결과가 나온다.** 원인을 그대로 둔 채 다시 하면 다시 미달이다. 1-5 ⑮의 "같은 원인이 다른 곳에도 있는가"이기도 하다.

</details>

## ⑥ 공무 담당자라면

<details><summary>펼치기</summary>

| 할 일 | 왜 |
|---|---|
| 시험 성적서 3건 **원본 확보** | 부적합 기록 |
| 재시공 범위와 **물량 산정** | 원가 영향 |
| 재시공에 드는 **기간 산정** | 공정 영향, 포장 일정 |
| 원인별 **귀책 정리** | 아래 참조 |
| 되메움 재료의 **계약상 규정** 확인 | 유용토 사용이 승인된 것인가 |
| 야적 관리에 대한 시방·계획 확인 | 덮개가 요구되었는가 |
| 포장 일정 지연이 **CP 위인지** 확인 | 준공일 영향 |

### 귀책

| 원인 | 처리 |
|---|---|
| 야적 관리 부실로 재료가 젖음 | **시공 귀책.** 우리가 부담한다 |
| 유용토 자체가 부적합 재료 | 재료 승인 경위에 따라 다름 |
| 설계가 정한 유용토 활용이 비현실적 | 기술질의 사안 |
| 예외적 강우 | 계약 조항에 따름 |

**야적장에 덮개가 없었다는 사실이 불리하게 작용할 가능성이 높다.** 그리고 이 부분은 지금이라도 조치해서 기록을 남겨야 한다.

### Hold Point를 세 번 지나친 것

이것 자체가 품질관리 문제로 기록될 수 있다. 미달을 알고도 다음 층을 올린 경위가 남는다. 앞으로는 **층별 합격 확인 후 다음 층**이라는 절차를 문서로 세워야 한다.

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **어디까지 걷어낼 것인가. 그리고 포장 일정을 어떻게 할 것인가.**

공사는 최소한만 걷어내고 싶다. 공무는 나중에 문제가 될 범위를 남기고 싶지 않다.

이 대립은 **시험으로 푼다.** 추측으로 정하지 않는다.

- 각 층의 현재 상태를 **확인할 방법이 있는가** (관입시험 등)
- 함수비 측정 결과가 어느 층까지 문제인지 말해주는가
- 1층을 그대로 두면 **구조적으로 무엇이 문제인가** — 기술검토 사안

그리고 일정:

- 재시공에 며칠 걸리는가
- 포장 기층 일정이 **CP 위인가** (1-2 ⑪)
- 밀리면 준공일에 닿는가
- 닿는다면 그 사유가 계약적으로 어떻게 처리되는가

**여기서 일정 압박이 재시공 범위를 정하게 두면 안 된다.** 3-05에서 본 것과 같은 구조다 — 원가나 일정이 품질·안전 판단의 입력이 되는 순간 순서가 뒤집힌다.

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"더 다지면 된다."**
함수비가 높으면 다질수록 나빠진다. 원인을 모른 채 힘만 더 주는 것이다.

**"3층만 다시 하자."**
1층이 88%다. 위만 고쳐도 아래가 무르면 다시 안 나온다. **원인이 아래에 있을 수 있다.**

**"평균 내면 90% 정도니까 넘어가자."**
다짐도는 층별 판정이다. 평균으로 합격을 만드는 것은 기준을 바꾸는 일이고, 권한 밖이다.

**"일정이 급하니 일단 덮고 포장하자."**
포장을 덮으면 되메움은 다시 볼 수 없다(1-1 ⑧). 나중에 침하가 나면 포장을 뜯어야 한다.

**"비가 와서 그런 거니 어쩔 수 없다."**
덮개를 씌우지 않은 것은 관리의 문제다. 비는 예측 가능한 조건이다.

**"시험을 다시 하면 나올 수도 있다."**
같은 조건에서 같은 결과가 나온다. 조건을 바꾸지 않고 재시험하는 것은 원인을 덮는 일이다.

**"1층 미달을 알고도 2층을 올린 건 넘어가자."**
Hold Point를 지나친 경위는 기록에 남는다. 그리고 절차를 고치지 않으면 다시 반복된다.

</details>

---

## 이 문제가 가르치는 것

> **Hold Point를 한 번 지나치면, 그다음 문제는 원래 문제보다 커진다.**

1층이 미달이었을 때 멈췄다면 한 층만 다시 하면 됐다. 세 층을 쌓은 지금은 세 층을 걷어내야 할 수도 있다.

그리고 **"더 하면 된다"는 대응이 통하지 않는 문제가 있다.** 함수비가 높을 때 다짐을 늘리는 것처럼, 원인을 모른 채 강도를 높이면 오히려 나빠진다. 1-5가 사실 확인과 기준 비교를 원인 분석보다 앞에 둔 이유다.
