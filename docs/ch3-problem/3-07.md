# 3-07. 여굴이 계속 많이 난다

> **관리업무 축** 원가 · 자원 · 품질 | **공종 축** 토공 · 굴착
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

계획고 부근 바닥 정리 작업이 진행 중이다.

측량 결과, 최근 3일간 작업한 구간에서 **여굴이 평균 15cm** 발생했다. 시방서가 정한 허용 여굴은 **10cm**다.

여굴은 규정에 따라 빈배합 콘크리트로 채우고 있다. 그만큼 콘크리트 물량이 늘고 있고, 이번 달 토공 원가가 실행예산을 넘기 시작했다.

작업반장은 "지반이 무르고 장비가 크다 보니 어쩔 수 없다"고 한다. 굴착 장비는 대형 백호 1대이고, 야간 작업은 없다. 작업은 주간 1개 조로 진행된다.

이번 주 안에 바닥 정리를 마치고 다음 주 월요일 버림 콘크리트를 쳐야 후속 일정이 맞는다.

---

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 허용 여굴 | 10cm |
| 실제 여굴 | 최근 3일 평균 15cm |
| 처리 방법 | 빈배합 콘크리트 충전 |
| 원가 | 토공 부문 실행예산 초과 진행 중 |
| 장비 | 대형 백호 1대 |
| 작업조 | 주간 1개 조 |
| 반장 의견 | "지반이 무르고 장비가 커서" |
| 일정 | 이번 주 바닥 정리 완료 → 다음 주 월 버림 |

---

## ③ 먼저 답해볼 것

1. 여굴이 **왜 문제**인가. 단순히 콘크리트 값이 더 드는 것인가?
2. "장비가 커서 어쩔 수 없다"는 설명은 받아들일 만한가.
3. 여굴을 흙으로 채우면 왜 안 되는가.
4. 원가가 초과되는 이 상황에서 **가장 먼저** 해야 할 일은 무엇인가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-A-1의 `⑦ 바닥 정리·여굴 처리`다. 그리고 「이상의 신호」 표의 **"여굴이 계속 많이 난다 → 장비·방법·숙련도 문제 → 원가가 새고 있다"** 에 해당한다.

**여굴이 문제인 이유는 둘이다.**

| | 문제 |
|---|---|
| **원가** | 규정 재료로 채워야 하므로 비용이 는다. 그리고 계속 샌다 |
| **품질** | 잘못 채우면 지지력이 달라진다. 부등침하로 이어진다 |

흙으로 채우면 안 되는 이유가 두 번째다. **느슨한 흙은 원지반만큼 지지하지 못한다.** 구조물이 그 위에 올라가면 그 부분만 더 가라앉는다. 눈에 보이지 않다가 균열로 나타난다.

**"어쩔 수 없다"는 설명은 원인이 아니다.**

여굴은 여러 원인이 겹쳐 난다. 하나로 단정하면 대응이 틀린다.

| 원인 후보 | 확인 방법 |
|---|---|
| **장비가 크다** | 계획고 부근을 소형 장비나 인력으로 바꿨는가 |
| **마무리 방법** | 마지막 얼마를 남기고 조심스럽게 하는 절차가 있는가 |
| **숙련도** | 기사가 바뀌었는가. 구간별 편차가 있는가 |
| **지반이 무르다** | 실제로 연약한가. 그렇다면 2-A-1 ⑤ 보고 사안이다 |
| **물** | 바닥에 물이 고여 지반이 물러졌는가 (2-D-1) |
| **측량·기준** | 계획고를 잘못 보고 있지는 않은가 |
| **시간 압박** | 일정에 쫓겨 빨리 긁고 있는가 |

**마지막 항목을 놓치기 쉽다.** 이번 주 안에 끝내야 한다는 압박이 여굴을 키우고 있을 수 있다. 그러면 일정을 지키려다 원가가 새고 품질이 나빠지는 구조가 된다.

**그리고 이것은 이미 발생한 것과 앞으로 발생할 것이 다른 문제다.**

- 이미 난 여굴 → 규정대로 처리한다. 되돌릴 수 없다
- 앞으로 날 여굴 → **지금 줄일 수 있다.** 관리의 대상은 여기다 (1-4 ⑤)

</details>

## ⑤ 공사 담당자라면

<details><summary>펼치기</summary>

| 순서 | 할 일 |
|---|---|
| 1 | **구간별·일자별·기사별로 여굴량을 나눠 본다** — 평균 뒤에 편차가 있다 |
| 2 | 계획고 부근 **마무리 방법 확인** — 어디서부터 소형 장비/인력인가 |
| 3 | 바닥 **물 고임 여부** 확인 |
| 4 | 실제 지반이 무른지 확인 — 무르면 별도 보고 사안 |
| 5 | 측량 기준점과 계획고 재확인 |
| 6 | **마무리 절차를 정해 작업 지시에 반영** — 남길 두께, 장비, 확인 방법 |
| 7 | 개선 후 여굴량을 **같은 방법으로 다시 측정** |
| 8 | 이미 난 여굴은 규정대로 처리하고 **위치·수량 기록** |

**1번이 핵심이다.** "평균 15cm"는 원인을 가리지 않는다. 특정 구간이나 특정 날짜에 몰려 있다면 원인이 좁혀진다. 고르게 퍼져 있다면 방법 자체의 문제다.

**6번이 실질적인 조치다.** 예를 들어 마지막 얼마를 남기고 소형 장비로 바꾸는 식이다. 구체적인 두께와 방법은 지반과 장비 조건에 따라 정해야 한다.

</details>

## ⑥ 공무 담당자라면

<details><summary>펼치기</summary>

| 할 일 | 왜 |
|---|---|
| 여굴 **수량과 충전 물량**을 구간별로 집계 | 원가 추적의 기초 |
| 실행예산 대비 **발생원가** 정리 | 얼마나 초과했나 |
| **잔여예상원가 재산정** | 아래 참조 |
| 초과의 **원인 분류** | 시공 관리인가 지반 조건인가 |
| 계약 내역의 여굴 처리 항목 확인 | 별도 정산인가 포함인가 |
| 개선 조치 전후의 수치 | 효과 입증 |

### 잔여를 원래 단가로 계산하지 않는다

1-4 ⑤에서 말한 가장 흔한 실수가 여기 적용된다.

> 남은 구간을 여전히 계획 여굴 10cm로 계산하면, 전망이 실제보다 낙관적으로 나온다.

조건을 바꾸지 않는 한 남은 구간도 15cm가 난다. 개선 조치를 **계획**한 것만으로 전망을 고치면 안 된다. **효과가 확인된 뒤**에 반영한다(1-4 ⑩).

### 원인 분류가 정산을 가른다

| 원인 | 처리 |
|---|---|
| 시공 방법·장비·숙련도 | **시공 귀책.** 우리가 부담한다 |
| 실제 지반이 조사와 다르게 무르다 | 현장조건 상이 가능성 (1-10) |
| 설계 허용치가 이 지반에 비현실적 | 설계 사안. 기술질의 |

**섞여 있을 수 있다.** 구간별 편차를 보면 나뉜다. 전부 조건 탓으로 돌리는 것도, 전부 시공 탓으로 받는 것도 사실과 다를 수 있다.

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **일정을 지킬 것인가, 여굴을 줄일 것인가 — 그리고 그 대가가 각각 얼마인가.**

지금 구조는 이렇다.

```text
   이번 주 안에 끝내야 한다
        ↓
   빨리 긁는다
        ↓
   여굴이 는다
        ↓
   충전 콘크리트가 는다 → 원가 초과
   그리고 충전 작업 자체에 시간이 든다 → 일정도 손해
```

**서두르는 것이 일정에도 이득이 아닐 수 있다.** 여굴 충전에 드는 시간과 양생 시간이 있기 때문이다. 이것을 숫자로 놓고 비교해야 한다.

합의할 것:

- 마무리 방법을 바꾸면 **하루 진도가 얼마나 줄어드는가**
- 그만큼 **버림 일정이 며칠 밀리는가**
- 밀린 일정이 **CP 위인가** (1-2 ⑪)
- 여굴이 줄면 **원가가 얼마나 절약되는가**
- 두 값을 비교했을 때 어느 쪽인가

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"흙으로 채우면 싸게 끝난다."**
지지력이 달라진다. 부등침하로 구조물에 균열이 간다. 눈앞의 비용을 아끼고 되돌릴 수 없는 문제를 만든다.

**"장비가 커서 어쩔 수 없다."**
원인 후보 중 하나일 뿐이다. 그리고 바꿀 수 있는 원인이다 — 계획고 부근만 소형으로.

**"평균 15cm니까 대책을 세우자."**
평균은 원인을 가린다. **나눠 봐야** 무엇을 고칠지 나온다.

**"이미 난 건 어쩔 수 없으니 그냥 가자."**
이미 난 것은 그렇다. 그러나 **앞으로 날 것은 줄일 수 있다.** 관리 대상은 미래다.

**"일정이 급하니 일단 끝내고 보자."**
여굴 충전에도 시간이 든다. 서두르는 것이 일정에도 손해일 수 있다.

**"지반 탓이니 추가 정산 받자."**
구간별 편차를 보지 않고 단정한 것이다. 근거 없이 주장하면 신뢰를 잃는다.

**"개선하기로 했으니 전망을 고치자."**
효과가 확인된 뒤에 고친다. 그러지 않으면 전망이 희망의 합이 된다.

</details>

---

## 이 문제가 가르치는 것

> **"어쩔 수 없다"는 원인이 아니다. 그리고 평균은 원인을 가린다.**

이 문제에는 3-01처럼 당장 무너질 위험이 없다. 그래서 더 어렵다. 위험이 없으면 그냥 넘어가기 쉽고, 그동안 원가는 계속 샌다.

1-4가 말한 **"이미 쓴 돈은 바꿀 수 없지만 앞으로 쓸 돈은 바꿀 수 있다"** 가 실제로 적용되는 자리다.
