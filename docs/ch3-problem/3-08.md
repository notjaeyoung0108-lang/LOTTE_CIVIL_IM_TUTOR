# 3-08. 법면에 균열이 보인다

> **관리업무 축** 문제처리 · 안전 | **공종 축** 토공 · 굴착
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

부지 외곽의 오픈컷 구간이다. 흙막이 없이 법면을 깎아 자립시킨 구간으로, 굴착 깊이는 약 6m다.

오전 순찰 중, 법면 **어깨 부근 지표에 세로 방향 균열**이 보인다. 길이 4~5m, 폭은 손가락이 들어갈 정도다. 어제 순찰 때는 없었던 것으로 기억한다.

법면 아래쪽에는 소량의 흙이 흘러내려 쌓여 있다.

이 법면 아래에서는 배수관 부설 작업이 진행 중이다. 현재 인원 4명과 소형 장비 1대가 들어가 있다. 어제 비가 왔고, 오늘은 그쳤다.

---

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 구간 | 오픈컷, 굴착 깊이 약 6m |
| 법면 상태 | 어깨 부근 세로 균열 4~5m, 폭 손가락 정도 |
| 어제 | 균열 없었던 것으로 기억 |
| 법면 하부 | 소량의 흙이 흘러내려 쌓임 |
| 현재 작업 | 법면 아래 배수관 부설, **인원 4명 + 소형 장비 1대** |
| 강우 | 어제 있었음, 오늘 그침 |
| 설계 법면 기울기 | 확인 필요 |
| 계측 | 이 구간은 계측기 미설치 |

---

## ③ 먼저 답해볼 것

1. 지금 **가장 먼저** 해야 할 일은 무엇인가. 1초도 미루면 안 되는 것이 있는가.
2. 세로 균열과 하부에 쌓인 흙은 각각 무엇을 뜻하는가.
3. 비가 이 상황과 관계가 있는가.
4. 이 판단에서 다른 것보다 우선하는 것이 있는가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-A-1의 「이상의 신호와 그 의미」 표에서 두 줄이 동시에 켜졌다.

| 보이는 것 | 의미 |
|---|---|
| **법면에 세로 균열** | **붕괴 전조.** 즉시 통제, 접근 금지 |
| 법면 아래에 흙이 쌓인다 | **이미 부분 붕락 중.** 진행 중이다 |

**두 신호가 같은 방향을 가리킨다.** 하나는 앞으로 무너질 징후이고, 하나는 이미 움직이고 있다는 증거다.

**세로 균열이 왜 전조인가.** 법면이 미끄러지려 할 때, 미끄러지는 흙덩이와 뒤쪽 흙 사이가 벌어진다. 그것이 어깨에 균열로 나타난다. 즉 **이미 분리가 시작된 상태**다.

**비의 역할** — 비가 스며들면 두 가지가 동시에 일어난다.

```text
   빗물이 스민다
      ↓
   ① 흙이 무거워진다        → 미끄러뜨리는 힘이 커진다
   ② 흙 속 물이 흙을 벌린다  → 버티는 힘이 줄어든다
      ↓
   양쪽에서 동시에 불리해진다
```

그래서 **비 온 다음 날이 가장 위험하다.** 비가 그쳤다고 안전해진 것이 아니다. 물이 땅속으로 내려가는 데는 시간이 걸리고, 강도는 그 뒤에 떨어진다.

**이 상황의 결정적 요소는 사람이다.**

법면 아래에 **4명이 들어가 있다.** 6m 높이의 법면이 무너지면 사람이 묻힌다. 이것은 되돌릴 수 없다.

1-9에서 말한 것이 여기 그대로 적용된다.

> **안전에 관한 사안은 다른 것에 우선한다.** 공정이 밀리는 것은 되돌릴 수 있지만 사람이 다치는 것은 되돌릴 수 없다.

**그리고 계측기가 없다.** 이 구간은 흙막이가 아니라 오픈컷이라 계측 대상에서 빠져 있었다. 그래서 **육안 관찰이 유일한 신호였다.** 이것도 문제의 일부다.

</details>

## ⑤ 공사 담당자라면 — 지금 이 순간

<details><summary>펼치기</summary>

**순서가 아니라 동시에 해야 할 것이 첫 번째다.**

| 순서 | 할 일 |
|---|---|
| **0** | **법면 아래 인원 즉시 대피.** 장비도 뺀다. 이것이 먼저다 |
| 1 | 법면 상·하부 **출입 통제.** 경계 표시 |
| 2 | 법면 어깨 위쪽의 하중 제거 — 장비, 자재, 통행 |
| 3 | 균열 **사진·위치·규모 기록**, 균열 게이지 또는 표식 설치 |
| 4 | 일정 간격으로 균열 폭 변화 관찰 — **벌어지고 있는가** |
| 5 | 법면 상부 **배수 경로 확인** — 물이 법면으로 흘러들고 있는가 |
| 6 | 비닐 등으로 **우수 침투 차단** 검토 |
| 7 | 인접 구조물·도로 영향 확인 |
| 8 | **기술검토 요청** — 법면 안정성, 필요시 보강 공법 |

**0번에 다른 것을 끼워 넣지 않는다.** 사진을 먼저 찍거나 상부에 보고하고 나서 대피시키는 것이 아니다. 사람부터 뺀다. 그다음에 전부 한다.

**1-5 ②의 판단 기준**에 대입하면 명확하다.

```text
   계속하면 문제가 커지는가?   → 예 (진행 중이다)
   되돌릴 수 없게 되는가?      → 예
   사람이 위험해지는가?        → 예
```

셋 중 하나만 예여도 멈춘다. 여기는 셋 다 예다.

**8번은 권한 밖이다.** 법면 기울기를 바꾸거나 보강 공법을 결정하는 것은 설계 영역이다(1-6 ④).

</details>

## ⑥ 공무 담당자라면 — 오늘

<details><summary>펼치기</summary>

안전 조치가 먼저지만, **그와 동시에 남겨야 하는 것이 있다.**

| 할 일 | 왜 |
|---|---|
| **강우 기록 확보** (시각별, 강우량) | 원인 판단과 계약적 성격 |
| 균열 발견 **시각**과 조치 시각 | 대응이 적절했음의 기록 |
| 대피·통제 조치 기록 | 안전 관리 이행의 증거 |
| 중지된 작업, 대기 인원·장비와 시간 | 원가·기간 영향 |
| 설계 **법면 기울기와 토질 조건** 확인 | 설계대로 시공되었는가 |
| 실제 시공된 기울기 측량 | 위와 대조 |
| 이 구간이 **계측 대상에서 빠진 경위** | 계측계획 검토 사안 |
| 계약상 강우·불가항력 조항 | 귀책 판단 |

### 원인의 갈림

| 원인 | 처리 |
|---|---|
| 설계보다 급하게 깎았다 | **시공 귀책** |
| 설계대로 깎았는데 무너졌다 | 설계 전제(토질·강우) 문제. 기술질의 |
| 실제 토질이 조사와 다르다 | 현장조건 상이 가능성 |
| 예외적 강우 | 계약이 정한 바에 따름 |

**실제 시공 기울기를 측량해 두는 것**이 이 판단의 출발점이다. 나중에 보강하고 나면 원래 상태를 알 수 없다.

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **작업 재개 조건과, 그 판단을 누가 하는가.**

배수관 부설이 멈췄다. 후속 공정이 밀린다. 재개 압박이 곧 온다.

**"내일 괜찮아 보이면 재개"는 조건이 아니다.** 사람이 들어가는 자리이므로 기준이 명확해야 한다.

정해야 할 것:

- 균열 폭이 **더 벌어지지 않는 상태**가 얼마 동안 유지될 것
- 추가 붕락이 없을 것
- 법면 안정성에 대한 **기술검토 결과**가 나올 것
- 필요하다면 보강이 완료될 것
- 상부 배수가 정비될 것
- **누가 재개를 승인하는가** — 안전 관련 승인 체계 확인

그리고 재개하더라도 **계측을 붙이고 들어간다.** 육안만으로 판단하던 상태로 돌아가지 않는다.

또 하나 합의할 것 — **다른 오픈컷 구간도 같은 상태인가.** 1-5 ⑮의 횡전개다. 이 법면만 이럴 이유가 없다. 같은 조건의 다른 구간을 오늘 확인해야 한다.

</details>

## ⑧ 부족한 정보

<details><summary>펼치기</summary>

| 모르는 것 | 왜 필요한가 |
|---|---|
| 설계 법면 기울기와 전제 토질 | 설계대로 시공되었는가 |
| 실제 시공 기울기 | 위와 대조 |
| 균열 폭의 변화 추세 | 진행성 여부. **가장 중요** |
| 균열의 깊이와 연장 | 활동 규모 추정 |
| 법면 상부 배수 상태 | 물이 계속 들어가고 있는가 |
| 강우량과 침투 시간 | 원인과 시점 |
| 어제 순찰 기록 | 정말 없었는지 |
| 같은 조건의 다른 구간 상태 | 횡전개 |
| 소단 설치 여부 | 설계와 실제 |

**"어제는 없었다"가 기억이라는 점**이 걸린다. 순찰 기록이 사진과 함께 남아 있으면 진행 속도를 알 수 있고, 없으면 추정만 가능하다.

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"일단 사진 찍고 보고하자."**
사람이 아래에 있다. **대피가 먼저다.** 기록은 그다음이고, 몇 분 늦는다고 사라지지 않는다.

**"균열이 작으니 지켜보자."**
크기가 아니라 **진행 여부**가 지표다. 그리고 아래에 흙이 쌓였다는 것은 이미 움직이고 있다는 뜻이다.

**"비 그쳤으니 이제 괜찮다."**
물이 스며들어 강도가 떨어지는 데는 시간이 걸린다. **비 온 다음 날이 더 위험하다.**

**"오픈컷이라 계측 대상이 아니다."**
계측 계획에 없었다는 것이 위험이 없다는 뜻은 아니다. 계획이 위험을 따라가지 못한 것이다.

**"작업자들이 조심하면 된다."**
6m 법면이 무너지면 조심으로 피할 수 없다. 관리적 대책으로 물리적 위험을 덮는 전형적인 오류다.

**"보강하고 나서 원인은 나중에 보자."**
보강하면 원래 상태가 사라진다. 실제 기울기와 균열 상태는 지금만 기록할 수 있다.

**"이 구간만 조치하면 된다."**
같은 조건의 다른 법면이 있다. 횡전개하지 않으면 다른 곳에서 다시 만난다.

</details>

## 이 문제가 가르치는 것

> **되돌릴 수 없는 것이 사람일 때, 순서에 예외가 없다.**

앞의 케이스들은 "무엇을 확인하고 나서 판단한다"였다. 이 문제는 다르다. 확인보다 **대피가 앞선다.**

1-5의 문제처리 Flow에서 `②작업 영향 통제`가 `③사실 확인`보다 먼저인 이유가 가장 선명하게 드러나는 경우다. 그리고 1-9에서 안전이 다른 직무에 우선한다고 한 것이 실제로 어떻게 적용되는지 보여준다.
