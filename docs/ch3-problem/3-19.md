# 3-19. 말뚝 콘크리트가 이론량보다 훨씬 많이 들어갔다

> **관리업무 축** 품질 · 원가 · 문제처리 | **공종 축** 기초 · 말뚝 · 지하수
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

지하 4층 건축물 기초의 현장타설말뚝 공사다. 지름 1,000mm, 길이 약 22m, 총 34본. 오늘까지 11본을 시공했다.

오늘 시공한 **9번 말뚝**의 콘크리트 타설이 끝난 뒤, 타설 담당이 말했다.

> "오늘 건 좀 많이 들어갔습니다. 이론량이 17.3㎥인데 **23.5㎥** 나왔습니다."

이론량 대비 **약 136%**다. 앞선 8본은 대체로 105~112% 범위였다.

시공 중에 특별히 이상하다고 느낀 사람은 없었다. 천공은 평소보다 조금 오래 걸렸지만 장비 문제로 생각했다. 지하수는 이 현장 전체에서 나오고 있고, 9번 위치라고 특별히 심하지는 않았다.

내일 10번, 11번 말뚝 천공이 예정되어 있다.

---

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 말뚝 제원 | D1000, 길이 22m, 34본 중 11본 완료 |
| 9번 말뚝 | 이론 17.3㎥ / 실투입 23.5㎥ (약 136%) |
| 기시공 8본 | 105 ~ 112% 범위 |
| 천공 기록 | 9번은 천공 소요시간이 평소보다 약 40% 길었음 |
| 안정액 관리 | 비중·점성 측정 기록 있음. 9번 당일 기록은 **1회만** |
| 슬라임 처리 | "실시"로 기록. 처리 방법·소요시간 미기재 |
| 지하수 | 현장 전반 GL-6m 수준 |
| 지층 | GL-12 ~ 16m 구간에 느슨한 모래층 (주상도) |
| 주변 | 말뚝 9번에서 약 8m 거리에 가설 사무동 |
| 내일 예정 | 10·11번 천공 |
| 건전도시험 | 전 본 실시 예정. 아직 미실시 |

---

## ③ 먼저 답해볼 것

1. 타설량 136%는 무엇을 뜻하는가. 좋은 신호인가 나쁜 신호인가.
2. 이 말뚝 자체의 문제만 보면 되는가. 다른 것은 없는가.
3. 내일 10·11번 천공을 예정대로 해도 되는가.
4. "특별히 이상하다고 느낀 사람이 없었다"는 사실은 무엇을 말하는가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-B-1의 `⑥ 시공 중 확인·기록`에서 이상 신호가 잡혔다. 다만 **신호가 잡힌 시점이 이미 타설 후**다. 되돌릴 수 있는 지점은 지났다.

**신호의 해석** — 이론 체적보다 훨씬 많이 들어갔다는 것은 **구멍이 이론보다 컸다**는 뜻이다. 구멍이 왜 커졌는가. 대개 **공벽이 무너졌기 때문**이다.

```text
   콘크리트가 많이 들어갔다
        ↓
   구멍이 이론보다 컸다
        ↓
   공벽이 무너졌다
        ↓
   ① 무너진 흙은 어디로 갔는가  →  말뚝 안에 섞여 있을 수 있다
   ② 흙이 있던 자리는 비었는가  →  주변 지반에 공동
```

**두 갈래가 전혀 다른 문제다.**

①은 **말뚝 품질**의 문제다. 붕괴된 토사가 콘크리트에 섞이면 그 구간의 단면이 결손되거나 강도가 떨어진다. 건전도시험 대상이다.

②는 **주변 지반**의 문제다. 흙이 구멍으로 들어왔다는 것은 원래 있던 자리가 비었다는 뜻이다. 8m 거리에 가설 사무동이 있다. 2-D-1에서 본 "흙이 빠져나가면 그 자리가 빈다"와 같은 구조다.

**② 를 아무도 생각하지 않았다는 것이 이 문제의 핵심이다.** 타설량 초과는 대개 "재료가 더 들었다 = 원가 문제"로만 읽힌다.

**세 번째 신호가 있다** — 천공 시간이 평소보다 40% 길었다. 이것은 **시공 중에 이미 나타난 신호**였다. 그때는 장비 문제로 해석됐다. 2-B-1에서 본 대로, 보이지 않는 공종에서는 간접 증거가 유일한 단서다. 단서가 있었는데 다르게 읽혔다.

**깨진 것을 한 줄로** — **볼 수 없는 공종의 간접 증거가 나왔는데, 그것을 원가 지표로만 읽고 품질·안전 지표로 읽지 않았다.**

</details>

---

## ⑤ 공사 담당자라면 — 지금 당장

<details><summary>펼치기</summary>

**두 갈래를 동시에 본다.** 하나는 만든 말뚝, 하나는 주변 지반.

| 순서 | 할 일 |
|---|---|
| 1 | **9번 말뚝 주변 지표를 즉시 육안 확인.** 침하·균열·꺼짐이 있는가 |
| 2 | **가설 사무동 확인** — 바닥·벽 균열, 문틀 틀어짐, 기울기 |
| 3 | 9번 주변에 **침하 관측점 설치**, 관찰 시작 |
| 4 | 9번 말뚝의 **건전도시험을 우선 실시**하도록 요청 |
| 5 | 기시공 11본 전체의 **타설량 기록을 다시 정리** — 추세를 본다 |
| 6 | 천공 기록 재확인 — 다른 본에도 시간 이상이 있었는가 |
| 7 | **내일 10·11번 천공 착수 보류 또는 조건부 진행** 판단 요청 |
| 8 | 안정액 관리 기준과 실제 관리 실태 확인 |

**⑦에 대해** — 무조건 중단이 정답은 아니지만, **원인을 모른 채 같은 방법으로 계속 뚫는 것**은 2-D-1 3-01에서 본 것과 같은 실수다. 원인이 느슨한 모래층이라면 10·11번도 같은 층을 지난다.

**조건부 진행이 가능한 형태** — 안정액 관리 강화, 천공 속도 조정, 타설량 실시간 기록과 이상 시 즉시 보고, 인접 지표 관찰. 이런 조건이 붙는다면 진행을 검토할 수 있다. **판단은 현장 단독으로 하지 않는다.**

**가장 흔한 실수를 피한다** — "9번만 문제니까 9번만 보자". 원인이 지층이면 같은 층을 지나는 모든 본이 대상이다.

</details>

## ⑥ 공무 담당자라면 — 오늘 안에

<details><summary>펼치기</summary>

**말뚝은 볼 수 없다. 기록이 유일한 증거다.** (2-B-1)

| 할 일 | 왜 |
|---|---|
| **본별 타설량 기록의 정식 정리** (이론 / 실투입 / 비율) | 추세가 판단의 근거가 된다 |
| 9번 천공 기록 — 시간, 심도별 진행, 이상 유무 | 시공 중 신호의 증거 |
| **안정액 관리 기록 확보** — 측정 빈도와 값 | 관리가 기준대로였는가 |
| 슬라임 처리 기록의 **구체성 확인** | "실시"만 적혀 있으면 증명력이 약하다 |
| **가설 사무동의 현재 상태 사진** — 오늘 날짜로 | 나중에 균열이 발견돼도 기존 것인지 알 수 없다 |
| 주변 지표 현황 사진 | 같은 이유 |
| 지반조사 주상도 중 GL-12~16m 구간 기재 | 느슨한 모래층이 설계에 반영되었는가 |
| 초과 투입 콘크리트 수량과 비용 | 원가 영향 (1-4) |
| 계약상 통지 요건 검토 | 지반 조건 기인이면 성격 판단 대상 (1-10) |

**다섯 번째 항목이 오늘만 할 수 있는 일이다.** 사무동에 균열이 생겼는데 착공 전·사고 전 기록이 없으면, 기존 균열인지 이번 일로 생긴 것인지 아무도 말할 수 없다. 3-01에서 본 것과 같은 구조다.

**슬라임 기록에 대해** — "실시"라는 한 단어는 기록이 아니다. 방법, 시간, 확인 방식이 없으면 나중에 선단 지지 문제가 나왔을 때 반박할 수 없다. **오늘부터 기록 양식을 고칠 수 있다.**

**성격 판단은 아직 하지 않는다.**

- 지반이 조사 결과보다 불량 → 현장조건 상이 가능성
- 안정액 관리가 미흡 → 시공 귀책
- 공법 자체가 이 지층에 부적합 → 설계 사안

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **"타설량 이상을 어디서부터 이상으로 볼 것인가"를 숫자로 정하는 것.**

지금 문제의 뿌리는 **기준이 없었다는 것**이다. 136%가 나왔을 때 "많이 들어갔다"는 말은 나왔지만, 그것이 보고 사안인지 아닌지를 판단할 기준이 없었다.

정해야 할 것:

- **타설량 비율의 관리 기준값** — 몇 % 초과 시 보고·조사 대상인가
- 초과 시 **즉시 취할 조치** — 천공 중단, 주변 관찰, 건전도시험 우선 실시
- **천공 시간 이상**도 신호로 기록할 것인가
- 안정액 측정 **빈도**와 기록 양식
- 슬라임 처리 기록에 남길 항목
- 인접 구조물 관찰 주기

그리고 **이 기준이 검사·시험계획에 반영되어야 한다**(1-7). 현장에서 구두로 정한 기준은 다음 담당자에게 전달되지 않는다.

**기준을 지금 정하는 이유** — 아직 23본이 남았다. 남은 본에서는 같은 신호를 실시간으로 잡을 수 있다.

</details>

## ⑧ 부족한 정보

<details><summary>펼치기</summary>

| 모르는 것 | 왜 필요한가 |
|---|---|
| **9번 말뚝의 건전도시험 결과** | 말뚝 자체에 결함이 있는가 |
| 타설 중 **심도별 투입량 분포** | 어느 구간에서 많이 들어갔는가 |
| 안정액의 실제 비중·점성 추이 | 공벽 유지 능력이 확보되었는가 |
| 천공 중 붕괴를 시사하는 다른 기록 | 슬라임량, 배출토 성상 |
| 9번 주변 지표·구조물의 현재 상태 | 지반 공동의 흔적 |
| 가설 사무동의 **착공 전 상태 기록** | 균열의 신·구 판별 |
| 기시공 11본의 타설량 전체 추세 | 서서히 늘고 있었는가 |
| GL-12~16m 층의 실제 성상 | 배출토로 확인 가능 |
| 10·11번 위치의 지층 예상 | 같은 위험이 있는가 |
| 재하시험 계획 | 지지력을 무엇으로 확인하는가 |

**두 번째 항목이 가장 유용하다.** 심도별로 나눠 기록했다면 어느 구간에서 구멍이 커졌는지 알 수 있고, 그것이 주상도의 어느 층인지 대조할 수 있다. 기록 방식이 판단의 해상도를 정한다.

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"콘크리트가 더 들어간 건 원가 문제일 뿐이다."**
이 문제의 가장 큰 오해다. 더 들어갔다는 것은 **구멍이 컸다**는 뜻이고, 그 흙이 어디로 갔는지를 물어야 한다. 원가 지표가 아니라 지반 지표다.

**"말뚝 안이 꽉 찼으니 오히려 더 튼튼한 것 아닌가."**
붕괴된 토사가 콘크리트에 섞였을 수 있다. 양이 많다고 품질이 좋은 것이 아니다.

**"9번만 이상하니 9번만 확인하자."**
원인이 지층이면 같은 층을 지나는 모든 본이 대상이다. 그리고 앞선 8본도 105~112%였다. 이미 조금씩 초과하고 있었을 수 있다.

**"천공이 오래 걸린 건 장비 문제였다."**
그렇게 해석한 것이지 확인한 것이 아니다. 사실과 해석을 구분해야 한다(1-5 ③).

**"건전도시험은 전 본 계획되어 있으니 순서대로 하면 된다."**
9번은 이상 신호가 나온 본이다. 우선 확인 대상이다. 계획대로만 하는 것이 항상 옳지 않다.

**"주변에 아직 아무 일도 안 생겼다."**
공동은 땅속에 있고, 꺼짐은 나중에 나타난다. 3-03에서 본 구조와 같다. **현장 안이 멀쩡한 것이 주변이 멀쩡하다는 증거가 아니다.**

**"내일 천공은 조심해서 하면 된다."**
"조심해서"는 조치가 아니다. 무엇을 어떻게 바꿀 것인지가 조치다.

**"슬라임 처리는 기록에 실시로 되어 있다."**
무엇을 어떻게 얼마나 했는지가 없으면 나중에 지지력 문제가 나왔을 때 아무것도 말할 수 없다(1-10 ④).

</details>

## 이 문제가 가르치는 것

> **볼 수 없는 공종에서 숫자는 유일한 눈이다. 그 숫자를 어느 축으로 읽는가에 따라 보이는 것이 달라진다.**

타설량 136%라는 하나의 숫자가 세 가지로 읽힌다.

```text
   원가로 읽으면    재료비가 초과했다          → 정산 문제
   품질로 읽으면    말뚝에 결함이 있을 수 있다   → 건전도시험
   지반으로 읽으면  주변에서 흙이 빠져나갔다     → 인접 구조물
```

**세 번째가 가장 늦게 떠오르고 가장 위험하다.** 그리고 세 번째를 놓치면 나중에 사무동에 균열이 생겼을 때 이 말뚝과 연결 짓지 못한다.

또 하나. 천공 시간이 길었던 것은 **시공 중에 이미 보인 신호**였다. 그때 다르게 읽혔을 뿐이다. 2-B-1이 "보이지 않는 것이 많을수록 시공 중 기록이 유일한 증거"라고 말한 이유가 여기 있다. **기록을 남기는 것과 읽는 것은 다른 일이고, 읽으려면 기준이 있어야 한다**(1-7).
