# 3-10. 사토장이 갑자기 안 받는다고 한다

> **관리업무 축** 공정 · 자원 · 원가 | **공종 축** 토공 · 굴착
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

굴착이 한창이다. 나오는 흙 중 되메움에 쓸 **유용토**는 현장에 야적하고, 쓰지 못하는 **사토**는 외부 사토장으로 반출하고 있다.

오늘 아침 사토장에서 연락이 왔다. **오늘부터 반입을 받지 않는다**고 한다. 사유는 "용량 문제"라고만 들었다.

현재 현장 내 임시 야적 공간은 **약 1.5일치** 굴착량이 한계다. 그 이상 쌓으면 작업 동선과 가시설 배면에 영향이 간다.

굴착 장비 2대와 덤프 6대가 계약되어 있고, 오늘도 정상 투입되어 있다. 이번 단 굴착을 끝내고 스트럿을 설치해야 다음 단으로 갈 수 있다.

---

| 대체 사토장 | 확인 필요 |
| 반출 관련 인허가 | 확인 필요 |
| 굴착 일정의 CP 여부 | 확인 필요 |

## ③ 먼저 답해볼 것

1. 이것은 **굴착 문제**인가, 다른 무엇인가.
2. 1.5일이라는 시간을 어떻게 쓸 것인가.
3. 대체 사토장을 찾으면 해결되는가. 바로 쓸 수 있는가.
4. 지금 덤프 6대를 어떻게 할 것인가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**굴착은 파는 일이 아니라 옮기는 일이다.**

2-A-1의 첫 줄이 이것이었다 — 토공은 **흙을 옮기는 일**이다. 파기만 하고 옮기지 못하면 굴착은 멈춘다. 현장에 쌓아 둘 수 있는 양에 한계가 있기 때문이다.

그래서 이것은 굴착 능력의 문제가 아니라 **반출 경로의 문제**다. 장비도 인원도 그대로 있는데 일이 멈춘다.

**Flow 위치** — 1-2의 `⑥ Constraint`다. 그중에서도 **외부기관·외부 조건**에 해당한다.

Constraint의 성질을 다시 보면 이 상황이 정확히 설명된다.

> Constraint는 **대부분 남이 해소해 주는 것**이다. 내가 열심히 해서 없어지지 않는다.

굴착 속도를 높여도, 사람을 더 넣어도 해결되지 않는다. 받아주는 곳이 있어야 한다.

**시간의 성질이 다르다.**

1-8에서 전파 경로별 소요 시간을 다루며 이렇게 말했다.

> **외부기관이 관련된 경로는 시간이 길다.** 내부에서 아무리 빨리 결정해도 외부 절차가 끝나야 움직인다. 전파 경로 중 이것이 있으면 그것이 곧 CP가 된다.

대체 사토장을 구하는 일은 전화 한 통으로 끝나지 않는다. 계약, 운반 거리 재산정, 운반 경로 협의, 경우에 따라 인허가와 신고가 따라온다. **1.5일 안에 끝난다는 보장이 없다.**

**1.5일의 의미** — 이것은 유예가 아니라 **마감이다.** 1.5일 뒤에는 굴착이 멈춘다. 그 시점부터 장비와 인원이 논다.

</details>

## ⑤ 공사 담당자라면 — 오늘

<details><summary>펼치기</summary>

**1.5일을 세 갈래로 동시에 쓴다.** 순차로 하면 시간이 부족하다.

### 갈래 1 — 기존 경로를 살린다

| | |
|---|---|
| 1 | 사토장에 **정확한 사유와 재개 시점**을 문서로 확인. "용량 문제"는 사유가 아니다 |
| 2 | 일시 중단인가 영구 중단인가 |
| 3 | 부분 반입이라도 가능한가 |

### 갈래 2 — 대체 경로를 연다

| | |
|---|---|
| 4 | **대체 사토장 조사 즉시 착수** — 거리, 단가, 수용 가능량, 운반 경로 |
| 5 | 필요한 **인허가·신고 사항** 확인. 이것이 소요 시간을 결정한다 |
| 6 | 운반 거리가 늘면 **덤프 회전수가 줄어든다** — 대수 재산정 필요 |

### 갈래 3 — 버티는 시간을 늘린다

| | |
|---|---|
| 7 | 현장 내 **임시 야적 가능 공간 재검토** — 가시설 배면과 동선 영향 확인 필수 |
| 8 | **유용토 비율 재검토** — 사토로 분류된 것 중 되메움에 쓸 수 있는 것이 있는가 |
| 9 | **반출이 적은 작업으로 순서 변경** — 지금 할 수 있는 다른 구간이 있는가 |

**7번에 주의한다.** 야적장을 늘리려고 가시설 배면에 흙을 쌓으면 **토압이 늘어난다.** 2-A-2와 계측에 직결된다. 임의로 쌓을 자리가 아니다.

**8번이 의외로 효과가 크다.** 유용토 판정 기준을 다시 보면 반출량 자체가 줄 수 있다. 다만 재료 기준을 임의로 낮추는 것은 안 된다 — 3-09가 보여준 그대로다.

### 그리고 덤프

**오늘 덤프 6대를 어떻게 할 것인가**가 당장의 원가 문제다. 계약 형태에 따라 세워 두는 것 자체가 비용이다. 갈래 2의 전망이 서기 전까지는 판단할 수 없으므로, **오늘 중 결정 시한을 정해 두고** 그때까지 정보를 모은다.

</details>

## ⑥ 공무 담당자라면 — 오늘

<details><summary>펼치기</summary>

| 할 일 | 왜 |
|---|---|
| 사토장 **계약서 확인** — 수용 보장 조건, 중단 시 책임 | 우리 권리가 무엇인가 |
| 중단 통보를 **문서로 받기** | 구두는 근거가 되지 않는다 (1-6) |
| 통보 **시각과 내용** 기록 | 시점이 남아야 한다 |
| 대체 사토장의 **단가 비교** — 운반거리 차이 포함 | 원가 영향 |
| 덤프·굴착기 **대기 비용** 산정과 기록 | 1-10 ⑤ |
| 굴착 지연이 **CP 위인지** 확인 | 준공일 영향 |
| 계약상 **통지** 필요 여부와 기한 확인 | 권리 유지 |
| 반출 관련 인허가 소요 기간 확인 | 실제 재개 가능 시점 |

### 귀책

| 원인 | 처리 |
|---|---|
| 사토장 측 일방 중단 | 사토장 계약 위반 여부. 대체 비용 청구 가능성 |
| 우리가 물량을 잘못 통보했다 | 시공 귀책 |
| 굴착 물량이 설계보다 크게 늘어 용량을 넘었다 | 물량 변경 사안. 3-06과 연결될 수 있다 |
| 인허가·행정 사유 | 계약 조항에 따름 |

**마지막에서 두 번째가 중요하다.** 사토량이 계획보다 많아진 이유가 실제 지반 조건 때문이라면(암반 출현, 여굴 과다 등) 이 사건은 그 연장선에 있다. **앞선 사건과 연결해서 봐야 한다.**

### 통지

기간과 비용에 영향이 있을 가능성이 높다. **원인이 확정되지 않았어도 통지 기한은 흐른다**(1-10 ③). 애매하면 통지한다.

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **오늘 몇 시까지 무엇이 확인되지 않으면 장비를 어떻게 할 것인가.**

이것을 정해 두지 않으면 하루가 그냥 간다. 그리고 다음 날 같은 상황에서 또 정하지 못한다.

정할 것:

- 대체 사토장 확인의 **1차 마감 시각**
- 그때까지 안 되면 내일 덤프를 **몇 대로 줄일 것인가**
- 굴착기는 **다른 구간으로 돌릴 수 있는가**
- 언제 **굴착을 공식적으로 중지**하고 공정표에 반영할 것인가

마지막 항목이 자주 빠진다. 실제로 멈췄는데 공정표는 그대로인 경우가 많다. 그러면 나중에 왜 늦었는지 설명할 근거가 사라진다(1-5 ⑪, 1-8).

**그리고 야적 확대는 합의만으로 못 한다.** 가시설 배면 하중은 기술검토 사안이다(1-6 ④).

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"다른 사토장 알아보면 되지."**
맞는 방향이지만 **시간을 과소평가한 것**이다. 계약·거리·경로·인허가가 따라온다. 1.5일 안에 끝난다는 보장이 없다.

**"일단 현장에 쌓아 두자."**
가시설 배면에 쌓으면 토압이 는다. 계측에 나타나고, 최악의 경우 3-08 같은 상황이 된다. **쌓을 자리는 검토 사안이다.**

**"굴착을 천천히 하면서 버티자."**
장비와 인원은 그대로 나온다. 생산성만 떨어지고 원가는 그대로다. 차라리 세우고 다른 구간으로 돌리는 편이 나을 수 있다 — 숫자로 비교해야 한다.

**"사토장 문제니 우리가 할 건 없다."**
결과는 우리 공정과 원가에 온다. 그리고 통지 기한은 흐른다.

**"덤프는 일단 대기시켜 놓자."**
대기도 비용이다. **결정 시한을 정해 두고** 그때 판단한다. 정하지 않으면 하루씩 새어 나간다.

**"유용토 기준을 좀 낮춰서 반출량을 줄이자."**
재료 기준을 임의로 바꾸는 것은 권한 밖이고, 3-09처럼 나중에 다짐도로 돌아온다.

**"공정표는 상황 정리되면 고치자."**
멈춘 사실을 그때그때 반영하지 않으면 근거가 사라진다.

</details>

## 이 문제가 가르치는 것

> **내가 통제할 수 없는 것이 공정을 멈춘다. 그리고 그런 것은 대개 시간이 길다.**

앞의 토공 케이스들은 현장 안에서 판단하고 조치할 수 있는 것들이었다. 이것은 다르다. 장비도 인원도 날씨도 문제가 없는데 일이 멈춘다.

1-2가 **Constraint를 선후관계와 따로 관리하라**고 한 이유가 여기 있다. 선행작업이 끝나기만 기다리는 것과, 남이 해소해 줘야 하는 조건을 기다리는 것은 관리 방법이 다르다. 후자는 **요청한 날, 확약받은 날, 실제 해소된 날**을 따로 추적해야 한다.

그리고 이런 사건은 예고 없이 온다. 그래서 **반출 경로 같은 외부 의존 항목은 평소에 대안을 하나쯤 확인해 두는 것**이 관리의 일부다.
