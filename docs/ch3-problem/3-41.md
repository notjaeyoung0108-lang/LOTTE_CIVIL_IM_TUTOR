# 3-41. 관로 주변만 다짐 기준을 못 맞춘다

> **관리업무 축** 품질 · 문제처리 | **공종 축** 되메우기 · 지장물
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

도로 하부 구조물 되메우기다. 되메움 구간 안에 **이설한 상수도 관로**가 지나간다. 관로는 되메움 도중 일정 높이에서 통과하고, 그 위로 계속 채워 올라간다.

관로 통과 구간의 다짐이 문제다.

- 관로 좌우와 상부 구간에서 **다짐도가 계속 기준에 못 미친다**
- 다짐을 더 하려 하면 **관리기관에서 제동을 건다.** 관로 위에서 진동 다짐을 하면 관이 손상될 수 있다는 것이다
- 관리기관이 제시한 **관로 보호 조건**에는 관 상부 일정 높이까지 진동 다짐 금지, 장비 중량 제한이 들어 있다

즉 **다짐 기준을 맞추려면 관로 보호 조건을 어겨야 하고, 관로 보호 조건을 지키면 다짐 기준을 못 맞춘다.**

이 구간 위로는 도로 포장이 올라간다. 포장 후에 꺼지면 도로를 걷어내야 한다.

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 구간 | 도로 하부 되메우기 구간 중 관로 통과부 약 15m |
| 관로 | 이설 상수도관 |
| 다짐도 | 관로부 기준 미달 반복 |
| 다른 구간 | 기준 충족 |
| 관리기관 조건 | 관 상부 일정 높이까지 진동 다짐 금지, 장비 중량 제한 |
| 시방 | 되메움 다짐도 기준 규정 |
| 되메움재 | 승인품 사용 |
| 함수비 | 관리 범위 |
| 상부 | 도로 포장 예정 |
| 대체 공법 | 검토된 바 없음 |
| 관로 보호 상세 | 설계도서에 표기 있음 |
| 협의 기록 | 관리기관과 구두 협의만 |

## ③ 먼저 답해볼 것

1. 두 기준 중 어느 쪽을 따라야 하는가.
2. 이 문제를 현장에서 해결할 수 있는가.
3. 다짐도 기준의 목적은 무엇인가. 그 목적을 다른 방법으로 달성할 수 있는가.
4. 지금 그대로 진행하면 언제 무엇이 드러나는가.

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-B-6의 `⑥ 다짐`과 `⑦ 다짐도 확인`이다. 그런데 이 칸에 **다른 축의 요구가 겹쳐 들어와 있다.**

**두 기준이 같은 구간에서 충돌한다**

| 기준 | 목적 | 요구 |
|---|---|---|
| 되메움 다짐도 | 나중에 꺼지지 않게 | 충분히 다져라 |
| 관로 보호 | 관을 손상시키지 않게 | 세게 다지지 마라 |

**둘 다 정당하다.** 그리고 둘 다 지켜야 한다. 그런데 **현재 방법으로는 동시에 지킬 수 없다.**

**이것이 3-11에서 본 "지시가 상충할 때"와 다른 점** — 3-11은 두 지시의 우선순위를 정하는 문제였다. 여기서는 **어느 쪽도 양보할 수 없는 두 기준**이다. 다짐을 포기하면 도로가 꺼지고, 보호를 포기하면 관이 깨진다.

**그래서 답은 "어느 쪽을 고르는가"가 아니다.**

**질문을 바꿔야 한다** — 다짐도 기준의 **목적**이 무엇인가.

```text
   다짐도 기준의 목적   나중에 침하하지 않게 하는 것
        ↓
   다짐은 그 목적을 달성하는 수단이다
        ↓
   같은 목적을 다른 수단으로 달성할 수 있는가?
```

**이 질문을 하면 선택지가 생긴다.**

| 대안 방향 | 내용 |
|---|---|
| **재료를 바꾼다** | 다짐이 거의 필요 없는 재료 (유동성 채움재 등) |
| **장비를 바꾼다** | 소형·저진동 다짐 장비, 얇은 층 다회 |
| **구조로 푼다** | 관로 상부를 슬래브 등으로 덮어 하중을 분산 |
| **관리 방법을 바꾼다** | 다짐도 대신 다른 확인 방법 |

**어느 것도 현장이 정할 수 없다.** 전부 설계와 관리기관 협의가 필요한 사안이다(1-6).

**지금 현장이 하고 있는 것** — 두 기준 사이에서 **반복 시도만 하고 있다.** 다지고, 시험하고, 미달이고, 다시 다지고. 그리고 관리기관이 제동을 건다. **아무것도 해결되지 않는데 시간과 비용만 쓴다.**

**이것을 문제로 제기하지 않은 것이 이 케이스의 실패다.** 1-5 ⑥의 **권한 판단**이 안 된 것이다. 현장이 풀 수 있는 문제가 아닌데 현장에서 풀려고 하고 있다.

**협의가 구두로만 되어 있다** — 관리기관의 조건이 문서로 정리되어 있지 않다. 그러면 **조건의 범위도 근거도 불명확**하고, 나중에 어떤 문제가 생겨도 무엇에 따랐는지 말할 수 없다.

**시간 문제도 있다** — 이 위로 도로 포장이 올라간다. **포장 후에 꺼지면 걷어내야 한다**(2-B-6 ⑩). 그리고 도로는 공용 중이 되므로 훨씬 큰 문제가 된다.

**깨진 것을 한 줄로** — **두 정당한 기준이 충돌하는데, 그것을 상위로 올리지 않고 현장에서 반복 시도로 해결하려 하고 있다.**

</details>

## ⑤ 공사 담당자라면 — 지금 당장

<details><summary>펼치기</summary>

**반복 시도를 멈추고 문제를 정리한다.**

| 순서 | 할 일 |
|---|---|
| 1 | **관로부 되메우기 진행 중지** |
| 2 | 다짐도 시험 결과를 **전부 정리** — 위치별, 층별, 값 |
| 3 | 미달의 정도를 정량화 (얼마나 부족한가) |
| 4 | **관리기관 조건을 문서로 받는다** |
| 5 | 설계도서의 관로 보호 상세 확인 |
| 6 | 시방의 다짐도 기준과 적용 범위 확인 |
| 7 | **대안 목록 작성** — 재료 / 장비 / 구조 / 확인 방법 |
| 8 | 기술질의 작성 (1-6) |
| 9 | 이 구간의 포장 일정 조정 검토 |

**④가 가장 급하다.** 구두 조건으로는 아무것도 진행할 수 없다. **무엇이 금지되고 무엇이 허용되는지**가 문서로 있어야 대안을 검토할 수 있다.

**③이 중요한 이유** — 기준의 95%인 것과 70%인 것은 다르다. 근소한 차이라면 방법을 조금 바꿔 해결될 수 있고, 큰 차이라면 근본적인 대안이 필요하다. **"미달"이라는 말로 뭉뚱그리면 판단할 수 없다.**

**⑦이 현장이 기여할 수 있는 부분이다.** 결정은 설계가 하지만, **현장은 무엇이 실제로 가능한지를 안다.** 장비 반입 가능성, 작업 공간, 소요 기간 같은 것.

**⑨가 실무적으로 중요하다.** 이 구간을 해결하지 않고 포장하면, 나중에 도로를 걷어내야 한다. **지금 늦추는 비용이 훨씬 작다.**

**하지 말아야 할 것**

- **다짐도 시험 위치를 관로부에서 비켜서 하는 것.** 합격 기록은 생기지만 문제는 남는다
- 관리기관 조건을 **현장 판단으로 완화하는 것**
- "어차피 나중에 좀 꺼지겠지" 하고 넘어가는 것

</details>

## ⑥ 공무 담당자라면 — 오늘 안에

<details><summary>펼치기</summary>

| 할 일 | 왜 |
|---|---|
| **관리기관 조건의 문서화 요청** | 구두로는 근거가 안 된다 |
| 관리기관과의 협의 이력 정리 | 언제 누가 무엇을 |
| 다짐도 시험 기록 전량 (위치·층·값) | 문제의 정량화 |
| 시험 위치도 (관로와의 관계 표시) | 어디가 미달인가 |
| 시방의 다짐도 기준 조항 | 기준의 근거 |
| 설계도서의 관로 보호 상세 | 설계가 무엇을 전제했는가 |
| **기술질의 문서 작성** | 상충의 공식화 (1-6) |
| 되메우기 중지에 따른 영향 | 기간·비용 (1-2, 1-4) |
| 지장물 이설 관련 협의 문서 | 조건의 근거 |
| 포장 일정과의 관계 | 후속 영향 |

**일곱 번째가 이 케이스의 핵심 행동이다.** 3-35에서 본 것과 같은 구조다 — **상충을 공식화한다.**

**기술질의에 담을 것**

```text
   사실   관로 통과부 15m 구간에서 다짐도 기준 미달이 반복됨
          시험 결과 (위치별·층별 값) 첨부
          관리기관의 관로 보호 조건: 진동 다짐 금지 범위, 장비 중량 제한
          현 방법으로는 두 조건을 동시에 만족할 수 없음

   질문   이 구간의 다짐 관리 방법에 대해 검토를 요청함
          다음 대안의 적용 가능성을 검토해 주기 바람
            - 되메움재 변경 (유동성 채움재 등)
            - 저진동 소형 장비 + 박층 다짐
            - 관로 상부 하중 분산 구조
            - 다짐도 외의 확인 방법
          관리기관과의 협의가 필요한 사항이 있다면 창구를 확인 요청
```

**마지막 줄이 실무적으로 중요하다.** 관리기관과의 협의 주체가 누구인지가 정해져 있어야 한다. 현장이 직접 하는 것인지, 발주처를 통하는 것인지가 프로젝트마다 다르다.

**성격 판단**

- 설계 단계에서 이 상충이 검토되지 않았다면 → **설계 사안** 가능성
- 관리기관 조건이 이설 협의 이후 추가된 것이면 → 별도 사안
- 시공 방법의 문제라면 → 시공 사안

**세 가지를 지금 가릴 수 없다.** 그래서 질의가 필요하다. 그리고 **기간이 걸리는 사안이므로 통지가 늦으면 안 된다**(1-10 ③).

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **"이것은 현장이 풀 문제가 아니다"에 먼저 합의하는 것.**

지금 현장에서 벌어지는 일은 **반복 시도**다. 다지고 시험하고 미달하고 다시 다진다. 이것이 계속되는 이유는, **누군가 "이건 우리가 풀 수 있는 문제가 아니다"라고 말하지 않았기 때문**이다.

1-5 ⑥의 권한 판단이 이 케이스의 첫 단계다.

**정할 것:**

- 반복 시도 중지
- 관리기관 조건의 문서 확보
- 기술질의 제출 시점
- 협의 창구와 주체
- 회신까지의 공정 조정
- **이 구간을 제외한 다른 구간의 진행 여부**

**마지막 항목이 실무적이다.** 15m 구간 때문에 전체를 멈출 필요는 없을 수 있다. 다만 **관로부를 비워 두고 주변만 올리는 것**이 가능한지는 확인이 필요하다.

**구조적으로 정할 것:**

- 지장물이 통과하는 구간의 **되메우기 계획을 별도로 수립**
- 다짐도 시험 위치에 **반드시 지장물 주변 포함**
- 관리기관 조건은 **문서로 받아 공유**
- 유사 구간이 더 있는지 사전 확인

**공사와 공무의 시각**(1-9)

- 공사: 어떻게든 기준을 맞춰 보려 한다. 공정이 서 있다
- 공무: 두 기준이 충돌한다는 사실을 문서로 만들어야 한다

**여기서 두 사람이 같은 편이다.** 공사도 계속 시도하는 것이 답이 아니라는 것을 안다. 필요한 것은 **그것을 문제로 제기할 근거와 형식**이고, 그것이 공무의 일이다.

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"관로 보호가 우선이니 다짐은 포기하자."**
포장 후에 꺼진다. 도로를 걷어내야 하고, 그때는 공용 중이다.

**"다짐 기준이 우선이니 좀 세게 하자."**
관이 손상되면 단수와 배상이다. 그리고 관리기관 조건 위반이다.

**"시험 위치를 조금 비켜서 하자."**
합격 기록은 생기지만 문제는 그대로 남는다. 2-B-6이 지적한 그대로다.

**"조금 꺼져도 나중에 덧포장하면 된다."**
꺼짐은 계속 진행되고, 덧포장은 임시 조치다. 그리고 원인이 남아 있다.

**"관리기관이 구두로 말한 거니 융통성이 있을 것이다."**
문서로 받지 않았다는 것이 문제다. 융통성을 기대할 것이 아니라 조건을 명확히 해야 한다.

**"계속 다지다 보면 언젠가 나온다."**
방법이 같으면 결과도 같다. 그리고 그 사이에 관로가 손상될 수 있다.

**"설계에 나와 있는 대로 했는데 안 되는 걸 어떻게 하나."**
그것이 바로 기술질의 사유다(1-6). 설계대로 했는데 안 되면 설계에 물어야 한다.

**"이 구간만 조금 덜 다져도 티 안 난다."**
관로 주변은 가장 잘 꺼지는 구간이다. 가장 티가 잘 나는 곳이다.

**"관리기관과 협의하는 건 우리 일이 아니다."**
협의 주체를 확인하는 것은 현장의 일이다. 모르고 방치하는 것이 문제다.

**"공정이 급하니 일단 덮고 포장하자."**
포장을 걷어내는 비용이 지금 멈추는 비용보다 훨씬 크다.

</details>

---

## 이 문제가 가르치는 것

> **두 기준이 같은 구간에서 충돌할 때, 현장이 할 일은 한쪽을 고르는 것도 반복 시도도 아니다. 충돌 자체를 문제로 올리는 것이다.**

되메움 다짐도 기준과 관로 보호 조건은 둘 다 정당하다. 서로 다른 목적에서 나왔고, 각각의 자리에서는 옳다. **문제는 둘이 같은 15m를 두고 만난다는 것**이다.

이런 상황에서 현장의 자연스러운 반응은 세 가지인데, 셋 다 답이 아니다.

```text
   한쪽을 고른다     →  다른 쪽이 깨진다
   반복 시도한다     →  아무것도 안 바뀌고 시간만 간다
   기록을 비켜 간다  →  문제가 숨는다. 포장 후에 나온다
```

**네 번째가 답이다 — 충돌을 문서로 만들어 올린다.**

1-5 ⑥이 **"담당 권한 내 해결 가능 여부 판단"** 을 Flow의 분기점으로 둔 이유가 이것이다. 그리고 1-5는 **"가장 위험한 실수"** 를 권한 밖의 것을 권한 안에서 처리하려는 것이라고 했다. 이 케이스가 그 전형이다.

그리고 하나 더. **기준은 수단이지 목적이 아니다.**

다짐도 95%라는 숫자는 "나중에 꺼지지 않게"라는 목적을 위한 수단이다. 수단이 막혔을 때 **목적으로 돌아가면 다른 수단이 보인다.** 유동성 채움재, 하중 분산 구조, 다른 확인 방법. 이 선택지들은 "다짐도를 어떻게 맞추지"라고 물으면 보이지 않고, **"침하를 어떻게 막지"라고 물으면 보인다.**
