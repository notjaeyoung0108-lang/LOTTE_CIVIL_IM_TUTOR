# 챕터 3 — 문제풀이

정보를 일부러 일부 숨긴다. 먼저 **"지금 어느 칸이 깨졌는가"** 를 찾고, 그다음 직무별로 무엇을 할지 답한다.

각 문제는 **관리업무 축(챕터 1) × 공종 축(챕터 2)** 의 교차점에서 만들어진다.

## 각 문제의 공통 서식

```text
① 상황              정보가 일부 비어 있다
② 제공된 자료        지금 손에 있는 것
③ 먼저 답해볼 것      읽자마자 스스로 답해 본다
④ 무엇이 깨졌는가     어느 Flow의 어느 칸인가
⑤ 공사 담당자라면     지금 당장 할 일
⑥ 공무 담당자라면     오늘 안에 남길 것
⑦ 합의해야 할 것      두 직무가 반드시 맞춰야 하는 것
⑧ 부족한 정보        무엇을 더 알아야 판단이 끝나는가
⑨ 흔한 오답          왜 틀렸는가
```

※ 모든 수치·물량·기간·금액은 교육용 가정이다. 실제 현장의 실적이 아니다.
※ 통지 기한, 검측 명칭, 승인 권한은 프로젝트마다 다르다. 실제 계약문서에서 확인해야 한다.
