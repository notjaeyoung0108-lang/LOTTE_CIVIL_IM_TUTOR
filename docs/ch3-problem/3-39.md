# 3-39. 되메우기 중 벽체가 안쪽으로 밀렸다

> **관리업무 축** 품질 · 안전 · 문제처리 | **공종 축** 되메우기 · 구조물
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

지하차도 개착 구간이다. 본체 구조물이 완성됐고, 어제부터 양측 되메우기를 시작했다.

오늘 오후, 측량 담당이 보고했다.

> "북측 벽체 상단이 안쪽으로 들어왔습니다. 어제 기준선보다 **18mm** 정도입니다."

현장을 보니 북측은 되메움이 이미 **높이 3.5m**까지 올라갔고, 남측은 **1.2m**에 그쳐 있다. 북측 진입로 쪽이 반입이 편해서 그쪽부터 먼저 올린 것이다.

되메움재는 승인품이고 다짐도 시험도 통과하고 있다. 장비는 진동 롤러를 쓰고 있다.

구조물 중간 슬래브는 **아직 일부 구간만 시공**되어 있다. 북측 이 구간은 중간 슬래브가 없다.

---

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 구조물 | 지하차도 본체, 벽체 높이 7.2m |
| 되메우기 | 어제 착수 |
| 북측 | 높이 약 3.5m 도달 |
| 남측 | 높이 약 1.2m |
| 측량 | 북측 벽체 상단 내측 변위 약 18mm |
| 되메움재 | 승인품. 다짐도 시험 통과 |
| 다짐 장비 | 진동 롤러 (벽체 근접부 포함 사용) |
| 중간 슬래브 | 일부 구간만 시공. **이 구간 미시공** |
| 콘크리트 강도 | 벽체 28일 강도 충족 |
| 되메우기 계획 | 좌우 균형 조항 **기재 없음** |
| 계측 | 구조물 변위 계측 **미설치** |
| 흙막이 | 이미 일부 해체 |

---

## ③ 먼저 답해볼 것

1. 벽체가 왜 안쪽으로 밀렸는가. 원인 후보를 몇 개 떠올렸는가.
2. 18mm는 큰 값인가 작은 값인가. 무엇과 비교해야 하는가.
3. 지금 당장 무엇을 멈춰야 하는가.
4. 되메움재와 다짐도는 문제가 없었다. 그런데 왜 이런 일이 생겼는가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-B-6의 `⑤ 포설`이다. 그리고 그 칸의 관리 항목에 **좌우 균형**이 있었다.

**2-B-6의 첫 문장으로 돌아간다.**

> **되메우기는 구조물에 하중을 거는 행위다.**

```text
   북측 3.5m 되메움 → 북측에서 토압
   남측 1.2m 되메움 → 남측에서 작은 토압
        ↓
   차이만큼의 힘이 벽을 안쪽으로 민다
        ↓
   북측 벽체가 안으로 밀린다
```

**이것이 편토압이다.** 그리고 지금 관찰된 것과 정확히 일치한다.

**두 번째 원인이 겹쳐 있다** — 자료를 보면 **이 구간에 중간 슬래브가 없다.**

2-B-6에서 본 그대로다.

> **중간 슬래브나 버팀이 아직 없는 상태의 벽은 설계가 가정한 지지 조건이 아니다.**

완성 상태에서는 슬래브가 벽을 잡아 준다. 지금은 없다. **즉 벽이 혼자 토압을 받고 있다.**

**세 번째 요인** — 벽체 근접부에 **진동 롤러**를 썼다. 2-B-6에서 근접부는 작은 장비로 해야 한다고 한 이유가 이것이다. 큰 장비의 진동이 벽체에 전달되고, 다짐 과정 자체가 순간적으로 큰 측압을 만든다.

**네 가지가 동시에 있다**

| 요인 | 상태 |
|---|---|
| 좌우 불균형 | 3.5m vs 1.2m |
| 중간 슬래브 미시공 | 지지 조건 미확보 |
| 근접부 진동 롤러 | 과다 다짐 |
| 착수 조건 확인 | 되메우기 계획에 균형 조항 없음 |

**"재료도 승인품이고 다짐도도 통과했는데 왜"** — 이것이 이 케이스의 핵심 질문이다.

**측정하고 있던 것과 문제가 생긴 곳이 다르다.**

```text
   측정 중   되메움재 품질, 다짐도       → 전부 정상
   문제      좌우 균형, 지지 조건        → 아무도 안 봤다
```

**관리 항목에 없는 것은 관리되지 않는다.** 되메우기를 "재료와 다짐도"의 문제로만 보면, 하중으로서의 성질이 관리 밖에 남는다.

**18mm를 어떻게 봐야 하는가** — 절대값으로 판단할 수 없다. 봐야 할 것은 세 가지다.

1. **설계 허용치**와의 비교
2. **변화율** — 어제 하루 만에 생긴 값인가
3. **진행 중인가**

2-A-3과 3-13에서 계속 본 것과 같다. **변화율이 절대값보다 먼저다.** 그리고 지금 **구조물 변위 계측이 설치되어 있지 않다.** 측량으로 우연히 발견한 것이지, 관측하고 있던 것이 아니다.

**깨진 것을 한 줄로** — **되메우기를 채우는 작업으로 보고 재료와 다짐도만 관리했는데, 실제로 구조물에 걸린 것은 하중이었다.**

</details>

## ⑤ 공사 담당자라면 — 지금 당장

<details><summary>펼치기</summary>

**되메우기는 되돌릴 수 있다. 다만 벽체 변위는 되돌아오지 않을 수 있다.**

| 순서 | 할 일 |
|---|---|
| 1 | **북측 되메우기 즉시 중지** |
| 2 | 벽체 주변 인원·장비 통제 |
| 3 | **벽체 변위 재측량** — 전 구간, 높이별 |
| 4 | **변위 관측 개시** — 임시 계측점 설치, 주기적 측정 |
| 5 | 벽체 균열 유무 확인 (내측·외측) |
| 6 | 남측 되메우기로 **균형 회복**을 검토 (판단 필요) |
| 7 | 중간 슬래브 미시공 구간 목록 작성 |
| 8 | 다짐 장비와 방법 재검토 |
| 9 | 기술검토 요청 (1-6) |

**⑥이 판단이 필요한 지점이다.** 직관적으로는 "남측을 올려 균형을 맞추면 된다"이지만, **이것을 현장이 단독으로 해서는 안 된다.**

- 이미 변위가 생긴 벽에 반대쪽 토압을 거는 것이 안전한가
- 얼마씩 올릴 것인가
- 북측 흙을 일부 걷어내는 것이 나은가

**어느 쪽이든 구조 판단이다.** 잘못하면 벽이 반대로 밀리거나, 이미 손상된 단면에 반복 하중이 간다.

**④가 중요하다.** 지금 변위가 멈췄는지 계속 진행 중인지가 급박성을 정한다. **관측 없이는 알 수 없다.** 그리고 이것은 몇 시간 안에 설치할 수 있다.

**⑦이 범위 확인이다.** 다른 구간도 중간 슬래브 없이 되메우려 하고 있다면 같은 일이 생긴다.

**하지 말아야 할 것** — **"조금 밀린 거니까 마저 채우자."** 지금 멈추면 3.5m에서 끝나지만, 계속하면 7m까지 간다.

</details>

## ⑥ 공무 담당자라면 — 오늘 안에

<details><summary>펼치기</summary>

| 할 일 | 왜 |
|---|---|
| **측량 성과의 정식 기록** — 기준, 측정값, 시각 | 사실의 고정 |
| 양측 되메움 높이 기록·사진 | 편토압의 직접 증거 |
| 되메우기 착수 이후의 **일자별 진행 기록** | 언제 얼마나 올렸는가 |
| 사용 장비와 다짐 방법 기록 | 원인 자료 |
| **되메우기 계획서 확인** — 균형 조항 유무 | 계획의 결함 |
| 중간 슬래브 시공 현황 | 지지 조건 |
| 설계도서의 **되메우기 조건·순서 규정** | 무엇이 정해져 있었는가 |
| 벽체 강도·완성 기록 | 구조 판단의 입력 |
| **기술검토 요청 문서 작성** | 구조 판단 (1-6) |
| 되메우기 중지에 따른 영향 | 기간·비용 |
| 변위 관측 기록 개시 | 진행 여부 |

**다섯 번째와 일곱 번째를 함께 봐야 한다.** 설계도서나 시방에 되메우기 순서·균형 조건이 있었는데 계획서에 반영이 안 된 것인지, 아예 규정이 없었던 것인지가 성격을 가른다.

**기술검토에 담을 것**

```text
   사실   북측 되메움 3.5m, 남측 1.2m (일자별 진행 첨부)
          북측 벽체 상단 내측 변위 18mm (측량 성과 첨부)
          이 구간 중간 슬래브 미시공
          벽체 근접부 진동 롤러 사용

   질문   현 변위가 구조적으로 허용 범위인가
          되메우기를 재개할 수 있는 조건은 무엇인가
          균형 회복 방법 (남측 성토 / 북측 제거)은 무엇이 적절한가
          중간 슬래브 미시공 구간의 되메우기 조건은 무엇인가
          변위 관측의 관리기준치를 제시해 줄 수 있는가
```

**마지막 질문이 실무적으로 중요하다.** 지금 18mm가 큰지 작은지 판단할 기준이 없다. **관리기준치를 받아야 이후 판단을 할 수 있다**(2-A-3).

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **"되메우기를 하중 작업으로 관리할 것인가"를 정하는 것.**

지금까지 되메우기는 "재료와 다짐도"로 관리됐다. 그래서 편토압이 관리 항목에 없었다.

**이번 건에 대해 정할 것:**

- 되메우기 재개 조건
- 균형 회복 방법 (구조 판단에 따름)
- 변위 관측 주기와 **관리기준치**
- 관측 결과에 따른 중지 기준

**구조적으로 정할 것:**

- **좌우 높이차의 허용 한도**를 계획에 명시
- 단계별 되메움 높이와 확인 시점
- **중간 슬래브 시공과 되메우기의 선후 관계**
- 벽체 근접부의 **장비 제한**
- 구조물 변위 계측의 설치 여부와 위치
- 되메우기 착수 조건 확인 절차 (2-B-6 ①)

**세 번째가 가장 중요하다.** 이 현장은 중간 슬래브가 일부만 되어 있다. **어디까지 되메울 수 있는가**가 슬래브 시공 현황에 따라 달라진다. 이것을 공정에 반영하지 않으면 같은 일이 반복된다(1-2, 1-8).

**공사와 공무의 시각**(1-9)

- 공사: 되메우기는 마무리 작업이다. 진입로 쪽부터 하는 게 효율적이다
- 공무: 되메움은 하중이다. 순서가 구조에 영향을 준다

**여기서 공사의 판단에 악의가 없다는 점이 중요하다.** 반입이 편한 쪽부터 하는 것은 자원 운용상 합리적이다(1-3). 다만 **그 합리성이 구조 조건과 충돌한다는 것을 아무도 몰랐다.**

</details>

<details><summary>펼치기</summary>

| 모르는 것 | 왜 필요한가 |

| 변위의 높이별 분포 | 어떤 형태로 밀렸는가 |
| 설계 허용 변위 | 18mm의 의미 |
| 벽체 균열 유무 | 손상 여부 |
| 되메움 진행의 일자별 이력 | 변위와의 시간 상관 |
| 다짐 장비의 규격과 근접 거리 | 과다 다짐 기여도 |
| 설계상 되메우기 조건 | 무엇이 정해져 있었나 |
| 중간 슬래브의 설계상 역할 | 지지 조건의 크기 |
| 흙막이 해체 범위와 시점 | 다른 지지의 유무 |
| 되메움재의 단위중량 | 토압 산정 |
| 반대편 되메우기 진행 가능성 | 균형 회복 수단 |

**아홉 번째를 놓치기 쉽다.** 흙막이가 일부 해체됐다면, 그 지지도 없어진 상태다. **지지 조건이 두 개 빠진 셈**일 수 있다(2-A-2, 3-17).

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"18mm 정도는 별거 아니다."**
비교 기준이 없다. 그리고 하루 만에 생긴 값이라면 변화율이 문제다.

**"되메움재도 승인품이고 다짐도도 통과했다."**
관리하던 항목은 정상이었다. 문제는 관리하지 않던 항목에서 생겼다.

**"남측을 빨리 올려서 맞추면 된다."**
방향은 맞을 수 있지만 현장 단독 판단이 아니다. 이미 변형된 벽에 반대 하중을 거는 것은 구조 판단이다.

**"마저 채우면 양쪽이 같아진다."**
채우는 동안 차이는 더 커진다. 그리고 벽은 계속 밀린다.

**"구조물은 28일 강도가 나왔으니 튼튼하다."**
강도와 지지 조건은 다른 문제다. 중간 슬래브가 없으면 벽이 혼자 받는다.

**"되메우기는 마무리 작업이다."**
2-B-6이 첫머리에서 부정한 인식이다. 하중을 거는 행위다.

**"진동 롤러를 써야 다짐도가 나온다."**
근접부는 작은 장비로 얇게 여러 번 한다. 다짐도를 위해 구조물을 때리는 것은 순서가 뒤바뀐 것이다.

**"계측이 없으니 알 수 없다."**
지금 설치할 수 있다. 몇 시간이면 된다.

**"흙막이가 아직 일부 남아 있으니 괜찮다."**
남아 있는 범위를 확인해야 한다. 그리고 그것이 설계가 가정한 지지인지도 확인해야 한다.

**"반입이 편한 쪽부터 하는 게 당연하다."**
자원 운용으로는 합리적이다. 그러나 구조 조건이 그 합리성보다 앞선다.

</details>

## 이 문제가 가르치는 것

> **관리 항목에 없는 것은 관리되지 않는다. 그리고 무엇을 관리 항목에 넣을지는 그 작업의 본질을 어떻게 이해하는가가 정한다.**

이 현장은 되메우기를 성실하게 했다. 승인된 재료를 썼고, 층마다 다짐도를 확인했고, 시험을 통과했다. **관리해야 한다고 배운 것은 다 했다.**

그런데 되메우기의 본질은 두 개다.

```text
   ① 채우는 일    →  재료와 다짐도로 관리한다      ← 했다
   ② 하중을 거는 일 →  순서와 균형으로 관리한다     ← 안 했다
```

**②를 모르면 ②에 대한 관리 항목이 생기지 않는다.** 그리고 관리 항목이 없으면, 문제가 생겨도 사전에 잡히지 않는다. 이번에도 계측이 아니라 **측량하다가 우연히** 발견됐다.

2-B-6이 첫 문장을 "되메우기는 치우는 일이 아니다"로 시작한 이유가 이것이다.

그리고 두 번째. **합리적인 작업 순서가 구조 조건과 충돌할 수 있다.** 진입로 쪽부터 되메우는 것은 자원 운용상 자연스럽다. 그 자연스러움이 위험한 이유는, **누구도 이상하게 여기지 않기 때문**이다(1-8).

**현장의 판단이 합리적일수록, 그것이 다른 축의 조건을 건드릴 때 더 늦게 발견된다.**
