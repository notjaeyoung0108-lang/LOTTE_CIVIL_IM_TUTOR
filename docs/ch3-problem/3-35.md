# 3-35. 균열 원인에 대한 답이 서로 다르다

> **관리업무 축** 문제처리 · 원가 | **공종 축** 콘크리트
> ※ 아래 수치·물량·기간은 모두 교육용 가정이다.

---

## ① 상황

지하 구조물 벽체에 **수직 방향 균열**이 여러 곳에 생겼다. 타설 후 3주쯤 지나 발견됐고, 지금은 8주가 지났다.

균열 조사를 해서 발주처에 보고했다. 회신이 왔다.

> **발주처(감리 경유):** "시공 중 양생 관리 미흡으로 판단됨. 시공사 부담으로 보수 후 결과 보고 요망."

같은 자료를 설계사에도 보내 기술질의를 했다. 회신이 왔다.

> **설계사:** "해당 부위는 단면 변화가 큰 구간으로, 구속에 의한 수축균열이 발생할 수 있는 조건임. 균열유발줄눈 설치 간격 재검토 필요."

두 답이 다르다. 발주처는 **시공 문제**라 하고, 설계사는 **설계 조건 문제**를 시사한다.

보수 비용은 적지 않고, 남은 구간도 같은 형상이 계속 나온다.

---

## ② 제공된 자료

| 항목 | 내용 |
|---|---|
| 균열 | 벽체 수직 방향, 폭 0.2~0.4mm, 일정 간격 |
| 발생 시기 | 타설 후 약 3주 관찰 시작 |
| 현재 | 타설 후 8주. 진행 여부 미확인 |
| 위치 | **단면이 변하는 구간에 집중** |
| 양생 기록 | 살수 양생 기록 있음. 기간·횟수 기재 |
| 온도 기록 | **없음** |
| 균열유발줄눈 | 설계도서상 설치. **간격 설계값 있음** |
| 시공 | 줄눈은 설계 간격대로 시공됨 |
| 강도 | 28일 기준 충족 |
| 남은 구간 | 동일 형상 구간 3개소 예정 |
| 누수 | 현재 없음. 지하수위는 벽체 중간까지 |

---

## ③ 먼저 답해볼 것

1. 두 답 중 어느 쪽이 맞는가. 이 질문이 옳은 질문인가.
2. 지금 보수부터 하면 되는가.
3. 남은 3개 구간에 대해 지금 해야 할 일은 무엇인가.
4. 현장이 두 기관 사이에서 할 수 있는 일은 무엇인가.

---

## ④ 무엇이 깨졌는가

<details><summary>먼저 스스로 답한 뒤 펼친다</summary>

**Flow 위치** — 2-B-4의 `⑩ 결함 확인`에서 시작해 1-5의 문제처리 Flow로, 그리고 1-6과 1-10으로 이어졌다. 지금은 **⑧ 회신** 단계에서 회신이 엇갈린 상태다.

**먼저 확인할 것 — 두 답이 정말 모순인가**

| 발주처 | 설계사 |
|---|---|
| 양생 관리 미흡 | 구속에 의한 수축균열 조건 |

**이 둘은 서로 배타적이지 않다.**

```text
   수축균열의 발생 조건    단면 변화에 의한 구속  (설계 조건)
                              +
                        수축량 (재료 · 양생 조건)
                              ↓
                        균열
```

건조수축 균열은 **구속과 수축이 함께 있어야** 생긴다. 구속이 없으면 자유롭게 줄어들고, 수축이 없으면 구속이 있어도 힘이 안 생긴다.

즉 **두 답은 같은 현상의 다른 항을 말하고 있다.** 발주처는 수축 쪽, 설계사는 구속 쪽을 지목했다.

**그렇다면 문제는 "어느 쪽이 맞는가"가 아니다.** 각 항이 **어느 정도 기여했는가**다. 그리고 그것은 **자료로만 판단할 수 있다.**

**자료를 보면 현장의 위치가 드러난다**

| 항목 | 현장에 유리 | 현장에 불리 |
|---|---|---|
| 균열이 단면 변화 구간에 집중 | ○ 구속 요인 시사 | |
| 줄눈을 설계 간격대로 시공 | ○ 시공은 도서대로 | |
| 28일 강도 충족 | ○ 재료는 정상 | |
| 살수 양생 기록 존재 | ○ 양생을 했다 | |
| **온도 기록 없음** | | ● 양생 조건을 증명 못 한다 |

**네 항목이 유리하고 한 항목이 불리하다.** 그런데 **그 한 항목이 발주처 주장의 핵심을 반박하지 못하게 만든다.**

```text
   발주처   "양생 관리 미흡"
   현장     "살수 양생을 했다" → 기록 있음
   발주처   "조건이 어땠는가"
   현장     "…"                 → 온도 기록 없음
```

**3-28, 3-34에서 계속 나온 같은 문제다.** 양생 기록의 결손이 여기서 계약적 대가로 나타난다.

**보수부터 하면 안 되는 이유** — 보수하면 **균열의 현 상태가 사라진다.** 폭, 분포, 진행 여부가 원인 판단의 자료인데, 메우면 없어진다(1-5 ③, 1-10 ④).

**진행 여부를 아직 모른다** — 8주가 지났는데 진행 중인지 멈췄는지 확인하지 않았다. **건조수축 균열은 대개 어느 시점에 멈춘다.** 계속 벌어지고 있다면 다른 원인을 봐야 한다.

**가장 시급한 것은 남은 3개 구간이다** — 같은 형상이 또 나온다. **원인이 정리되기 전에 또 치면 같은 균열이 3번 더 생긴다.**

**깨진 것을 한 줄로** — **원인이 복합적인데 두 기관이 각각 한 항씩 지목했고, 현장은 그 사이에서 어느 쪽을 고를지 고민하느라 정작 해야 할 일을 안 하고 있다.**

</details>

## ⑤ 공사 담당자라면 — 지금 당장

<details><summary>펼치기</summary>

| 순서 | 할 일 |
|---|---|
| 1 | **보수 착수 보류.** 현 상태가 자료다 |
| 2 | **균열 진행 관찰 개시** — 게이지 부착, 주기적 측정 |
| 3 | 균열 전수 조사 — 위치, 방향, 폭, 길이, 간격 |
| 4 | **단면 변화 위치와 균열 위치를 도면에 겹쳐 표시** |
| 5 | 관통 여부 확인 (반대 면 대조) |
| 6 | 누수 흔적 확인 |
| 7 | 타설·양생 기록 전량 정리 |
| 8 | **남은 3개 구간의 착수 보류 요청** |
| 9 | 남은 구간에 대한 기술질의 (줄눈 간격 재검토) |

**④가 가장 설득력 있는 자료를 만든다.** 균열이 단면 변화 위치와 일치한다면 그것은 **구속 요인을 보여 주는 직접 증거**다. 말로 하는 것과 도면 위에 겹쳐 보여 주는 것은 다르다.

**②가 두 번째로 중요하다.** 진행이 멈췄다면 건조수축 균열의 전형이고, 진행 중이라면 다른 원인(구조적 요인, 부동침하 등)을 봐야 한다. **원인 판단의 갈림길이다.**

**⑧과 ⑨가 실질적 대응이다.** 이미 생긴 균열의 책임을 다투는 것보다, **앞으로 3번 더 생길 것을 막는 것**이 훨씬 가치가 크다. 그리고 설계사가 먼저 "줄눈 간격 재검토 필요"라고 했다. **그 말을 받아서 정식 절차로 만들면 된다.**

</details>

## ⑥ 공무 담당자라면 — 오늘 안에

<details><summary>펼치기</summary>

**두 회신을 받았다는 사실 자체가 중요한 자료다.**

| 할 일 | 왜 |
|---|---|
| **두 회신 문서 원본 보관** | 상충하는 지시의 증거 |
| 균열 현 상태 사진·실측 자료 | 보수 전 기록 (1-10 ④) |
| 균열 위치도 (단면 변화 중첩) | 구속 요인의 증거 |
| 진행 관찰 기록 개시 | 원인 판단의 자료 |
| 설계도서의 줄눈 간격 조항 확보 | 설계 조건 |
| **시공이 설계 간격대로였음을 증명하는 기록** | 시공 적합성 |
| 양생 기록 원본 | 무엇을 증명하는가 |
| 28일 강도 결과 | 재료 정상의 근거 |
| **정식 기술질의 재작성** | 두 답을 하나의 절차로 모은다 |
| 계약상 설계도서 하자 관련 조항 | 성격 판단의 근거 |
| 보수 비용 산정 (조치 시) | 원가 (1-4) |

**아홉 번째가 이 케이스의 열쇠다.**

지금 현장은 **두 개의 답을 각각 받은 상태**다. 그런데 이 둘은 서로를 모른다. 발주처는 설계사 회신을 못 봤고, 설계사는 발주처 판단을 못 봤을 수 있다.

**현장이 할 일은 둘을 한 자리에 놓는 것이다.**

```text
   현재   현장 ─── 발주처  (답 A)
          현장 ─── 설계사  (답 B)
          두 답이 만나지 않는다

   해야 할 것
          현장 → "두 회신을 받았습니다. 내용이 다릅니다.
                  자료는 다음과 같습니다. 판단을 요청합니다."
                 → 두 기관이 같은 자료 위에서 답하게 한다
```

**이것이 현장이 할 수 있는 가장 강한 행동이다.** 어느 한쪽 편을 드는 것이 아니라, **상충을 공식화하는 것**이다.

**중요한 원칙** — 두 답이 다르다는 사실을 **숨기지 않는다.** 유리한 쪽만 들고 있다가 나중에 드러나면 훨씬 불리해진다.

**성격 판단**

- 설계 조건 기인이면 → **설계 사안**. 보수 비용의 귀속이 달라진다
- 양생 미흡 기인이면 → **시공 귀책**
- 복합이면 → 기여도의 문제. 협의 사안

**셋 다 가능하고, 지금은 정할 수 없다.** 그러나 **통지와 기록은 지금 한다**(1-10 ②).

</details>

## ⑦ 두 사람이 합의해야 할 것

<details><summary>펼치기</summary>

> **"이미 생긴 것"과 "앞으로 생길 것"을 분리해서 다루는 것.**

두 문제가 섞이면 아무것도 진행되지 않는다.

**앞으로 생길 것 (남은 3개 구간) — 이것부터 푼다**

- 남은 구간 착수 보류 여부와 기간
- 줄눈 간격 재검토 요청의 공식화
- 양생 계획 강화 (온도 기록 포함)
- 설계 회신까지의 공정 영향

**이쪽은 이견이 적다.** 양쪽 다 같은 균열이 3번 더 생기는 것을 원하지 않는다. 그리고 **여기서 취한 조치가 원인 판단에도 도움이 된다.** 줄눈을 조정해서 균열이 줄면 구속 요인이 컸다는 뜻이고, 양생을 강화해서 줄면 수축 요인이 컸다는 뜻이다.

**이미 생긴 것 — 순서를 정한다**

- 진행 관찰 기간 (얼마나 볼 것인가)
- 조사 자료의 범위
- 두 회신의 상충을 공식 제기할 것인가 (해야 한다)
- 보수 시점 — 진행이 멈춘 것이 확인된 뒤
- 보수 방법과 비용 부담은 **원인 정리 후**

**공사와 공무의 시각**(1-9)

- 공사: 보수해서 빨리 정리하고 싶다. 현장이 지저분하다
- 공무: 보수하면 증거가 사라진다. 그리고 비용 귀속이 안 정해졌다

**여기서 공무의 논리가 우선한다.** 다만 기한 없이 두는 것도 문제이므로, **관찰 기간을 정해 두는 것**이 합의점이다.

</details>

## ⑧ 부족한 정보

<details><summary>펼치기</summary>

| 모르는 것 | 왜 필요한가 |
|---|---|
| **균열이 진행 중인가** | 원인 판단의 갈림길 |
| 균열 위치와 단면 변화의 일치도 | 구속 요인의 크기 |
| 관통 여부 | 수밀 영향 |
| **당시 양생 온도와 습도** | 기록이 없다 |
| 살수 양생의 실제 횟수·기간 | 기록의 구체성 |
| 배합의 단위수량·수축 특성 | 수축 요인 |
| 줄눈의 실제 시공 상태 (깊이·연속성) | 유발 기능이 작동했는가 |
| 설계 줄눈 간격의 근거 | 무엇을 전제했는가 |
| 남은 구간의 형상 조건 | 같은 위험인가 |
| 계약상 설계도서 관련 조항 | 성격 판단 |
| 유사 구간의 균열 발생 이력 | 패턴 |

**일곱 번째를 놓치기 쉽다.** 균열유발줄눈은 **거기서 갈라지게 유도하는 장치**다. 깊이가 부족하거나 연속되지 않으면 기능하지 않고, 그러면 옆에서 갈라진다. 설계 간격대로 설치했어도 **시공 품질이 다른 문제**다.

</details>

## ⑨ 흔한 오답

<details><summary>펼치기</summary>

**"발주처가 하라는 대로 보수하면 된다."**
보수하면 증거가 사라지고, 비용 부담이 확정되며, **남은 3개 구간에서 같은 일이 반복된다.**

**"설계사가 설계 문제라고 했으니 우리 책임 없다."**
설계사 회신은 조건을 지적한 것이지 면책을 준 것이 아니다. 그리고 양생 요인이 배제된 것도 아니다.

**"어느 쪽이 맞는지 정해야 한다."**
두 답이 배타적이지 않다. 같은 현상의 다른 항이다.

**"두 답이 다르니 유리한 쪽을 쓰자."**
상충을 숨기는 것이다. 나중에 드러나면 훨씬 불리하다.

**"균열 0.3mm는 큰 문제 아니다."**
폭만으로 판단하지 않는다. 진행 여부, 관통 여부, 수밀 요구가 함께 봐야 할 항목이다.

**"8주 지났으니 이제 안 벌어질 것이다."**
확인하지 않았다. 관찰이 필요하다.

**"남은 구간은 똑같이 하면 된다."**
같은 조건이면 같은 결과가 나온다. 그리고 설계사가 이미 재검토가 필요하다고 했다.

**"양생 기록이 있으니 우리는 잘했다."**
살수 기록은 있지만 온도 기록이 없다. 조건을 증명하지 못한다.

**"현장은 두 기관 사이에서 할 수 있는 게 없다."**
있다. **자료를 정리해서 두 답을 한자리에 놓는 것**이다. 그것이 현장만 할 수 있는 일이다.

**"보수하고 나서 원인은 나중에 정리하자."**
순서가 반대다. 보수하면 원인 판단의 자료가 사라진다.

</details>

---

## 이 문제가 가르치는 것

> **상위 기관의 답이 갈릴 때, 현장이 할 일은 한쪽을 고르는 것이 아니라 두 답이 같은 자료 위에서 만나게 하는 것이다.**

발주처와 설계사는 서로 다른 것을 본다. 발주처는 시공의 결과를 보고, 설계사는 설계의 조건을 본다. 그리고 **둘은 서로의 답을 모른 채 각각 답한다.**

현장은 그 사이에 있다. 그래서 두 답을 **모두 가진 유일한 위치**다. 이 위치가 부담이기도 하지만, 동시에 **할 수 있는 일이 있는 자리**다.

```text
   잘못된 대응   한쪽을 골라 따른다        → 다른 쪽 답이 나중에 튀어나온다
   잘못된 대응   유리한 쪽만 들고 있는다   → 숨긴 것이 된다
   옳은 대응     상충을 공식화한다        → 두 기관이 같은 자료 위에서 답한다
```

그리고 이 케이스의 두 번째 교훈. **이미 생긴 것과 앞으로 생길 것을 분리하면 움직일 수 있다.**

책임 다툼은 오래 걸린다. 그동안 남은 3개 구간을 그대로 치면 손실이 4배가 된다. **책임이 정리되기 전에도 할 수 있는 일이 있고, 그것이 가장 값이 크다**(1-5 ②).

마지막으로, 이 케이스에서 현장을 가장 불리하게 만든 것은 **온도 기록의 부재**였다. 3-28에서 판단을 어렵게 했고, 3-34에서 원인 특정을 막았고, 여기서는 **계약적 방어를 못 하게** 만들었다. 같은 결손이 세 번 다른 모습으로 나타났다(1-10 ④).
