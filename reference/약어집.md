# 약어집

명칭은 사업별로 다르다. 약어를 알았다는 사실만으로 승인·권한·검사 결과를 판단하지 않는다.

| 약어 | 원어 | 의미 / 첫 장 |
|---|---|---|
| TBM | Tool Box Meeting | 작업 전 안전·역할 공유 / 01. 터널 공법에서 Tunnel Boring Machine을 뜻할 수도 있어 문맥 구별 |
| BM | Bench Mark | 측량 기준점 / 02 |
| EL | Elevation | 정한 기준면에 대한 표고 / 02 |
| GL | Ground Level | 지표면 높이 표현 / 02 |
| Rev. | Revision | 문서 개정 / 02 |
| IFC | Issued for Construction | 시공용 발행 상태 표현 / 02 |
| BBS | Bar Bending Schedule | 철근 가공표 / 08 |
| ITP | Inspection and Test Plan | 검사·시험계획 / 12 |
| IR | Inspection Request | 검사 요청 서식의 한 명칭 / 12 |
| WIR | Work Inspection Request | 작업 검측 요청 서식의 한 명칭 / 12 |
| NCR | Nonconformance Report | 부적합 보고 / 12 |
| CP | Critical Path | 전체 완료를 지배하는 일정 경로 / 14 |
| CPM | Critical Path Method | 주공정 경로법 / 14 학습의 일정망 |
| RFI | Request for Information | 기술 정보 질의 / 15 |
| EAC | Estimate at Completion | 준공 예상원가 / 16 |
| KDS | Korean Design Standard | 국가건설 설계기준 / 기술검증 문서 |
| KCS | Korean Construction Specification | 국가건설 표준시방서 / 기술검증 문서 |

공종별 보조 카드에는 PHC, PSC, NATM 등이 더 나온다. 본편 18장은 교량·터널 전체 시공교육 대신 판단 전이 문제를 제공하므로 해당 약어의 공법 상세는 보조 자료와 현장 적용 기준으로 확장한다.
