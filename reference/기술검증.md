# 기술 검증 범위와 현장 적용 확인

확인일: 2026-09-24. 본문 사건·대화·공정·계산은 교육용 구성이다. 이번 검토는 개념·권한 경계·계산·내용 일관성 검토이며, 특정 현장의 시공 승인이나 전문 기술자의 설계 감수가 아니다.

외부 자료를 본문으로 옮겨 붙이지 않았다. 해외 자료는 개념을 교차 확인하는 참고로만 사용했다. 원문 열람이 제한된 자료는 확인 범위를 위와 같이 한정했다. 국내 법규·계약의 특정 수치·통지기간을 본문에 새로 제시하지 않았다.

## 자체 검토한 항목

- Piping·Boiling·Heaving을 같은 현상으로 쓰지 않았고 관찰만으로 원인을 확정하지 않았다.
- 계측값 하나를 다음 굴착·지보 해체의 안전 근거로 쓰지 않았다. 힘의 전달은 벽·띠장·버팀·접합·지반과 영구부 전환을 함께 설명했다.
- 피복 부족 원인을 철근 이동 하나로 고정하지 않았다. 정착·이음·거푸집·동바리 변경을 권한 있는 검토에 연결했다.
- Slump·공시체·표면 경화·날짜 경과를 구조 강도 합격과 혼동하지 않았다.
- Hold/Witness·요청/결과·NCR 발행/종결을 구분했다. 해당 사례의 Hold Point는 가상 프로젝트 설정이다.
- RFI 회신·설계 승인·비용 합의·기성 인정을 나눴다. 귀책과 공기연장을 자동 결론으로 만들지 않았다.
- 원지반·운반 체적, 함수비 분모, 가공·반입·설치의 누적·상태 수량, 발생원가·지급액을 구별했다.
