# 도면을 현장에 놓는 순서

처음 학습은 CASE 02, 배근 연결은 CASE 08, 개정 영향은 CASE 13, 준공 인수는 CASE 18에서 한다.

## 위치를 찾는다

도면 번호·제목·적용 구간·승인 상태·개정·발행 목적을 문서대장과 대조한다. 다음으로 평면에서 구조물 번호와 측점을 찾는다. 종단에서는 같은 측점의 높이, 횡단에서는 폭·경사·좌우 위치, 상세에서는 접속·배근·시공 조건을 확인한다. 축척으로 잰 길이보다 표기 치수와 상세를 우선 확인하되 문서 간 충돌은 해당 계약·설계 질의 경로로 해소한다.

## 기준을 맞춘다

좌표계·기준점·표고 기준·단위·방향을 기록한다. 먹이 중심선인지 외곽선인지 작업 여유선인지 구분한다. 기준점 보호 상태와 독립된 교차 확인 없이 기계를 다시 설치했다고 오류가 해결된 것은 아니다. EL·GL 표기는 도면 범례와 현장 정의를 확인한다.

## 실제 작업과 연결한다

구조도→시공상세도→BBS→반입 표찰→설치 위치를 같은 Mark로 잇는다. 개정 대조는 구름 표시만 보지 말고 관련 치수·상세·다른 공종 문서까지 확인한다. 철근을 가공장 잔량·운송·현장 적치·조립으로 나누며 누적 가공량에 반입량을 더하지 않는다.

## 바뀐 정보를 닫는다

접수·배포·수령·교육·실제 사용본을 각각 확인한다. 구도면은 현장 사용을 막되 이력은 보존한다. 변경 상세의 기술 승인과 계약 금액·기간 합의를 혼동하지 않는다. 준공도면은 실제 시공을 기록하지만 미승인 시공을 적법·적합하게 만드는 수단은 아니다.
